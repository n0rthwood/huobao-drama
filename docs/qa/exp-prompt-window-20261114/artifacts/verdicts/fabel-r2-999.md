## 逐份意见

**X**

优点：mid/last 关键帧几乎逐句落实设计卡 gen_plan（「一轮齐射的白烟横在整排队列前」对应 p6/p7 的烟，「倒下的人横在泥水里」对应 p8），机位/景别/光线/四肢状态齐全（「双腿分开站稳、两只皮靴踩在湿泥上清晰可见」），每张都以「16:9 横构图电影感剧照，单帧静态画面」收口，完全自足；C 衔接规则执行干净——first 留空，视频第一段「0-1秒：俯拍平面地图式画面……镜头静止，画面无人」逐项复述 caption、无切镜、≤1.5 秒；每个内容段都 @ 了 `@托博尔河与额尔齐斯河交汇处`，无编造资产；对无名群演的服装描写与已确认设计卡同口径（卡内即写「尖顶毡帽、深色长袍、背弓」），且末帧明确「画面中所有人都是无名的交战双方」，不触碰图像优先红线。

硬伤（两条时间轴硬规则同时违反）：① 规则「各段时间范围相加……总时长以提交时长为准」——本镜提交时长 = gen_s = **9.5 秒**，X 的分段 0-1 / 1-4 / 4-7 / 7-11 / **11-13.5** 总和 **13.5 秒**，末段整段落在提交时长之外；② 规则「mid_frame_time 有值时，必须有某个分段的起点正好落在该秒数」——X 的 mid_frame_time=5.5，但段起点只有 0/1/4/7/11，**5.5 落在 4-7 段中部**，且该段开头是「切到对岸方向」的骑兵强调机位，与 mid_frame_prompt 的齐射正面全景不对位，中间帧引导（round(5.5×24) 帧）会撞上文本正在讲别的画面。另有次要问题：p7 要求的「倒下的骑兵」在视频正文全程缺位（只有 mid 关键帧里「一名蒙古骑兵连人带马歪倒」一处既成事实）；人数写成「十余人」对「七八骑+五六人」，约略相当，暗暗削弱旁白与 p3 的「人数上远低于蒙古人」。

**Y**

优点：mid_frame_time 改为 4.5 并严格兑现——「4.5-7.5秒：……一轮齐射打响」段起点正好落在 4.5，段开头与 mid_frame_prompt（齐射+「前排几名骑兵已中弹栽落」）一致，是两份中唯一满足中间帧对位规则的；叙事弧更完整（列队→齐射→倒下→肉搏→定格尾帧），把旁白的两个关键信息真正画了出来：「人数明显多于左侧的哥萨克横列」「后排仍有成片身影在跟进」直接可视化 p3 的人数悬殊，「前排几名骑兵中弹从马背栽落」正是 p7 说的「横扫」；seg4 先引入「长矛刺出 vs 枪身横架」这对动作，seg5「两人的缠斗姿态定格」收在尾帧，承接干净。C 规则、@ 引用、关键帧自足（含「无运动模糊」）与 X 同样合格。

硬伤：时间轴总长同样违反「以提交时长为准」——0-1 / 1-4.5 / 4.5-7.5 / 7.5-11 / 11-15 总和 **15 秒**，明显是把成片时间轴（图层 5.5 + 生成 9.5）当成了视频提示词时长，超出提交时长 5.5 秒；11-15 的尾帧定格段在真实 9.5 秒视频里不存在，全部内容会被模型压缩变速。次要：远景「二十余人+成片身影」对扩散模型是高难构图，群像糊脸风险比 X 的中景高。

## 取舍

**胜者：Y。** 一句话结论：两份都犯了同一个「把时间轴写超提交时长 9.5 秒」的错误，但 Y 守住了中间帧对位这条硬规则并把「人数悬殊、步枪横扫」真正变成了画面，X 则是总长、mid 对位双违规且 p7 落空。

若只能用 Y 的小修：保持段落内容与顺序不动，把时间轴压回 9.5 秒并保留 4.5 这个段起点——建议 `0-1 / 1-4.5 / 4.5-6.5 / 6.5-8 / 8-9.5`，各段文字按比例精简（尤其把 11-15 的定格段压成 8-9.5 的收束句），mid_frame_time=4.5 不变，其余原样可用。若被迫用 X：需重切为 `0-1 / 1-3 / 3-5.5 / 5.5-7.5 / 7.5-9.5`，让 5.5 成为段起点并把 mid 画面移到该段开头，同时在齐射段补「骑兵中弹栽落」。
