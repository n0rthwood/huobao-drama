## 逐份意见

**X**：画面功力明显更高。两张关键帧完全自足（机位/光线/构图/四肢状态齐全：「骑者各自端坐马背、双手握着缰绳搁在鞍前、双腿垂在马腹两侧、双脚踩在马镫上」），mid 忠实带上了设计卡的「寨内几处营火升起细烟」，尾段「草面留有一道被踏过的痕迹向画面右侧远处延伸」把 ipm0「两百多年统治的终点」变成了可拍的空镜意象；「随后为首几骑依次越过草坡的隆起处、马身与骑者的背影一道隐入坡后」让撤离在画内完成，远景→反向中景→回切空营的三段结构是真正的镜头语言。0–1 秒衔接复述段逐项还原 caption、无人、不切镜、承诺单一运镜（「极缓推近」），满分。**硬伤在维度 4，且是生产级的**：规则要求「mid_frame_time 有值时，必须有某个分段的起点正好落在该秒数，且该段开头画面与 mid_frame_prompt 一致」，X 的分段边界是 0/1/4/8——5.5 秒落在「4-8秒：切到近岸前景的**反向中景**平视固定机位」段内部，而 mid_frame_prompt 写的是「**远景广角**平视固定机位，取 @乌格拉河畔 的宽阔河湾」。中间帧引导在 5.5 秒注入时会与正文机位正面相撞（本项目实测引导帧在其帧位 SSIM≈0.93–0.95，必然吸附），成片会在反向中景段中途被硬拉回宽构图，出现一次计划外跳变。另有与 Y 共有的总时长问题（见下）。

**Y**：胜在规则落点。「5.5-8.5秒：切到 @乌格拉河畔 的宽阔河湾远景广角平视固定机位，正午顶光、河面亮白反光强烈……」——分段起点正好落在 mid_frame_time=5.5，开头画面（远景广角、顶光、骑队右移）与自己的 mid_frame_prompt 逐项一致，这是本镜唯一满足中间帧硬规则的一份。@ 引用、C 衔接段同样干净。缺点集中在工艺层：① 「4-5.5秒：仍取 @乌格拉河畔 的远景广角固定机位，镜头缓推」是为凑 5.5 边界插入的 1.5 秒填充段——「固定机位」与「缓推」自相矛盾，且 5.5 秒处「切到」几乎同景别同机位的宽景，形成跳切；1–4 / 4–5.5 / 5.5–8.5 三段连续宽景重复，骑队消失靠跨切镜交代，表现力明显弱于 X。② last 关键帧混入两句不可拍的元叙述：「表达两百多年统治的终点」「可被下一镜直接承接」，后者还是对邻镜的相对指涉，违背关键帧自足原则。③ 0–1 段照抄规则原文写「镜头静止**或**极缓推」，提示词不应给模型二选一。④ mid 关键帧漏掉设计卡的「对岸木栅营寨冒着细烟」（视频段里才补回）。

**共有硬伤（两份同罪，必须指出）**：规则明文「总时长以提交时长为准」，本镜提交时长 = gen_s = **5.5 秒**（实渲 6.58 秒），而 X、Y 的时间轴都写满 **11 秒**（把成片总轴当成了生成段时长）。后果：X 的「8-11秒」、Y 的「8.5-11秒」空营收束段在 6.58 秒的视频里基本不会被渲染，ipm0 的「终点」画面只能靠尾帧引导硬拉，正文等于失效。合规写法应是 0–1 衔接复述 + 约两个内容段收在 5.5 秒，并相应把 mid_frame_time 改进段内（候选本就被允许改它），两份都没做。

## 取舍

**胜者：Y。** 一句话结论：X 的镜头设计更好看，但在 mid_frame_time=5.5 处与自己的中间帧引导正面相撞，属于会在成片中段产生可见跳变的硬规则违例；Y 以分段对齐换走了这颗雷，在两份共有「11 秒 ≠ 提交时长 5.5 秒」错误的前提下更接近可用。

**若只能用 Y 的小修**：① 把时间轴压到提交时长——`0-1 衔接复述 / 1-3 撤离远景 / 3-5.5 切空营收束`，mid_frame_time 同步改为 **3.0 秒**（保持「分段起点 = 中间帧时刻」）；② 删除 last 关键帧里「表达两百多年统治的终点」「可被下一镜直接承接」两句元叙述；③ 0–1 段写死「极缓推」；④ mid 关键帧补回「对岸木栅营寨冒着细烟」；⑤ 压轴后若仍嫌宽景重复，可把收束段换成 X 的反向中景写法（前景木桩原木压右下角）做景别变化——即「Y 的时间骨架 + X 的画面血肉」。
