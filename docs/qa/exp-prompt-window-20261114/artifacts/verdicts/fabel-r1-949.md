## 逐份意见

**X**

优点：mid/last 两张关键帧提示词（与 Y 共用）质量很高——机位/景别（「中景平视固定机位」「远景广角平视固定机位，构图分三层」）、四肢状态（「双脚踩在马镫上」「右手提着一支 @哥萨克火枪 的枪托后段、枪管朝下斜指地面」）、光线（「午后偏黄的地面光，阳光自画面上方偏右强烈斜照」）齐备，完全自足，无「同上」式相对描述。C 衔接规则执行干净：first 为空，视频第一段「0-1秒：@哥萨克聚落，俯拍地图式全景……镜头极缓推近，画面无人」逐句复述 caption、无人、无切镜、≤1.5 秒，「极缓推」在允许范围内。设计卡信息点落地完整：ip5 的「骑队穿缺口、草顶棚架、拴马桩」与 ip6 的「捆包、驮马、巢穴」都有对应画面；gen_plan 两项参考资产（@哥萨克聚落、@哥萨克火枪）逐段被 @，无 card_ref_unmet 风险。信息头主动声明「出场人物：无名哥萨克男子（营地住户与骑队）」且不滥用 @，与设计卡「画面中不见明确的主角」一致。

硬伤（维度 4，两条规则）：
1. **违反「mid_frame_time 有值时，必须有某个分段的起点正好落在该秒数」**：X 自报 mid_frame_time = 3.0 秒，但分段起点是 0 / 1 / 4 / 7 / 9.5——没有任何一段起点落在 3.0。中间帧的院内中景被写进「4-7秒」段，t=3.0 落在「1-4秒」聚落外围远景的半中腰。中间帧会在 3.0 秒作为引导帧注入（frame_idx≈72），而文案此刻还在另一个机位，引导图与文字必然打架，跳变会出现在段中而非切点。
2. **「4-7秒」段开头与 mid_frame_prompt 相抵触**：视频写「那四名骑马的人**已全部进入院内**……马匹四腿**立稳**在夯土地上、马头朝向画面**左侧**」，而 mid_frame_prompt 是「**正从土路上穿过缺口进入院内**……马匹四腿**跨步前行**、马头朝向画面**右侧**」——不止时间错位，画面内容也反了（停 vs 行、左 vs 右），等于要求马在一秒内原地调头。
3. 共有问题（与 Y 同罪）：时间轴总长 11.5 秒 ≠ 提交时长 6.5 秒，违反「总时长以提交时长为准」——C 组合的视频提示词只驱动生成段，0-1 秒衔接段已证明时间轴以生成段为零点，末段却写到 11.5 秒，相当于给 6.5 秒的视频塞了 10.5 秒的内容量。

**Y**

优点：与 X 共享同一套高质量关键帧提示词与段落画面素材，而在唯一的实质分歧点上做对了——**「3-6秒」段起点正好落在 mid_frame_time = 3.0**，且该段开头「切到聚落院内中景平视固定机位……四名骑马的人……**依次穿过缺口进入院内**……马头朝向画面**右侧**」与 mid_frame_prompt 逐项吻合（穿缺口、行进中、朝右），引导帧与文案互相强化而非互相撕扯。C 首段「镜头静止，画面无人」最稳妥。末段「9-11.5秒：切回聚落全景远景广角」逐句收在 last_frame_prompt 的三层构图上。逐段 @场景、可见火枪逐段 @ 且带辨识性要素（「枪托后段」「火绳夹」「通条」），合规。

硬伤 / 瑕疵：
1. 与 X 共有的时间轴总长问题：末段写到 11.5 秒，超出 6.5 秒提交时长（见上，X 第 3 条）。这是 Y 维度 4 只有 6 分的原因。
2. 信息头省略了「出场人物」位（只有「场景：@哥萨克聚落；道具：@哥萨克火枪。」）——本镜无角色资产，省略可辩护，但不如 X 的「无名」声明信息完整，属小瑕。
3. 与 X 共有的轻微设计卡偏离：设计卡 gen_plan.mid 写「一名哥萨克**背对镜头站在门旁，右手提着一支火枪**」，共用的 mid_frame_prompt 改成「侧身朝向墙缺口……双手各垂在体侧」、火枪挪到墙根斜靠——信息未丢（聚落 + 武装 + 火枪在场）但姿态被重摆，两份同罪，不构成区分。

## 取舍

**胜者：Y。** 两份关键帧完全相同，胜负只在视频提示词的时间轴：Y 把分段起点钉在 mid_frame_time = 3.0 且画面与中间帧一致，X 错位到 4 秒并与中间帧内容相抵触，属引导帧契约层面的硬违规。

若只能用 Y，小修方案：把时间轴压回 6.5 秒提交时长——`0-1`（衔接空镜）/ `1-3`（聚落外围骑队穿缺口）/ `3-5`（院内中景，mid 对齐 3.0 不变）/ `5-6.5`（全景收束在尾帧画面），驮马一拍并入末段全景（last_frame_prompt 里本就有「另一名哥萨克男子牵着一匹驮马停在路边」），删掉独立的侧向中景段；其余文字原样保留。
