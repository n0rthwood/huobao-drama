## 逐份意见

**候选 X**

优点：
- **C 组衔接规则满分执行**：不写 first_frame_prompt；「0-1秒：…镜头静止…画面无人」几乎逐字复述衔接帧 caption（木桌烛台、红褐地毯、两根石柱、右侧深色木门、左墙拱窗、留白位置全中），无人、无切镜、无 @ 角色、无过渡写法，首段 1 秒收束，是三条候选规则里最干净的写法；「切到」从 1 秒后的第二段才出现，合规。
- **mid_frame_time 锚定正确**：存在以 2.5 秒为起点的分段（「2.5-5.5秒」），且该段开头（科尔佐把皮捆「端正在胸前」、伊凡四世前倾持杖横膝、廷臣列于阶下）与 mid_frame_prompt 画面一致——这是硬规则，X 独自做到了。
- 前三段 0-1 / 1-2.5 / 2.5-5.5 恰好铺满提交时长 5.5 秒，内部自成一条完整可拍的时间轴。
- 信息点落地好：ip1 的「汇报」被拍成画面（「下颌抬起、嘴唇开合向阶上回话」），而不是靠旁白；ip3 的震惊有具体面部动作（「眉骨舒展、眼睛睁大、嘴唇微张」）；群演人数全程稳定「共六人」。关键帧提示词机位/景别/光线/四肢状态齐全，且道具细节（「杖头镶宝石的多面球饰」「杖身中段的雕花凸环」「三段粗麻绳扎结」）与资产参考图（图 5/6）逐一对得上，附图 7/8 的渲染结果证明可落地。

硬伤：
- **维度 4：时间轴总和 16.7 秒 ≫ 提交时长 5.5 秒**，违反「各段时间范围相加等于段落总时长、总时长以提交时长为准」。5.5 秒之后的四段（5.5-8.5 摊皮、8.5-11.5 沙皇震惊、11.5-14.5 侍从解捆、14.5-16.7 收束）全部落在模型根本不会渲染的死区——ip3 最强的震惊节拍被写进了不存在的时间里。
- 维度 2：1-2.5 秒段固定机位且「雕花木座位于画面右后方」在画内，但该段没 @伊凡四世；到 2.5 秒中间帧他已坐在同一木座上，等于沙皇在固定镜头里凭空出现，属「画内绑定角色漏 @」。
- 共有小疵：mid 提示词「画面右后方是雕花木座」与「视线投向**画外**右侧的木座」自相矛盾；mid 画面（皮捆仍举在胸前、权杖横膝）与设计卡 mid（「地上摊开的成捆黑貂皮」「权杖搁在扶手上」）有偏离；「两只宫廷侍从」量词错；「皮靴/靴尖」踩在服装描写的边线上。

**候选 Y**

优点：
- @ 引用最完整：1-4 秒段里木座在画内时就 @伊凡四世 并带权杖，每段场景、在场角色/道具覆盖无遗漏；科尔佐「从画面右侧走入」与衔接帧「右侧为深色木门」的空间逻辑吻合，也更贴近设计卡 gen_plan.first（两人同框）。关键帧提示词与 X 几乎同文，同样自足。

硬伤：
- **维度 4 双重违规（本局致命）**：mid_frame_time = 2.5 秒，但分段边界是 0/1/4/7.5/10.5/13.5/16.5——**没有任何分段起点落在 2.5 秒**，2.5 秒时画面还在「1-4秒」的入场途中，与 mid_frame_prompt（皮捆举胸、沙皇前倾）对不上，直接违反「必须有某个分段的起点正好落在该秒数」；同时总时长 19.5 秒是两份中溢出最严重的，且按实际渲染（约 6.58 秒）截断会停在 4-7.5 段中间，连「截掉后半」的补救都不成立。
- 维度 3：0-1 秒复述段把 caption 的「烛台」抄成「**燧台**」，复述失真；「极缓推进」合规但不如 X 的「镜头静止」稳。
- 维度 1/7：群演人数在同一连续场面里漂移（「共四人」→「共六人」→「共五人」→「共六人」）；全程「嘴唇抿平」，旁白核心动作「汇报」没有任何开口画面；13.5-16.5 与 16.5-19.5 两段构图近乎重复，纯属拖长；1-4 秒段木座明明在画内却写「目光投向**画外**右上方的木座」，矛盾比 X 更刺眼。

## 取舍

**胜者：X。** 一句话结论：两份都把 5.5 秒的生成段写成了十几秒的幻影时间轴，但 X 的前 5.5 秒（0-1 衔接复述 / 1-2.5 入场 / 2.5-5.5 中间帧锚定）自成一条完全合规、可直接渲染的骨架，而 Y 同时丢失 mid_frame_time 锚点、溢出最狠、复述还抄错字，不可修复性更高。

**若只能用 X 的小修方案**：把 video_prompt 截断为前三段（总长 = 5.5 秒），将死区里的关键节拍压回最后一段——「2.5-5.5秒」后半改为皮捆摊开落地、@伊凡四世 眼睛睁大前倾（ip3），段尾收在与 last_frame_prompt 一致的「摊开皮张 + 沙皇俯视」构图上（满足「末段收在尾帧画面」）；同时在 1-2.5 秒段补 @伊凡四世（或明写该段取景不含高台），并把 mid/last 里「画外右侧的木座」统一改成「画面右后方的木座」。
