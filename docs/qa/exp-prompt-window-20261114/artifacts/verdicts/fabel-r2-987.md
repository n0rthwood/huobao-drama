## 逐份意见

**X**

优点：① C 规则执行干净——first 留空，0–1 秒段逐项复述 caption（米黄底图、浅蓝细线、红白小圆点、双折线箭头与深棕箭头交叉、右下留白），「镜头极缓推近，画面无人」，无切镜、无 @、1 秒内收束，完全合规。② mid_frame_time 沿用 7.5 秒，落在生成段（4.5–11）内，且时间轴上确有分段起点正好在 7.5——「有分段起点落在该秒数」这条机械规则是 X 唯一满足的一方。③ 两张关键帧自足度极高：机位（中景/中远景平视固定）、光线（低角度淡金晨光方向明确）、构图分区、四肢状态（「双腿分开站稳、两只皮靴踏在栈桥木板上可见」）俱全，无相对描述。

硬伤：① **信息头缺出场人物**：「场景：@索利卡姆斯克；道具：@哥萨克火枪。」——@叶尔马克·齐莫菲叶维奇 全片在场却未列入首行，违反「信息头＝出场人物与场景」。② **7.5 秒切点画面与 mid 关键帧对不上**：mid_frame_prompt 写他「立在木栈桥端头……左手掌虚扶在一只平底船的船舷沿上」，而 7.5–10 段开头却是「已从栈桥端头移步到最前那艘平底船的船尾横板前」的宽景——引导帧注入点恰好撞上一个位置、景别都不同的切镜，违反「该段开头画面与 mid_frame_prompt 一致」。③ **动作线倒退**：7.5–10 段「桨叶斜插入水中，船身在水面拖出细碎的浅色尾迹」（船队已开动），10–11 段却回到「平底船队已泊成一列……岸上还有数人沿跳板依次登船」——先出发再回泊、边拖尾迹边登船，视觉逻辑自相矛盾，且设计卡 last 本就定格在「待发」而非「启航」。④「共十余人」把 ip7 要的「人数众多的远征」直接写小了。⑤ 时间轴总长 11 秒 ≠ 提交时长 6.5 秒（与 Y 共有，见下）。

**Y**

优点：① 信息头完整：「出场人物：@叶尔马克·齐莫菲叶维奇；场景：@索利卡姆斯克；道具：@哥萨克火枪。」② 叙事弧最贴设计卡：1–4.5 无主角的登船大全景（对应 gen_plan.first「画面无人直视镜头」）→ 4.5–7.5 主角走上栈桥端头站定（对应 mid）→ 7.5–11 满载船队定格（对应 last），单调递进、不回头。③ ip7 落地最好：「队伍沿栈桥向岸上延伸、队尾隐在薄雾里」「船身吃水显示已满载」，用画面而非数字表达 1340 人的规模。④ 0–1 秒复述段同样逐项合规（「镜头静止，画面无人」）；关键帧末尾显式标「单帧静态画面」，自足性与 X 同级。

硬伤：① **mid_frame_time = 3.0 秒是本镜最重的机械错误**：生成段占成片 4.5–11 秒，3.0 秒落在图层段内，违反 C 组合「mid_frame_time 落在生成段内」——生产基线用 7.5（4.5+3.0）正说明存储值走成片时间轴，3.0 会把引导帧推到确定性渲染区甚至与锁死的衔接首帧打架；即便按「生成段内相对秒数」善意解读，Y 自己的时间轴（0-1/1-4.5/4.5-7.5/7.5-11）也**没有任何分段起点落在 3.0**，违反「必须有某个分段的起点正好落在该秒数」；且其 mid 画面（叶尔马克立栈桥端头的中景）与 3.0 秒所在的 1–4.5 段（无叶尔马克的广角）无论怎么对都对不上。三种读法全部失败。② 1–4.5 段火枪可见却只写裸文本「数人各自单手握着火枪的枪身」，整段无 @哥萨克火枪，违反「该段画面内可见的绑定道具每段都要 @」。③「接在空镜之后，切到……」是相对指代式写法，属噪音。④ 时间轴总长 11 秒（共有缺陷）。

**两份共有的硬伤**：规则明文「总时长以提交时长为准」，本镜提交时长 = gen_s = 6.5 秒，而 X、Y 的 video_prompt 都排到 11 秒——约 7.3 秒之后的内容（X 的 7.5–10/10–11、Y 的 7.5–11 大半）在模型视频里根本不存在，两份的 last 收束画面都被排进了幻影区间，实际成片末帧引导会与文本中段（人物还在栈桥）打架。正确形态应是 0–1 复述 + 1–6.5 两个内容段、在 6.5 前收到 last 画面。

## 取舍

**胜者：X**。一句话结论：Y 文笔与设计卡贴合度更高，但它把 mid_frame_time 改到 3.0 秒——一个落在图层段、全时间轴无切点、与自家 mid 画面也对不上的值，属于会直接损坏引导帧机制的机械性错误；X 的缺陷（信息头漏人、7.5 切点画面错位、启航—回泊倒退）都是文本层可修的编辑问题，故险胜。

若只能用 X，小修四处：信息头补「出场人物：@叶尔马克·齐莫菲叶维奇」；时间轴压缩为 0–1 / 1–4 / 4–6.5 并把 last 的「泊成一列待发」画面收进末段（删掉 7.5–10 的划桨拖尾迹内容，消除倒退）；让起点在 mid_frame_time 的那段以 mid 关键帧画面（栈桥端头、左手扶船舷）开场；「共十余人」改为「长队沿岸滩延伸、队尾隐入雾中」。
