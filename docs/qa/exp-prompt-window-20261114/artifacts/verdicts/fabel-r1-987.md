## 逐份意见

**X**
- 优点：C 组合执行到位——不写 first_frame_prompt，第一段「0-1秒：俯拍远景，米黄色地图底面……镜头静止，画面无人」逐项复述了 caption（折线箭头、红白小圆点、深棕直线箭头、留白方位全中），无 @、无切镜、1 秒收段，切镜严格从「1-4秒」起。信息头完整：「出场人物：@叶尔马克·齐莫菲叶维奇；场景：@索利卡姆斯克；道具：@哥萨克火枪」，三个 @ 与资产名逐字一致，每个内容段都 @ 场景并对在场角色/道具逐段 @，道具句带「枪托后段／火绳夹／通条」等辨识要素。mid/last 关键帧机位（中景／中远景平视固定）、构图三分区、光线方向、四肢状态齐全，收尾「16:9 横构图电影感剧照，单帧静态画面」双保险，与 contact sheet 第 5/6 格渲染结果吻合；设计卡 gen_plan.mid/last 的每个动作点（右手提枪托、左手扶船舷／舵桨、皮靴可见、跳板登船）全部落地。全片泊船状态一致，无运动逻辑矛盾。
- 硬伤：**时间轴**。分段 0-1/1-4/4-7.5/7.5-11 总和 11 秒，违反「总时长以提交时长为准」（提交时长 = gen_s 6.5 秒，实渲也只有 7.29 秒）；mid_frame_time=7.5 落在提交时长之外，违反「mid_frame_time 落在生成段内」，实渲时会被钳到末帧附近、与尾帧引导打架。且 7.5 处分段开头是「切到……站在最前那艘平底船的船尾横板上」= 尾帧构图，而 mid_frame_prompt 写的是「立在木栈桥端头」，违反「该段开头画面与 mid_frame_prompt 一致」——注入的中间帧引导图（码头）会与文本（船队）直接冲突。
- 共同风险（不分胜负）：参考图第 4 格是燧发式短铳，而两份都写「火绳夹」（火绳枪部件），道具层面与图不符；群演「灰褐粗呢短衣、灰毡帽」服色描写系设计卡原文带入、针对无参考图的群演，可接受。

**Y**
- 优点：关键帧与 X 几乎同源，质量相当；衔接段「镜头极缓推近，画面无人」同样合规；新增「10-11秒……镜头停稳」给尾帧一个干净的落点；试图把「叶尔马克从栈桥移步上船」演出来而非靠切镜瞬移，叙事意识更强。
- 硬伤一（@ 引用／信息头）：第一行只有「场景：@索利卡姆斯克；道具：@哥萨克火枪。」——**漏列出场人物 @叶尔马克·齐莫菲叶维奇**，违反「第一行是信息头（出场人物与场景）」；正文虽有 @，信息头残缺仍是格式性缺陷。
- 硬伤二（运动逻辑，7.5-10 段）：「双手各握一支木桨的桨柄向后拉、桨叶斜插入水中，船身在水面拖出细碎的浅色尾迹」——船在走，同段却还有「岸上的哥萨克队伍……依次踏上跳板登船」（对着行进中的船搭跳板），且 10-11 段又回到「船队已泊成一列」、尾帧关键帧是「桨柄停在胸前」：泊→划→泊的倒车式连续性矛盾，这个划桨动作设计卡里也没有，会诱发模型画面抽搐。
- 硬伤三（与 X 共享）：时间轴总和 11 秒 ≠ 提交时长 6.5 秒；mid_frame_time=7.5 超出生成段；7.5 处开头「已从栈桥端头移步到……船尾横板前」亦不等于 mid_frame_prompt 的码头画面。
- 小缺：mid/last 结尾缺「单帧静态画面」类收束标签，last 对岸上登船者细节删减较多。

## 取舍

**胜者：X。** 两份共享继承自生产参数的时间轴/中间帧硬伤，但 X 信息头完整、全片运动逻辑自洽、关键帧更自足，Y 多出信息头漏人和「边划桨边泊船边登船」的连续性矛盾，X 全面不劣于 Y。

若只用 X 的小修：把分段压回提交时长 6.5 秒（0-1 衔接复述 / 1-3.5 栈桥立像 / 3.5-5 队伍登船 / 5-6.5 切船队收束），mid_frame_time 改为 3.5 并让该段开头画面就是 mid 关键帧的「码头+登船」构图（或反过来把 mid_frame_prompt 改写成切镜后的船队画面），即可同时满足「总时长以提交时长为准」「mid 段起点画面一致」两条硬规则；其余文本可原样保留。
