## 逐份意见

**X**

优点：
- **设计卡落地最忠实**。mid 关键帧几乎逐句实现 gen_plan.mid（「一名哥萨克男子……背对镜头站在土屋门旁，右手提着一支 @哥萨克火枪 的枪托后段」），last 对应 gen_plan.last（院中持枪者 + 「牵着一匹驮货马停在路边」），ip5（骑队过缺口）放进 1-3 秒视频段——这正是 C 组合下「first 被衔接帧锁死、ip5 只能由视频段承担」的正确处理；ip6 的「扛捆包、卸到墙根」把"靠劫掠为生"变成了可拍的赃物动作，是全篇最好的信息点影像化。
- **中间帧对齐教科书式正确**：3-6 秒段起点恰在 mid_frame_time=3.0，且该段开头与 mid_frame_prompt 一致；末段收在尾帧画面。
- C 首段合规干净：「俯拍地图式全景……镜头静止，画面无人」，逐句复述 caption、1 秒收束、无切镜无 @角色。
- 四肢状态逐人写明（「双腿分开站稳、两只皮靴踩在夯土地面上可见」），道具带辨识要素（枪托后段/火绳夹/通条），合乎 limb_risk 与道具锚定规则。

硬伤：
1. **时间轴总长写错（维度 4）**：各段相加 11.5 秒 = 成片时长，而规则是「总时长以提交时长为准」，本镜提交时长 = gen_s 6.5 秒（实渲 7.29 秒）。「6-9秒」「9-11.5秒」两段在实际视频里不存在，且与代码注入的「尾帧在 ~6.5 秒结束」声明直接打架——这是把成片时间轴误当生成段时间轴。
2. **0-1 秒段漏 @哥萨克聚落（维度 2）**：「每个时间分段正文必须出现本分镜绑定的 @场景名」，开场转场段不豁免；X 该段一个 @ 都没有。
3. 小瑕疵：尾帧里「可被下一镜直接承接」是制作备注不是画面内容；「另有两人扛着的捆包摞在墙根」在单帧语境下有歧义（可能诱发画出两个扛包者）；群演服装颜色描写（「粗呢短袍、黑皮帽」）触碰图像优先的字面禁令（与 Y 同犯，无参考图的群演属情有可原）。

**Y**

优点：
- **@ 引用全篇最完整**：每一段（含 0-1 秒衔接段）都带「@哥萨克聚落」，道具逐段 @，信息头还交代了非资产群演（「出场人物：无名哥萨克男子（营地住户与骑队）」）。
- C 首段合规（「镜头极缓推近，画面无人」，规则允许"静止或极缓推"）。
- 叙事连贯性好：骑队过缺口 → 入院、院中人「抬头看向进院的骑队，眉骨压低、嘴唇抿平」→ 驮马赃物 → 全景收束，段与段之间有因果，比 X 的独立画卷更像连续事件。

硬伤：
1. **mid_frame_time 彻底失配（维度 4，最重）**：mid_frame_time=3.0，但分段是 0-1 / 1-4 / 4-7 / 7-9.5 / 9.5-11.5，**没有任何分段起点落在 3.0**，直接违反「必须有某个分段的起点正好落在该秒数，且该段开头画面与 mid_frame_prompt 一致」。3.0 秒处正值 1-4 段的「远景广角平视固定机位」骑队过缺口，而 Y 的 mid_frame_prompt 是「中景……骑队穿过缺口进入院内 + 院中男子张望」——景别、机位、人物构成全对不上；引导帧在第 3 秒注入时必然与提示词描述冲突，会出可见跳变。
2. **mid 关键帧偏离已确认设计卡（维度 1）**：gen_plan.mid 写明「一名哥萨克背对镜头站在门旁，右手提着一支火枪」，Y 整个换成「骑队入院 + 院中人双手垂侧张望」，把卡里 first 槽（已被衔接帧锁死）的内容挪来当 mid，又没相应改 mid_frame_time，属于未经设计卡授权的改写。
3. 同犯 X 的 11.5 秒总时长错误（硬伤 1 同源），以及群演服装颜色描写。
4. 小瑕疵：mid 帧一个「中景」里塞四骑 + 马匹 + 张望者，景别与元素量不匹配，出图易挤爆构图。

共同小瑕疵：附图 3 的 prop #260 外观是燧发式机构 + 药壶，两份都写「火绳夹」（火绳枪部件），道具辨识要素与资产图有打架风险。

## 取舍

**胜者：X。** 一句话结论：X 只犯了「把成片 11.5 秒当提交时长」这一处共性时间轴错误，设计卡与中间帧对齐全部正确；Y 在同一错误之上还丢了 mid_frame_time 切点、改写了已确认的 mid 画面，属双重硬伤。

若只能用 X，小修方案：① 把时间轴压回提交时长 6.5 秒——`0-1秒` 衔接复述不动，`1-3秒` 骑队过缺口，`3-6.5秒` 院内卸捆包并在段内切镜推进到全景收束（段内多镜头切镜合规），删除「6-9秒」「9-11.5秒」，全景收尾与 last_frame_prompt 保持一致；② 给 0-1 秒段补上「@哥萨克聚落」；③ 删掉尾帧里「可被下一镜直接承接」的元话术，把「两人扛着的捆包」改成「两个捆包摞在墙根」；④ 酌情把群演的「粗呢短袍、黑皮帽」等服色描写收敛为姿态与动作描写。
