## 逐份意见

**X**

优点：
- C 衔接规则执行得最干净：first 不写文案；第一段「0-1秒：俯拍全景式地图画面……镜头极缓推进，**画面无人**」逐句复述 caption（米黄底色、深褐直线、红色折线带箭头、留白方位全部命中附图 1），无切镜、无场景过渡、无 @角色，且显式写明无人，首段 1 秒 ≤1.5 秒，全部合规。
- 关键帧的 @ 与画面内容严格对齐：mid 只 @乌拉尔山口（自己的文本写明河谷在「**画外**东侧」，塔尔吉河营地确实不可见），last 只 @塔尔吉河营地。槽位绑定即参考图发送，这个取舍避免了把黄昏雪原营地参考图混进午后山脊帧（反之亦然），对出图纯净度是实打实的收益。
- mid/last 两帧机位（远景广角平视固定）、三层构图、四肢状态（「双腿分开站稳、两只皮靴踏在脊顶岩面上清晰可见」）、光线与「16:9 横构图电影感剧照，单帧静态画面」收尾齐全，完全自足；5.5 秒处「5.5-8.5秒：切到 @乌拉尔山口 的山脊顶端远景广角平视固定机位……」开头画面与 mid_frame_prompt 逐句一致，mid 对齐正确。
- 视觉叙事链（地图→登山道→山脊远眺→东坡下行初见河谷→扎营→黄昏定格）把「翻山口、抵河岸、扎营过冬」全部变成可拍镜头，尾段收束与 last 帧逐项吻合，可被引导帧稳定接住。

硬伤：
- **时间轴总长违规（与 Y 同犯）**：分段 0-1/1-4/4-5.5/5.5-8.5/8.5-11.5/11.5-14/14-16.5 合计 16.5 秒，而规则明文「总时长以提交时长为准」、本镜提交时长 = gen_s = **11 秒**。11.5 秒以后的两个营地段整体落在提交时长之外，意味着营地戏只能靠尾帧引导硬压进最后两三秒，节奏会被模型自行压缩。按 ceil(11/3) 应是 1 秒衔接段 + 4 个内容段。
- 小瑕：「4-5.5秒……固定机位，镜头随队伍向上推进」自相矛盾（固定机位却推进）；mid 的「长矛杆身上段、矛尾拄地」与设计卡「握杆身中段」有微小出入（Y 同文，属共同偏差）。

**Y**

优点：
- 主体文本与 X 同骨架，mid 对齐、衔接段复述、信息点 ip6/ip7 落地同样成立；gen_plan 槽位的场景列法（mid「@塔尔吉河营地 @乌拉尔山口」、last「@乌拉尔山口 @塔尔吉河营地」）**逐字照抄设计卡**，形式一致性最高；「1-4秒」补的「灰色岩块与**青苔**……几根倒伏的枯干」更贴附图 2 参考素材的苔石质感；「8.5-11.5秒」@塔尔吉河营地 并写「下部谷底露出河岸滩地」做了一次目的地预告，叙事意识好。

硬伤：
1. **@ 引用与画面可见性打架（维度 2/5 的主要失分）**：mid_frame_prompt 开头 @塔尔吉河营地，而同一条提示词里写「头转向**画外**东侧的更低山脊与河谷方向」——@ 了一个自己声明不在画内的场景，且排在首位（成为 image1），会把黄昏雪原营地参考图送进这张午后山脊帧；last 同理反向 @乌拉尔山口（帧内背景只有针叶林坡地与冰河，并无山口），两帧都在没有任何可见性短语支撑的情况下多绑了一张冲突参考图。照抄设计卡的列法不构成豁免——关键帧 @ 即绑定即发图。
2. **尾段编造元素破坏收束（维度 1/7）**：「14-16.5秒……一座**土屋的草顶冒着细淡的炊烟**」——last_frame_prompt 与参考素材 #183（帐篷 + 原木棚）里都没有土屋，视频末段画面与尾帧引导图对不上，恰恰发生在必须「收在尾帧画面」的位置。
3. 衔接段「0-1秒……镜头极缓推进。」少了「画面无人」的显式声明（实质未入人物，程序校验可过，但复述完整度弱于 X）。
4. 与 X 同犯 16.5 秒 vs 提交时长 11 秒的时间轴违规（见上）。

## 取舍

**胜者：X。** 两份同骨架、同犯「16.5 秒时间轴超出 11 秒提交时长」的硬伤，但 X 的关键帧 @ 与画面可见性严格一致、尾段与 last 帧干净收束，而 Y 把画外场景绑进关键帧参考图、又在末段编出土屋炊烟破坏尾帧收束——取更可直接投产的 X。

若只能用 X，小修一处即可：把视频提示词时间轴压回 11 秒——保留「0-1秒」衔接段不动，内容段改为 1-3.5（登山道）/ 3.5-5.5（逼近山口）/ 5.5-8.5（山脊远眺，mid 仍锚 5.5 秒）/ 8.5-11（东坡下行接黄昏扎营、末拍收在 last 帧构图），并顺手把「固定机位，镜头随队伍向上推进」改成「缓慢跟移」之类自洽的运镜写法。
