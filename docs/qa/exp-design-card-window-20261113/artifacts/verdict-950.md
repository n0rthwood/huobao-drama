## 排名与理由

**第一：W（8.5）**
对一段纯词义辨析旁白，组合 A + 15.5 秒图层段是最诚实的判断；三拍文字（0.3 / 4.5 / 10.8s）与配音节奏对位是四张中最准的，蒙古语一条恰好落在旁白转句处。对底图的构图描述经 sheet #1 逐项核对全部属实（房屋中左、上三分之一净空、右下空草地、无文字），右侧文字栈确实压得住；不设锚点与该场景无语义条目的事实一致，也没有伸手去抢 #19 的地理内容。缺点：rationale 被截断，承接 #17 生成段收尾的说法无法从材料证实；单底图三拍字幕的表现力中规中矩。

**第二：Z（7）**
组合 A 的判断与 W 同样正确，且「词义不涉地理、硬留地图会误导」的论证是四张中对本镜性质最清醒的一段；文字分两批 bullets + 10.2s keyword，与枚举和蒙古语句的时间轴对得不错，并正确识别 #266 无语义条目、不做任何无依据锚定。硬伤在底图视觉判断：sheet #4 里肖像面部就在画面上中部，选 h-center-top 还声称「不压面部」与原图直接矛盾，竖幅原件进横幅成片的留边问题也没交代；与前后镜（聚落→地图）之间是无论证的跳切。rationale 同样截断。

**第三：X（6）**
「前 11 秒讲清词义、末 4.5 秒给词义一个可看的人」是四张里最有镜头感的构思，生成段提示词具体可拍，参考资产（#172、#260）与附图相符，组合 C 也正确地不写被锁定的 first。但连续性推理建立在客观错误的镜序上：把 #21 当「上一镜」，引其旁白做承接依据——观众在 #18 时还没听到那句话，inherit_prev 的底图预期因此不可靠；此外 keyword 在 10.8s 入场而图层段 11s 即结束（只闪 0.2 秒），蒙古语涵义大半落在无字幕的生成段上，尾部声画错位。

**第四：Y（4）**
值得肯定的是所有锚点都用了资产清单里真实存在的语义条目、几何可画，容量核对也细。但问题是系统性的：把 #19 的「分布于东欧平原」编造成本镜旁白的层次，并用克里米亚／阿斯特拉罕／西伯利亚三个汗国版图冒充「哥萨克分布弧」——语义错配且剧透下一镜；全部文字挤进前 6.5 秒，蒙古语词条比配音提前约 7 秒；combo C 却给锁定槽写了 first，且图层段末帧是地图、生成段要落到聚落实拍，在「C 首段只能复述衔接帧、禁写转场」的规则下无法成立；date 框装非日期文本；「右侧条带无文字」与原图不符（喀什里克标注与右下示意说明框都在该区域）。

## 最终选择

只能用一张就用 **W**——它是唯一一张信息点、时间轴、资产事实与模板规则全部对得上、可以不返工直接进渲染管线的卡，其余三张各有至少一处必须重做的硬伤。
