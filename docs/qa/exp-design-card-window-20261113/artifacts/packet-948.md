按以下 7 个维度给每张卡打 1–10 分（10 = 专业纪录片导演可直接执行，1 = 无法使用）：

1. 信息点覆盖：是否覆盖旁白里观众必须 get 到的信息点，有无遗漏/编造。
2. 资产选择正确且可用：选的底图/参考资产是否真的画着它要表达的东西（对照 sheet.jpg）；证据素材是否被误当可重绘素材。
3. 组合与图层/生成段规划匹配：combo 与两段预算是否与内容相符（该用图层的用图层、该生成的有生成段）。
4. 文本框使用：text 模板框的角色/布局/字段是否符合模板规范，文字是否装得下旁白时长。
5. 与邻镜的连续性：是否承接上一镜已经让观众看到的东西（同一张地图/同一构图/同一图层状态），不重复也不跳。
6. 可执行性：图层锚点是否有真实语义、几何存在、能被图层段真正画出来；生成段的提示词方向是否可拍。
7. 视觉表现力：这一镜作为纪录片画面是否有想法、有层次，而不是把旁白抄成字幕。

然后给出：每张卡的 overall（1–10，加权综合）、三者排名（第一/第二/第三，允许并列但要说明）、每张卡 2–4 句最关键的优点与问题。最后用一句话说明「如果只能采用其中一张，你选哪张，为什么」。
