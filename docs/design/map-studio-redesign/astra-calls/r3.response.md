# MapGeoEditor 重写详设

## 1. 编辑器容器与层级

编辑器作为第三块「点线面核对与编辑」独立占满面板内容宽度，不与 AI 日志并排。仅设计编辑器内部，不改变主界面其他区块。

### 1.1 尺寸与伸缩

以下为**设计尺寸**，不是现有实现事实：

| 场景 | 编辑器尺寸与规则 |
|---|---|
| 1440×900 桌面、普通面板 | 内容宽度随面板，建议 1120–1360px；编辑器高度 720px，可随页面滚动 |
| 面板全屏 | 使用应用内全屏层，占视口减四边各 16px；不创建第二份草稿 |
| 小高度视口 | 高度不低于 520px；允许外层滚动，不把画布压成细条 |
| 独立窗口 | 本轮不做；避免两个窗口持有不同 revision、同时编辑同一草稿 |
| 全屏进出 | 保持当前 TAB、选择、草稿、视图中心和缩放级别；仅重新计算 fit 基准 |

垂直顺序固定：

```text
┌ 地点 12 [待核对 3] │ 线要素 8 │ 面要素 4      [+ 新增线要素] [全屏] ┐
│ 当前仅显示线要素 · 已隐藏 2 类几何（切换 TAB 查看）                  │
├───────────────────────────────────────────────────────────────────┤
│  底图 img + 当前类 SVG                                [+] [-]      │
│                                                      [重置] [适配] │
│                 选中顶点 ○ [删除顶点]                              │
│  当前：选择 / 平移                         局部编辑提示与完成工具条  │
├ 当前类条目列表                         [收起列表]                    ┤
│ 路线 A · 12 点 · 数据集几何 · 待核对       [继续编辑] [12 点]        │
│ 路线 B ·  8 点 · 人工几何                 [完成编辑] [8 点]         │
├ 经度 … 纬度 … │ 250% │ 已配准 · 投影摘要 │ 未保存                   ┤
└───────────────────────────────────────────────────────────────────┘
```

- TAB 与提示区约 76px，状态栏 32px；剩余高度默认按画布∶列表 **65∶35** 分配。
- 桌面画布最小 320px、列表最小 160px；分隔条可拖动，并支持键盘调整。
- 列表可收起为 40px 标题条，显示当前类数量、选中条目名、未提交编辑提示；再次展开恢复高度与滚动锚点。
- 全屏默认沿用比例，不自动折叠列表。
- 状态栏经纬度仅在光标位于有效底图且 registration 可用时显示；否则显示「—」及原因，不猜测映射。
- 缺底图时保留数值编辑和列表；画布空态：  
  **「底图尚未就绪；可先编辑坐标。」 / “The base map is not ready. You can edit coordinates first.”**

## 2. 三类 TAB：只绘制当前类

### 2.1 TAB 规格

| TAB | 内部类别 | 内容与新增动作 |
|---|---|---|
| 地点 | point | 名称、经度、纬度、删除、行级保存到草稿；「全部地点」；新增地点 |
| 线要素 | line | 名称、点数、来源与核对状态、平滑、继续/完成编辑、删除；新增线要素 |
| 面要素 | region | 同线要素，点数按不重复闭合端点计数；新增面要素 |

类别值是新 UI 状态枚举；现有 `msgeo` 的 kind 序列化保持兼容，通过适配层映射，不假定现有 kind 拼写。

- 数量徽标统计页面 `specDraft` 中该类要素；待核对徽标统计 `proposed===true`，文案为「待核对 N」。
- 新增按钮仅作用于当前类；不会新增其他类别。
- 未完成新形状尚未计入正式数量，另显示「绘制中 1」。
- 当前类空态仍显示其他 TAB 的数量，避免误认为数据丢失。
- 固定次级提示：  
  **「当前仅显示线要素 · 已隐藏 2 类几何（切换 TAB 查看）」**  
  **“Showing lines only · Geometry in 2 other categories is hidden. Switch tabs to view it.”**

### 2.2 TAB 切换确定行为

| 切换时状态 | 确定行为 |
|---|---|
| 已选中旧类别要素 | 暂存该类选择记忆；清空当前活动选择。返回该类时，实体仍存在则恢复 |
| 正在新增或继续编辑形状，有局部草稿 | 拦截切换，提供「完成编辑并切换 / 放弃局部改动并切换 / 留在当前类别」 |
| 局部草稿点数不足 | 禁用「完成编辑并切换」，显示点数要求；允许放弃或留下 |
| 无局部草稿，页面已有未保存几何 | 直接切换；页面 `specDraft` 保留，不 PUT |
| 平滑滑杆已有改动 | `layerOptionsDraft` 保留，不自动保存、不复原 |
| zoom/pan | 保留同一底图视图，不按类别重新 fit |
| 列表滚动 | 每类记忆首个可见条目 ID 与偏移；恢复时实体失效则回到顶部 |
| 点列表弹窗打开 | 模态阻止背景 TAB 操作；先保存到草稿或取消关闭 |

### 2.3 显隐实现契约与决策记录

- 底图 `<img>` 始终保留，切换 TAB 不卸载、不重新请求。
- SVG 几何层**只创建当前类别的要素、标签、把手和命中区域**。
- 其他类别不画、不参与命中、不进入画布可访问树；其数据继续保存在页面草稿中。
- TAB 数量和「已隐藏 2 类几何」共同提供隐藏确认。
- 不采用透明度降低、灰显或轮廓残影。**V12 要求不画，淡显仍会造成密点干扰，也违反类别隔离规则。**
- “底图保留”指纯底图；不得使用已烘焙任务点线面的成图充当编辑底图。

## 3. 画布 zoom/pan 与坐标契约

### 3.1 视图定义

- `zoom=1`：完整底图适配当前画布内容区。
- 范围：**1–16**；显示为 100%–1600%。
- 缩放围绕光标锚点；按钮缩放围绕画布中心。
- 持久化视图使用 **zoom + viewBox 中心坐标**，不保存依赖容器尺寸的屏幕 pan。
- 内部 pan 单位为 CSS px；底图与 SVG 几何共享同一变换。
- 把手与操作浮层在屏幕空间保持恒定尺寸。

### 3.2 交互规格

| 输入 | 行为 | 写入几何 |
|---|---|---|
| 滚轮 | 向上乘 1.2、向下除 1.2；高精度滚轮按归一化量连续插值；clamp 1–16；光标下位置保持不动 | 否 |
| 双击空白 | 不缩放、不完成形状、不删除 | 否 |
| select 模式空白拖拽 | 平移；鼠标位移超过 4 CSS px、触摸/笔超过 8px 后进入拖动 | 否 |
| 顶点把手拖拽 | 移动选中顶点；pointer capture；只操作命中顶点 | 提交时 |
| 线/面本体点击 | 选择该要素；不移动整条线或整块面 | 否 |
| 按住空格拖拽 | 临时平移，优先于绘制；输入框获得焦点时无效 | 否 |
| `+` / `−` 按钮 | 每次乘/除 1.2 | 否 |
| 重置视图 / `0` | zoom=1，中心回到底图中心 | 否 |
| 适配视图 | 适配当前选中要素；未选中则适配当前类全部要素；无要素则适配底图；留 24px 边距 | 否 |
| 第二个触点加入 | 不新增顶点、不提交拖点；取消当前未提交指针编辑。本轮不做双指缩放 | 否 |

滚轮仅在画布拥有交互焦点时截获；未激活时允许页面滚动，提示「点击画布后滚轮缩放」。

无 registration 时允许查看底图的 zoom/pan，但禁用画布新增、拖点和中点插入；仍可数值编辑和显式删除。提示：

> **未配准：无法从画布位置确定经纬度，请使用坐标输入。**  
> **Not registered: coordinates cannot be determined from the canvas. Use coordinate inputs.**

### 3.3 三级坐标换算：无代码实现规范

#### 第一级：屏幕像素 → 画布像素

1. 指针位置统一为 CSS 像素。浏览器 pointer 的 client 坐标本身已是 CSS px，不再乘除 DPR。
2. 若输入来源是截图或物理像素，先除以 DPR；例如 DPR=2 的物理位置 `(800,600)` 对应 CSS 位置 `(400,300)`。
3. 减去画布在视口中的位置、边框和 padding，得到内容区坐标。
4. 使用底图的**实际布局内容区**，不把元素外框或自然尺寸误当渲染尺寸。测量未施加 zoom 的布局尺寸，避免重复消除变换。

#### 第二级：画布像素 → viewBox

顺序固定：

1. 撤销外层平移。
2. 围绕约定变换原点撤销 zoom。
3. 撤销 `xMidYMid meet` 产生的左右或上下信箱边距。
4. 除以底图适配比例，得到以底图自然像素为单位的 viewBox 坐标。

底图与 SVG 必须使用相同内容矩形、居中规则和变换原点。信箱区不是地理编辑区。

#### 第三级：viewBox → 经纬度

- 使用当前底图对应 registration 的反投影，将 viewBox 坐标转换为经纬度。
- 不以 bbox 的线性插值代替 registration。
- 无 registration、反投影失败或结果非有限值：不提交几何，显示可读错误。
- 拖点越出有效图像矩形时夹到图像边界并显示「已到达底图边界」，不向信箱区域外推经纬度。

#### 数值示例

条件：

- 底图与 viewBox：2048×1280。
- 画布内容区：900×620 CSS px；本例 padding、边框、视口偏移均已扣除。
- 变换原点：内容区中心 `(450,310)`。
- zoom=2.5；pan=`(120,-80)`，定义为缩放之后的屏幕空间平移。
- 光标内容区坐标：`(400,300)`。

| 步骤 | 计算含义 | 结果 |
|---|---|---|
| 适配比例 | 900/2048 与 620/1280 取较小值 | 0.439453125 |
| 实际底图尺寸 | 自然尺寸乘适配比例 | 900×562.5 |
| meet 边距 | 剩余宽高各平分 | 左 0，上 28.75 |
| 撤销 pan | 光标减去平移 | `(280,380)` |
| 撤销 zoom | 相对中心的位移除以 2.5，再加回中心 | `(382,338)` |
| 撤销信箱边距 | 减去左、上边距 | `(382,309.25)` |
| 换成 viewBox | 两坐标分别除以 0.439453125 | **`(869.2622,703.7156)`** |

最后将该 viewBox 点交给 registration 反投影。题目未提供 registration，不能据此编造经纬度；行为测试使用有已知逆映射的 registration fixture。

### 3.4 命中测试

| 目标 | 视觉与命中规则 |
|---|---|
| 顶点 | 视觉半径固定 6 CSS px；透明命中区域至少 44×44px |
| 中点 | 仅显示选中边的中点；鼠标靠近边或键盘选择该边时出现，不再铺满所有边；命中区至少 44×44px |
| 线本体 | 透明命中走廊宽至少 44px；只选择，不拖动整线 |
| 面本体 | 内部可选择；小面用扩大的屏幕命中区辅助选择 |
| 底图空白 | 没有更高优先级目标时触发平移或当前绘制工具 |
| 多个把手重叠 | 视觉实体命中优先；再比较屏幕距离。候选过密时打开「选择顶点」候选列表，不任意拖第一个 |
| 缩放很小、点很密 | 不改变几何；限制辅助把手展示，保留点列表逐行定位与「适配选中」 |
| 触摸/笔 | 使用相同语义和最小命中尺寸；不依赖 hover 才能访问动作 |

优先级：操作浮层 → 顶点 → 中点 → 线/面本体 → 空白。扩大区域重叠时必须消歧，不能靠 SVG DOM 顺序决定。

### 3.5 零写入守卫与吸附取舍

- `pan`、`zoom`、`select` 手势只更新视图状态；不得调用 `cloneSpec`、`markManual`、`emit('update')` 或 PUT。
- 只有 `moveVertex`、`insertVertex`、数值提交、删点等几何事务可以进入更新通道。
- pointercancel、Esc、未达到拖动阈值、最终坐标等于原值：不提交、不转人工、不置脏。
- 本轮**不做跨要素吸附**：隐藏类别不能成为看不见的吸附目标，已知要素也未必足够精确。保留自由拖动与数值输入。

## 4. 删点

### 4.1 三种入口

| 入口 | 规格 |
|---|---|
| 显式删除 | 选中顶点旁显示 44×44px 浮层按钮；靠近边缘时向内翻转，避免遮挡顶点；条目展开区同步提供「删除选中顶点」 |
| Delete / Backspace | 仅编辑器拥有焦点、选中了顶点且焦点不在文本输入或可编辑区域时生效；阻止浏览器默认行为 |
| 双击顶点 | 保留兼容，仅 select 模式生效；等同一次显式删除 |

删除按钮默认中性描边，hover/focus 为浅红背景和深红图标；不可只靠红色表达含义。可键盘聚焦，`aria-label` 包含要素名及顶点序号，例如「删除路线 A 的第 4 个顶点」。

双击冲突处理：

- pointerdown 只选择并建立候选拖动，不立即写入。
- 两次点击均未越过拖动阈值、目标为同一顶点，才允许 dblclick 删除。
- 发生实际拖动后取消双击删除资格，避免拖完又误删。
- 双击删除一个事务，只 emit 一次，不以可变数组下标重复执行。
- 地点使用「删除地点」，不称为删除顶点，也不通过双击隐式删除。

### 4.2 下限与写入

- 线删除后至少 2 个顶点；面至少 3 个不同顶点。闭合端点不作为独立可删行。
- 拒绝删除时保留原值、原选择，不 emit：
  - **「线要素至少需要 2 个点；如需移除，请删除整个要素。」**  
    “A line needs at least 2 vertices. Delete the feature to remove it.”
  - **「面要素至少需要 3 个点；如需移除，请删除整个要素。」**  
    “A polygon needs at least 3 vertices. Delete the feature to remove it.”
- 行内错误与 `role=alert` toast 同时出现，不能静默。
- 删点永不自动转为删要素。显式「删除要素」可以删除该类最后一个要素，随后显示空态。
- 活动形状中的删点只更新局部草稿；完成编辑后写入页面草稿。非活动形状删点直接进入统一草稿更新通道。
- SVG 立即反映工作草稿；页面「保存修改」成功前始终显示「未保存」，不称为服务端保存成功。

## 5. 点列表弹窗与地点逐条编辑

### 5.1 同组件、不同列配置

| 场景 | 入口与标题 | 表格列 |
|---|---|---|
| 线/面顶点 | 条目内「N 点」；「路线 A · 线要素 · 顶点」 | 序号、经度、纬度、删除 |
| 全部地点 | 地点 TAB「全部地点」；「全部地点 · N 个」 | 序号、名称、经度、纬度、删除 |

- 桌面宽 760px、最大不超过视口减 32px；最大高度 80vh；小屏改为全屏模态。
- 固定表头和底部按钮：「保存到草稿 / 取消」。
- 本轮不做批量删除，避免误删和增加确认分支。
- 输入保留用户正在键入的文本；允许输入中的负号、小数点暂态，不在每次 input 时强行数字化。
- 保存前校验有限数、经纬度合法范围和点数下限；无效单元格标红并聚焦第一处错误。
- 不静默截断既有坐标精度；地图 preview 使用解析后的有效值。

地点主列表具备同等能力：每条名称、经纬度输入、删除、**保存到草稿**、取消。其保存不要求打开弹窗，单独覆盖 V11 验收。

### 5.2 统一编辑语义

采用三层状态，避免“保存”双写：

| 层级 | 持有者 | 行为 |
|---|---|---|
| 局部工作副本 | 当前输入行、弹窗或活动形状 | 改格、拖动时更新；可取消；不发 PUT |
| 页面草稿 | 页面 `specDraft` / `layerOptionsDraft` | 接收编辑器提交；SVG 更新；页面标脏 |
| 服务端快照 | 页面最近一次已接受的 detail/revision | 仅页面显式保存通过 CAS PUT 更新 |

共同通道：

**局部有效编辑 → cloneSpec → markManual → emit('update') → 页面 specDraft → 页面保存 PUT(expectedRevision)。**

- 弹窗每次 input 改局部工作副本；「保存到草稿」一次性 emit，取消完全丢弃。
- 独立拖点在 pointerup 提交；活动形状内拖点归入该形状，直到「完成编辑」统一提交。
- 选择批量提交而非逐 input emit：取消可预测，避免半输入坐标进入页面草稿，避免反复标人工。
- `markManual` 仅应用到实际变更要素；打开、选中、无改动保存不转人工。
- 弹窗保存按钮**不 PUT**。页面按钮标「保存修改」，是唯一持久化入口。
- 存在未收尾局部工作副本时，页面保存引导先完成/保存到草稿或取消，不悄悄漏存。

保存到草稿后提示：

> **已更新编辑预览，尚未保存。保存修改后，如需更新成图，请显式重新渲染。**  
> **Editing preview updated; changes are not saved yet. Save changes, then explicitly re-render to update the rendered image.**

### 5.3 弹窗、视图与规模

- 弹窗打开时画布 inert，暂停画布快捷键；关闭恢复原 zoom/pan。
- 从活动形状进入弹窗前必须先完成或取消形状，避免两个并行局部副本。
- 保存或取消后焦点返回原「N 点」或「全部地点」按钮；实体被删除时回到 TAB 内列表标题。
- 使用 **50 行分页**，不采用容易破坏表格读屏语义的虚拟行。
- 地点提供名称搜索；顶点提供「跳到第 N 点」。搜索不改变原始序号。
- 分页间保留所有局部修改和错误；有其他页错误时显示错误数并提供跳转。
- 极端数量时只挂载当前页输入控件；不可为提速静默抽稀真实顶点。画布性能预算需在实施阶段用真实密点样本测量。

深链恢复仅打开对应弹窗并定位行，不创建编辑、不 emit。行失效则打开要素级弹窗并提示「该顶点已不存在，已打开要素点列表」；要素失效则关闭弹窗并回到对应 TAB。

## 6. 条目内「完成编辑 / 继续编辑」

### 6.1 状态机

| 状态 | 条目按钮 | 点击结果 |
|---|---|---|
| 未在编辑，无页面改动 | 继续编辑 / Continue editing | 创建该要素局部工作副本，进入顶点编辑 |
| 未在编辑，有页面未保存改动 | 继续编辑 +「未保存」 | 从页面草稿继续，不回到服务端旧值 |
| 当前条目正在编辑且有效 | 完成编辑 / Finish editing；取消编辑 | 完成：提交局部副本、退出该形状编辑；取消：恢复编辑前页面草稿 |
| 当前条目正在编辑且点数不足 | 完成编辑禁用；取消编辑可用 | 显示缺少点数，不提交 |
| 另一个条目正在编辑 | 继续编辑 | 先处理旧草稿：完成、放弃、留下 |
| 完成后等待页面保存 | 继续编辑 +「未保存」 | 不伪装成已保存或已确认 |

新形状在列表顶部以临时条目呈现，也有「完成编辑」按钮；不只依赖顶部工具条。

### 6.2 职责分离

- 条目内「完成编辑」：收尾**该形状**，提交到页面草稿。
- 顶部「完成并退出编辑」：收尾当前活动草稿并回到 select；本轮同时最多一个活动形状。
- 顶部「取消当前编辑」：仅丢弃局部工作副本，不清空页面其他未保存修改。
- 无活动形状时，顶部不显示空的「完成（0 点）」。

固定旁注：

> **完成编辑只结束本次修改，不代表你已核对并确认几何。**  
> **Finishing an edit does not mean you have reviewed and confirmed the geometry.**

服务端保存坐标修改后可能设置 `verification=confirmed`、删除 `proposed`。这是既有存储行为，不能据此声称用户点击过「确认几何」，也不能让「完成编辑」自动触发作图。当前服务端未确认几何不阻塞 drawing；本设计不改变闸门。

### 6.3 数据集要素

继续编辑前显示非阻断说明：

> **来自数据集的几何；实际改动并提交到草稿后将转为人工几何。**  
> **This geometry comes from a dataset. Committing changes to the draft will make it manual geometry.**

不弹重复确认框。无改动完成或取消保留来源；实际几何修改沿 `markManual` 通道处理，删除 `dataset_ref` 的行为与现有保存语义保持一致。

## 7. 平滑偏离警告

现状为整数展示造成「偏离 18px / 上限 18px」难以理解，非数据集要素默认强度为 1，提示又只有「调到 0.95 以下或关闭」。

### 7.1 新呈现

保留既有默认值，不在加载、恢复或校验时自动降低强度。

```text
⚠ 平滑曲线偏离原走势
  第 3 段   偏离 18.4px / 上限 18.0px   建议强度 0.85
  第 8 段   偏离 22.1px / 上限 19.2px   建议强度 0.70

  [一键降到建议强度（0.70）] [关闭平滑]
  强度越高曲线越平滑，但偏离原走势越多。
```

- 每个 `deviationProblems` 项一行：段号、偏离、上限、该段建议强度。
- px 指渲染几何使用的图像像素，**不是屏幕 CSS px**；zoom 不改变告警判定。
- 偏离和上限各保留一位小数；比较使用未舍入值。
- 舍入后相同仍超限：例如  
  **「18.0px（超限）/ 18.0px」**，可聚焦详情显示 `18.03 / 17.98`。
- 普通超限也可显示 **「18.4px（超限）/ 18.0px」**；精确详情示例 `18.43 / 17.98`。详情不只依赖鼠标 hover。

### 7.2 建议值与按钮

- 采用既有算法：14 步二分寻找偏离不超过上限的最大强度，向下取 0.05 档，小于 0.05 归 0。
- 同一滑杆控制多个段时，主按钮采用各超限段建议值的最小值，不能任选一段；点击后检查完整曲线。
- 建议值大于 0：显示「一键降到建议强度（S）」和「关闭平滑」。
- 建议值为 0：**只显示「关闭平滑」**，不显示「降到 0.00」的重复按钮。
- 说明：  
  **「这条曲线在 0.05 的力度下也会超出容差，只能关闭平滑来保持原走势。」**  
  **“This curve still exceeds the allowed deviation at strength 0.05. Turn smoothing off to preserve its original path.”**
- 按钮是人的显式动作。写入 `layerOptionsDraft`，页面保存才 PUT；服务端不自动改强度。
- 点击后前端立即使用同一 `smooth.js` 对当前草稿重新计算 `deviationProblems`。不得直接清空警告数组。
- 若仍有超限段，保留剩余条目与实际数值，不宣称修复成功。
- 无法复算时显示「无法验证平滑预览，未确认偏离已消除」，保留告警，不伪造成功。
- 缺尺寸或 registration、无法生成同口径像素几何时，禁用建议强度计算并说明原因；不以屏幕像素替代。

### 7.3 中英文文案族

| 用途 | 中文 | English |
|---|---|---|
| 标题 | 平滑曲线偏离原走势 | Smoothing moves the curve away from its original path |
| 段描述 | 第 {n} 段：偏离 {d}px，上限 {l}px；建议强度 {s} | Segment {n}: deviation {d}px, limit {l}px; suggested strength {s} |
| 降强度 | 一键降到建议强度（{s}） | Reduce to suggested strength ({s}) |
| 关闭 | 关闭平滑 | Turn smoothing off |
| 复算通过 | 偏离已回到允许范围；修改尚未保存 | Deviation is within the allowed range. Changes are not saved yet |
| 仍超限 | 仍有 {n} 段偏离过大，请查看下方明细 | {n} segments still deviate too far. Review the details below |
| 滑杆说明 | 强度越高曲线越平滑，但偏离原走势越多 | Higher strength makes the curve smoother but moves it farther from its original path |
| 超限标记 | 超限 | Over limit |

### 7.4 可理解的小示意

```text
                 平滑后的曲线
               ╭────────╮
原始折线  ──────●        ●──────
                ↕ 最大偏离
```

配文：

> **平滑会把折线弯成曲线；这里检查曲线离你原来画的路线最远有多远。**  
> **Smoothing bends the original path into a curve. This checks how far the curve moves away from that path.**

正式图例采用原始折线灰色虚线、平滑曲线实线及带文字的距离标注，不只用颜色区分。

### 9.2 焦点与读屏

- TAB 使用 `tablist/tab/tabpanel`、`aria-selected`、roving tabindex。
- 画布是可聚焦交互区域，有名称、当前工具和操作说明；不为每个密集 SVG 顶点强制建立焦点序列。

- 通过列表选中顶点时，画布显示高亮；用户可显式选择「适配选中」，不自动跳动视图。

- 弹窗限制焦点循环，背景 inert，关闭归还焦点。
- 光标经纬度不逐帧 aria-live 播报；保存成功用 polite，删除拒绝和保存失败用 alert。
- 图标按钮必须有名称；禁用动作关联具体原因。
- 错误、脏状态、来源、proposed、已确认均有文字，不仅依赖颜色。

### 10.1 页面拥有唯一持久草稿

页面持有：

- `specDraft`、`layerOptionsDraft`；
- 最近已接受的服务端快照及 `revision`；
- `dirty`、`saving`、保存错误、冲突恢复副本。

编辑器内部持有：

- 局部未提交工作副本；
- zoom、中心、当前选择、TAB、弹窗等 UI 状态；
- UI 状态可同步 URL，坐标草稿不得写入 URL。

### 10.2 CAS 与回滚

- 页面保存带当前接受快照的 `expectedRevision`；保存期间锁定编辑，避免响应覆盖保存后的新改动。
- 成功：以服务端返回或随后读取的权威状态建立新基线，清脏标记，提示「修改已保存」。
- 普通拒绝：关闭局部事务，将活动页面草稿与预览回滚到最近接受快照；失败内容放入独立恢复副本，不继续作为有效草稿展示。
- 409：停止提交，隔离本地失败副本，获取最新 detail 后用最新服务端状态恢复编辑器；**不得自动把旧副本覆盖到新 revision**。
- 获取最新状态失败时保持编辑锁定，显示「冲突后无法读取最新版本，请重试读取」，不以旧 revision 继续保存。
- 现有 keep/discard 入口保留，但 keep 仅保留可比较的恢复副本，不表示已保存；重新应用必须是用户检查后的新操作。
- 失败文案：  
  **「保存失败，编辑预览已回滚；未保存内容已保留供检查。」**  
  **“Saving failed. The editing preview was rolled back; unsaved changes are retained for review.”**

### 10.3 Undo/redo 与迁移顺序

本轮不新增全局 undo/redo：局部取消、页面放弃、冲突恢复覆盖基本撤销需求；不引入跨 revision 的隐式重放。原生输入框撤销保留。

迁移顺序：

1. 固定统一编辑事务和页面 CAS 契约；先明确旧 `commitDraft` 与 `update` 的职责。
2. 抽离 `MapFeatureMeta`、`MapSmoothWarning`，保持来源与算法口径。
3. 抽离 `MapEditorList` 和共用 `MapPointListDialog`，先接通地点与顶点两类写入。
4. 抽离 `MapEditorCanvas`，保留 `eventGeo` 已有 meet 处理，外加共享 zoom/pan 逆变换。
5. 引入 `MapEditorShell`，落地类别只绘制当前类、单活动形状及切换拦截。
6. 接入深链和条目完成动作，迁移所有 `MapGeoEditor` 调用；移除旧全类绘制、全局唯一完成入口及旧比例把手逻辑，不保留双通道。

| `msgfull` | `1 / 0` | 应用内全屏；不触发浏览器权限请求 |
| `msglist` | `open / collapsed` | 恢复列表折叠 |
| `msgsplit` | 画布比例 0.5–0.8 | clamp，并服从最小高度 |
| `msganchor` | 各类条目 ID 与偏移的编码值 | 恢复滚动；失效回该类顶部 |
| `msgpage`、`msgfilter` | 弹窗页码、地点筛选文本 | 页码夹到有效页；显式行定位优先 |

优先级：有效点列表弹窗目标 → 有效 `msgeo` 类别 → 显式 TAB → 地点默认值。冲突键仅规范化 URL，并给一次可读提示，不触发业务写入。

- zoom/pan URL 更新在手势结束后节流 replace，不为每帧添加浏览历史。
- 关闭弹窗只清弹窗相关键；不清视图、选择及其他页面深链域。
- 用户通过浏览器前进/后退请求切换、有局部未完成编辑时，执行同样的完成/放弃/留下仲裁，不静默丢弃。
- 初次深链恢复不创建未保存草稿。
- 纠正文案：  
  **「链接中的缩放值超出范围，已调整为 {zoom}%。」**  
  **“The linked zoom value was out of range and was adjusted to {zoom}%.”**
