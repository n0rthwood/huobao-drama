# 第 1 轮产出：信息架构、结果优先主界面、成图快照、AI 活动抽屉、深链与组件分解

你现在做 Issue #126 阶段 0 的**第一份设计**：整体信息架构与主界面布局。约束与事实见随附 `facts.md`（第 0-5 节），必须遵守，尤其是第 4 节的结构性张力与 v2 条款 V1-V5/V13-V16/V28-V33。

## 设计立场（用户已定，不可改）

- 界面按「人的工作流 + 注意力」组织：资产信息 → 一键检索 → 底图就绪 → 核对/编辑点线面 → 渲染出图。过程信息（agent 逐轮、调用、观测对话、历史运行）默认不可见，收进「AI 活动」抽屉。
- 主界面必须始终回答三个问题：**这是哪张地图**（资产/需求）、**现在有没有成图、处在哪一版**（成图主视图 + 阶段/状态）、**我下一步要做什么**（唯一主动作）。
- 结果优先：成图占据最大视觉权重；编辑器占第二；表单与列表退到次要位置。
- 这是内嵌在宿主（剧集资产）弹窗里的面板：顶栏只有一条（宿主身份 + 阶段/状态 + AI 活动 + 更多菜单），不重复堆砌 chip。
