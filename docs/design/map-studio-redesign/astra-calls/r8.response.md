## 1. 编辑器容器与层级

编辑器作为第三块「点线面核对与编辑」，不与 AI 日志并排。普通布局就提供完整编辑能力，不以进入专注模式为前提。

### 1.1 尺寸与伸缩

以下比例为**设计尺寸**，不是现有实现事实；按内容区可用高度分配，视口不足时允许滚动，不压缩必要操作。

| 工作阶段 | 普通默认布局 | 编辑器内部 |
|---|---|---|
| base 就绪、几何待核对、待启动作图 | ③点线面核对最大，约 55%；②约 22%，保留图片身份摘要与展开大图入口 | 画布与当前类列表左右约 62∶38；窄屏上下排列 |
| drawing 完成、complete 待交付、已完成 | ②成图复核最大，约 52%；③收为可展开条带 | 展开即可完整编辑，不要求进入专注模式 |
| 正在编辑时阶段刷新 | 不抢走焦点、不自动收起编辑器 | 保留同一页面草稿、选择及视图 |

删除「普通编辑器约 270px」作为主常态的取舍。普通编辑布局必须可见：

- 地点名称、经度、纬度、真实来源说明、待核对状态、删除地点及「全部地点」入口。
- 线/面名称、点数、来源与核对状态、「点列表」「继续编辑」「完成编辑」、删除要素。
- 选中顶点的可见删除动作、平滑告警明细与建议强度/关闭动作。
- 页面「保存几何 / Save geometry」及未保存状态，不将这些操作藏入专注模式。

长列表可内部滚动；所选条目的操作及告警可展开，不能只靠 hover 访问。

### 1.2 专注模式

「放大编辑 / Enlarge editor」仅是增强：保留图片身份摘要，编辑器使用剩余空间，画布在上、列表在下，默认约 65∶35。720px 是可用高度示例，不是普通布局默认高度。

```text
┌ 地点 │ 线要素 │ 面要素    [新增当前类] [放大编辑] ┐
│ 当前仅显示线要素 · 已隐藏另两类几何              │
├ 底图 + 当前类 SVG             [+] [−] [重置]     ┤
│ [选择] [绘制] [平移]          [适配选中]         │
│ 选中顶点：[删除]  选中边：[插入顶点]             │
├ 当前类列表                                     ┤
│ 名称 · 来源 · 核对状态 · N 点 [点列表]           │
│ [继续编辑] [完成编辑] [取消当前形状]             │
│ 平滑告警明细 [采用建议强度] [关闭平滑]           │
├ 已加入待保存草稿                 [保存几何]     ┤
└────────────────────────────────────────────────┘
```

- 专注模式画布最小 320px、列表最小 160px；视口不足时滚动。分隔条支持拖动和键盘调整。
- 收起列表后保留数量、选中条目名及未保存提示；再次展开恢复本地滚动位置。
- 退出恢复普通阶段布局及同一份草稿、选择、zoom/中心；焦点返回「放大编辑」按钮。
- 状态栏经纬度仅在 registration 可用且指针位于有效底图时显示，否则显示原因，不猜映射。
- 缺底图时仍可使用列表数值编辑：  
  **「底图尚未就绪；可先编辑坐标。」 / “The base map is not ready. You can edit coordinates first.”**

## 2. 三类 TAB：只绘制当前类

### 2.1 TAB 规格

| TAB | 内部类别 | 内容与新增动作 |
|---|---|---|
| 地点 | point | 名称、经度、纬度、来源、核对状态、删除；全部地点；新增地点 |
| 线要素 | line | 名称、点数、来源、核对状态、平滑、点列表、继续/完成编辑、删除；新增线要素 |
| 面要素 | region | 同线要素；闭合端点不重复计数；新增面要素 |

类别值是拟议 UI 枚举；既有 `msgeo` kind 编码保持兼容，通过适配层映射。

- 有效地点行/弹窗编辑立即进入唯一页面 `specDraft`，标 **「已加入待保存草稿 / Added to unsaved draft」**；无「保存到草稿」按钮。
- 数量取页面 `specDraft`；未达到下限的新形状不计入正式数量，另显示「绘制中 1 / 1 shape in progress」。
- 待核对数量统一采用 `geometryUnverified`：`dataset_missing` 一律计入；其余为 `proposed===true` 且非 manual/verified/confirmed。依据 `accuracy.ts:88-95`。
- 既有 UI 仅数 `proposed===true` 的徽标口径与上述不同，本 Issue 必须统一；刷新后从服务端事实重算，不依赖浏览器整体复核标记。
- 新增仅作用于当前类；空类仍保留其他 TAB 数量。
- 固定提示：  
  **「当前仅显示线要素 · 已隐藏 2 类几何（切换 TAB 查看）」**  
  **“Showing lines only · Geometry in 2 other categories is hidden. Switch tabs to view it.”**

### 2.2 TAB 切换

| 状态 | 行为 |
|---|---|
| 已选中旧类要素 | 记忆该类选择；返回时仅恢复仍有效的实体 |
| 有活动形状局部事务 | 提供「完成编辑并切换 / Finish and switch」「取消当前形状并切换 / Cancel shape and switch」「留在当前类别 / Stay」 |
| 新形状未达线 ≥2、面 ≥3 个不同顶点 | 禁用完成并说明下限；允许追加、取消或留下 |
| 仅有地点/弹窗输入半成品 | 提示修正或丢弃该输入缓冲；已生效的页面草稿不回滚 |
| 页面几何或平滑选项已脏 | 直接切换并保留全部草稿，零 PUT |
| 点列表模态打开 | 背景不可操作；先关闭模态，不要求再次提交 |
| zoom/中心、列表滚动 | 保留同底图视图与每类本地滚动记忆；失效锚点回列表顶部 |

### 2.3 显隐契约

- 底图持续保留，必须是纯底图，不能使用烘焙了任务几何的成图。
- SVG 仅创建当前类的要素、标签、把手及命中区域。
- 其他类不画、不参与命中、不进入画布可访问树，但仍在同一页面草稿中。
- 不以灰显、透明度降低或残影替代 V12 的「不画」。
- 切换、选择、恢复均不保存；页面「保存几何」会提交所有类别的全部有效脏条目，不存在保存 A 而 B 仍脏的粒度。

## 3. 画布 zoom/pan 与坐标契约

### 3.1 视图定义

- zoom=1 为完整底图适配内容区，范围 1–16。
- 指针缩放围绕指针；按钮缩放围绕画布中心。
- 可恢复视图保存 zoom 与 viewBox 归一化中心，不保存依赖容器尺寸的屏幕 pan。
- 内部 pan 单位为 CSS px；底图和 SVG 共用内容矩形与变换。
- 把手及操作浮层保持恒定屏幕尺寸。

### 3.2 完整输入路径与焦点

| 输入/动作 | 行为 | 动作后焦点 |
|---|---|---|
| 鼠标滚轮 | 画布聚焦时乘/除 1.2，高精度滚轮连续归一化；clamp 1–16；未聚焦时滚动页面 | 画布 |
| 工具按钮 | 鼠标、触摸、笔、键盘均可选「选择 / Select」「绘制 / Draw」「平移 / Pan」 | 激活按钮；下一 Tab 可进入画布或坐标表 |
| 选择要素 | 点选当前类几何，或点按列表「选择」 | 画布入口或触发的列表按钮 |
| 选择顶点/边 | 点按把手/边；或打开点列表，使用顶点行、边列表的选择按钮 | 相应选择按钮；画布触发则画布入口 |
| 候选重叠 | 打开包含要素名、顶点/边序号的候选列表，每项有「选择 / Select」按钮；不依 DOM 顺序选第一个 | 打开后首个候选；选定/取消后回触发入口 |
| 插入顶点 | 选边后显示「在所选边插点 / Insert on selected edge」；按钮默认取相邻经纬度中点，也可输入合法坐标；无需 hover | 新顶点的经度输入 |
| 新建并追加 | 当前类新增按钮创建地点输入或未完成形状；画布点按或坐标表「追加顶点 / Add vertex」逐点添加，直到线 ≥2、面 ≥3 个不同顶点 | 坐标追加后回下一次经度输入；画布追加后留画布 |
| 完成/取消形状 | 按条目按钮收尾或丢弃该形状局部事务，不持久化 | 对应条目「继续编辑」；取消新形状则当前类新增按钮 |
| 空白拖拽/平移工具 | 鼠标超过 4 CSS px、触摸/笔超过 8px 后平移；平移工具不新增顶点 | 画布 |
| 顶点拖拽 | select 模式命中顶点后捕获 pointer，仅 pointerup 的有效变化提交 | 画布，保留顶点选择 |
| `+`、`−`、重置、适配 | 所有输入设备均可点按钮；缩放乘/除 1.2，重置回中心与 zoom=1；适配留 24px 边距 | 原按钮 |
| 方向按钮/方向键 | 方向按钮每次平移视图 40 CSS px；画布聚焦时方向键同义，不改变坐标 | 原按钮或画布 |
| 第二触点 | 立即取消未提交手势并恢复手势起点，释放 capture；直到全部触点抬起前不接受新增/拖点 | 保留原逻辑焦点 |
| pointercancel / Esc | 取消未提交指针手势，不提交预览位置 | 画布 |

本轮不做双指缩放，触摸/笔通过 `+`、`−`、重置及平移工具完成视图操作。空白双击不缩放、不完成形状、不删点。Space+拖拽可临时平移；输入框或可编辑区域聚焦时不截获上述快捷键。

无 registration 时可查看、zoom/pan、数值编辑及显式删除；禁用画布新增、拖点和按画布位置插点。坐标表的数值追加及按相邻经纬度中点插入仍可使用，不假装它是投影曲线的屏幕中点。

**「未配准：无法从画布位置确定经纬度，请使用坐标输入。」 / “Not registered: coordinates cannot be determined from the canvas. Use coordinate inputs.”**

### 3.3 三级坐标换算

1. **屏幕 → 内容区**：pointer client 坐标已经是 CSS px，不重复处理 DPR；扣除视口偏移、边框和 padding。截图物理像素才先除 DPR。测量未 zoom 的布局内容区。
2. **内容区 → viewBox**：先撤销屏幕 pan，再围绕约定原点撤销 zoom，再扣 `xMidYMid meet` 信箱边距，最后除适配比例。
3. **viewBox → 经纬度**：使用所选底图 registration 的逆映射，不以任意 bbox 插值代替真实 registration。反投影失败、缺 registration 或非有限值均拒绝提交。拖出图像矩形时夹到图像边界并提示，不外推信箱区域。

数值示例：viewBox=2048×1280，内容区=900×620 CSS px，原点=(450,310)，zoom=2.5，pan=(120,−80)，内容区指针=(400,300)。

| 步骤 | 结果 |
|---|---|
| meet 比例 | 0.439453125 |
| 底图布局尺寸、信箱边距 | 900×562.5；左 0、上 28.75 |
| 撤销 pan | (280,380) |
| 撤销 zoom | (382,338) |
| 扣信箱边距 | (382,309.25) |
| viewBox | (869.2622222222222,703.7155555555555) |

该例自身不含真实 registration；§11.1 给出显式定义逆映射的测试 fixture，不将示例数字当作生产地图证据。

### 3.4 命中规则

| 目标 | 规则 |
|---|---|
| 顶点 | 视觉半径 6 CSS px，命中区域至少 44×44px |
| 边与线本体 | 命中走廊至少 44px；先选择，不拖动整线 |
| 中点 | 仅选中边显示；选边按钮同样可达，不要求 hover |
| 面 | 内部可选择，小面扩大屏幕命中区 |
| 重叠目标 | 优先操作浮层、顶点、中点、线面、空白；同级扩大区域重叠时必须候选消歧 |
| 密点 | 不抽稀数据；提供点/边列表及适配选中 |

### 3.5 零写入守卫

- zoom、pan、select 只改 UI，不调用 `cloneSpec`、`markManual`、`emit('update')` 或 PUT。
- 第二触点、pointercancel、Esc、未过拖动阈值、拖回原坐标：零 update、零 markManual、零 PUT；不置脏。
- 拖动中只有临时预览；最终坐标与事务起点比较后才决定提交，不能因移动过程经过其他位置而置脏。
- 活动形状的操作进入局部形状事务，其余有效几何编辑进入页面统一通道。
- 本轮不做跨要素吸附；隐藏类别不能成为隐形吸附目标。

## 4. 删点

### 4.1 可见入口与快捷操作

| 入口 | 规格 |
|---|---|
| 选中顶点删除 | 画布浮层至少 44×44px；条目和顶点行同步提供「删除顶点 / Delete vertex」 |
| Delete / Backspace | 编辑器聚焦且已选顶点时生效；文本输入、可编辑区域保留原行为 |
| 双击顶点 | 仅 select 模式兼容；两次点击同一目标且均未超过拖动阈值才删除一次 |
| 删除地点 | 独立可见按钮「删除地点 / Delete place」，不通过双击隐式删除 |

按钮必须可聚焦、带要素名与顶点序号，不只依赖颜色。实际拖动后取消双击删除资格，避免一次拖动又触发删除。

### 4.2 下限、草稿与焦点

- 已有线删除后至少 2 点，面至少 3 个不同顶点；闭合端点不单列。
- 拒绝时保留数据和选择，零 update、零 markManual、零 PUT，行内及 alert 同时反馈：
  - **「线要素至少需要 2 个点；如需移除，请删除整个要素。」 / “A line needs at least 2 vertices. Delete the feature to remove it.”**
  - **「面要素至少需要 3 个不同顶点；如需移除，请删除整个要素。」 / “A polygon needs at least 3 distinct vertices. Delete the feature to remove it.”**
- 未完成新形状允许继续增删局部点；未达到下限不得完成或进入页面保存载荷。
- 删除不自动改为删除整个要素。显式删除要素可删除最后一条，随后呈现空态。
- 活动形状内删除只改该形状事务，完成后写页面草稿；普通顶点表及地点行删除立即写唯一 `specDraft`，无弹窗二次提交。
- 成功删除后聚焦下一行，末行则上一行，空列表则新增按钮；拒绝时留原按钮。
- SVG 即时预览；持久化前显示 **「已加入待保存草稿 / Added to unsaved draft」**，仅页面「保存几何」成功后显示已保存。

### 5.1 同组件、不同列配置

桌面宽 760px、最大为视口减 32px，高度不超过 80vh；窄屏全屏模态。底部固定状态及 **「关闭 / Close」**，没有「保存到草稿」或弹窗服务端保存按钮。

- 输入文本保留负号、小数点、空值等半成品；有限数、经纬度范围、要素下限校验通过后才写页面草稿。

### 5.2 唯一页面草稿与关闭语义

| 状态 | 归属与规则 |
|---|---|
| 输入缓冲 | 只保存正在输入的半成品和错误，不是第二份可提交 spec |
| 页面 `specDraft` | 地点行/普通顶点弹窗每次有效编辑立即写入；其他页面视图读取同一份数据 |
| 活动形状事务 | 仅为未完成新形状或显式继续编辑保留；完成后并入页面，取消仅丢弃该事务 |
| 服务端基线 | 最近接受的规范化 spec、选项和 revision；仅页面保存更新 |

有效坐标编辑通道：

**实际变化 → cloneSpec → markManual（仅变更要素）→ emit('update') → 唯一 specDraft。**

名称修改不调用几何 `markManual`；无实际变化不 update。普通弹窗不持有待整体提交的第二份几何副本。

- 有效编辑后显示 **「已加入待保存草稿 / Added to unsaved draft」**。
- 关闭弹窗不再提交，也不撤销已进入页面草稿的编辑。
- 有半成品输入时关闭，提供「继续输入 / Continue editing」或「丢弃未生效输入并关闭 / Discard incomplete input and close」；只丢输入缓冲。
- Esc 与关闭按钮同义；不得将关闭称作取消整份草稿。
- 「取消当前形状 / Cancel current shape」仅取消活动形状事务；如需撤销整页有效改动，使用页面「放弃未保存修改 / Discard unsaved changes」，明确其整页范围。
- 页面保存前必须处理未完成形状及无效输入缓冲，不能悄悄漏存。
- 页面「保存几何 / Save geometry」一次 CAS 提交整份 `specDraft + layerOptionsDraft`，所有类别和条目一起保存；关闭不构成第二次提交。

### 5.3 点表、非 hover 操作与版本定位

- 模态打开后背景 inert，画布快捷键暂停。关闭恢复原 zoom/中心及触发的「N 点」「全部地点」按钮焦点；触发要素已删除则回当前 TAB 列表标题。
- 活动形状的坐标表直接操作**同一个活动事务**，不再复制一份弹窗事务；关闭表格保留活动形状。完成/取消使用形状按钮。
- 工具按钮可新建未完成线/面，坐标表可以从零点追加到线 ≥2、面 ≥3 个不同顶点，不仅编辑已有形状。
- 顶点行有选择按钮；边列表明确端点序号，选边后可插点，面包含末点至首点的闭合边。插点后焦点到新顶点经度；追加后回下一次经度输入。
- 重叠候选列表每项有选择按钮，支持触摸、笔和键盘；选定/取消返回触发入口。
- 50 行分页；地点可本地搜索、顶点可跳行，不把筛选、页码写入 URL。选中行自动打开其所在页，序号不因搜索变化。
- 页间保留输入缓冲及错误，提供跳到错误；不静默抽稀真实顶点。

**顶点行深链必须带版本。** 采用拟议 `msggeorev`，值为生成链接时可从 detail 读取的服务端 revision；`msgrow` 仅定位该 revision 下的顶点序号。保守绑定整任务 revision，允许无关修改导致退回，但不得误定位另一点。

- 先读 detail，再校验实体、revision、行号，最后定位。
- revision 缺失或不匹配，即便行号仍合法，也只打开要素级点列表，清行定位并提示：  
  **「几何版本已变化，已打开要素点列表；未定位原顶点。」 / “The geometry version has changed. The feature’s vertex list is open; the original vertex was not located.”**
- 当前页面已有该要素的未保存坐标变化时同样退到要素级；不将草稿坐标或未保存顶点序号编码进 URL。
- 要素失效则关闭子层并回所属 TAB；行越界退到要素级。
- 不新增稳定 vertex ID。现有坐标数组无稳定顶点 ID，依据 `services/layer-doc.ts:91,96,101`。
- 恢复、回退与关闭均零保存、零生成、零确认、零交付。

## 6. 条目内「完成编辑 / 继续编辑」

### 6.1 状态机

| 状态 | 行为 |
|---|---|
| 未编辑 | 「继续编辑 / Continue editing」可用；完成禁用并说明无活动形状 |

新形状在列表顶部有临时条目及完成/取消按钮，不只依赖画布工具条。本轮同时最多一个活动形状。

### 6.2 职责分离

- 「完成编辑」仅收尾局部形状，不持久化、不确认几何、不渲染、不交付。
- 地点行和普通弹窗不需要再点完成；其有效编辑已经进入页面草稿。
- 页面「保存几何」提交当前整份 `specDraft + layerOptionsDraft`，不存在 A 完成后只保存 A、B 仍脏的服务端提交粒度。
- 顶部完成/取消与条目按钮调用同一形状事务；无活动形状时不显示空的「完成（0 点）」。
- 完成已有形状后焦点回「继续编辑」；取消新形状回新增按钮。

**「完成编辑只结束本次形状修改；尚未保存，也不代表你已显式确认几何。」 / “Finishing ends this shape edit only. It does not save changes or explicitly confirm geometry.”**

服务端坐标修改会转 manual、删除 proposed 并设置 confirmed；仅改名称不会产生这些效果，依据 `run.ts:500-511`。该存储行为不能证明用户点击过确认入口。

默认 guided 契约在 base 后停靠，显式确认和渲染分开；现有服务端不强制未确认几何禁入 drawing，依据 `accuracy.ts:88-95`、`store.ts:575-595`。不新增整体复核键或正式门槛。

### 6.3 数据集要素

继续编辑前显示非阻断说明：

**「实际坐标改动加入草稿后将显示为人工几何；保存后按服务端规则更新来源。」 / “Actual coordinate changes become manual geometry in the draft; saving updates provenance under server rules.”**

无改动、选择、改名、取消及纯视图操作不转人工；真实坐标编辑按既有规则删除 `dataset_ref`，不虚构保留有效数据集关联。平滑选项变化不改坐标来源、不确认几何。

## 7. 平滑偏离警告

### 7.1 呈现与精确值

保留既有默认强度；加载、恢复、校验不自动改值。

| 呈现项 | 规则 |
|---|---|
| 每段明细 | 段号、偏离、上限、建议强度 |
| 像素单位 | 渲染图像像素，不是 CSS px；zoom 不改变判定 |
| 数值 | 偏离与上限各一位小数；比较仍用未舍入值 |
| 舍入相同但超限 | 显示「18.0px（超限）/18.0px」，保留精确值说明 |
| 精确值入口 | hover、键盘 focus、触摸/笔点按均可打开说明 tooltip；关闭返回触发入口 |

18.03/17.98 等仅为文案及阈值测试输入，不是已执行结果。精确 tooltip 使用实际计算值：

**「精确偏离：{deviation}px；精确上限：{limit}px」 / “Exact deviation: {deviation}px; exact limit: {limit}px”.**

### 7.2 建议值与动作

既有 `suggestedStrength` 使用 14 步二分、向下取 0.05 档、低于 0.05 归零，依据 `render/smooth.ts:227-237`；超限明细来自 `:239-264`。

- 多段共用滑杆时取所有超限段 suggested 的最小值，应用后对**整条曲线**复算，不只检查原告警段。
- suggested>0：显示「采用建议强度（S） / Use suggested strength (S)」与「关闭平滑 / Turn smoothing off」。
- suggested=0：仅显示关闭动作。它可能来自有限步搜索及向下取档，不证明不存在非零可行解。
- 通用说明：  
  **「当前算法未给出可采用的非零建议强度；建议关闭平滑。」 / “The algorithm returned no usable non-zero strength; turn smoothing off.”**
- 仅同口径计算证明 0.05 超限才可说该档超限；不能据此外推全部非零强度不可行。
- 点击、滑杆及关闭仅改 `layerOptionsDraft`，零自动 PUT、零几何确认。
- 完整复算为空才显示偏离已回到范围；仍有问题就列真实剩余段，不能直接清空警告。
- 无尺寸、registration 或无法构造同口径像素几何时禁用建议计算并说明原因，不用屏幕像素代替。
- 无法复算时保留未验证状态：  
  **「无法验证平滑预览，未确认偏离已消除。」 / “Smoothing preview could not be verified; deviation clearance is not confirmed.”**

### 7.3 持久化事实与本 Issue 必改分支

**首次成图前保存已经存在，不是待核实前提。**

`PUT /tasks/:id {expectedRevision, map_spec, layer_options}` 经 `run.ts:440-442` 校验，`:450-451` 接受已知要素 ID，`:467` 写 `outputs.layer_options`；drawing 经 `run.ts:258` 消费，`drawing.ts:87-95` 支持 semantic_id 到 layer ID 回落。前端同一次几何 CAS 提交见 `task.vue:963-972`。

**已有 layer_doc 的旧分支必须修改。** spec/brief 未变时当前会进入 `saveMapLayerDoc`（`run.ts:444-449`），随后重渲并自动交付（`run.ts:608-639`）。不能一面承诺保存不重渲，一面保留该路由副作用。

本 Issue 的目标契约：

1. 几何区「保存几何」一次 CAS 持久化整份 spec 与选项；只有选项变化时存选项并标旧图过期。
2. 不因已有 layer_doc 而隐式调用重渲/交付分支；这是必须实现的服务端分支拆分，不是假定现状已支持。
3. 渲染和交付为独立显式动作。complete 本身就是交付阶段（`run.ts:264-275`）；`/deliver` 仅重试/补交付，不重渲 pip（`routes.ts:141-148`、`delivery.ts:69-86`）。
4. 保存成功后刷新须恢复滑杆、开关和按恢复数据计算的告警；首次成图须实际消费保存的选项。

### 7.4 文案与说明

| 用途 | 中文 | English |
|---|---|---|
| 标题 | 平滑曲线偏离原走势 | Smoothing moves the curve away from its original path |
| 段明细 | 第 {n} 段：偏离 {d}px，上限 {l}px；建议强度 {s} | Segment {n}: deviation {d}px, limit {l}px; suggested strength {s} |
| 复算通过 | 偏离已回到允许范围；修改尚未保存 | Deviation is within the allowed range. Changes are not saved yet |
| 仍超限 | 仍有 {n} 段偏离过大 | {n} segments still deviate too far |
| 草稿状态 | 已加入待保存草稿 | Added to unsaved draft |
| 原理说明 | 平滑把折线弯成曲线；这里检查曲线离原路线最远有多远 | Smoothing bends the path into a curve. This checks its greatest distance from the original path |

以下是拟议接口，不是现有实现；复用模块现有类型。

### 10.1 页面唯一草稿

页面持有 `specDraft`、`layerOptionsDraft`、最近已接受的服务端规范化基线/revision、dirty、saving、错误及隔离恢复副本。

- brief 属于独立需求编辑职责，不暗带入几何保存。
- 页面保存前必须完成/取消活动形状、修正/丢弃半成品输入。
- URL 仅存视图与选择，不存坐标草稿、输入缓冲或冲突副本。

### 10.2 CAS、失败与结果未知

请求契约：

`PUT /tasks/:id {expectedRevision, map_spec: specDraft, layer_options: layerOptionsDraft}`。

几何未变时提交最近服务端接受的原样 spec，不用前端重新拼装以制造差异。保存期间锁定相关编辑。

| 结果 | 处理 |
|---|---|
| 成功 | 以服务端返回的规范化 spec、选项及 revision 建立新基线；返回不足则读 detail 后确认。全部几何脏项一起清除 |
| 明确拒绝 | 活动预览回滚到已接受基线；失败内容隔离为恢复副本，不显示已保存 |
| 409 | 保留隔离副本，读最新 detail，恢复服务端状态；不得用旧内容自动覆盖新 revision |
| 超时/断线、结果未知 | 不断言未落盘，不盲重发；先读 detail，revision 前进且整份提交内容按规范化契约匹配才视为已保存 |
| 结果未知且内容不匹配 | 进入冲突恢复，保留副本供比较；即便 revision 未前进也不得自动重试未知请求 |
| 重读失败 | 保持保存/渲染锁定，提供重试读取，不以旧 revision 继续提交 |

keep/discard 仅处理恢复副本；沿用既有 5d 恢复口径，不扩展永久存储或跨 revision 自动重放。重新应用须用户检查后成为新草稿。

文案：
- **「修改已保存 / Changes saved」**：仅已确认持久化后使用。
- **「保存结果未知，正在读取最新版本；请勿重复提交。」 / “Save outcome unknown. Reading the latest version; do not resubmit.”**
- **「保存失败，预览已回滚；未保存内容已保留供检查。」 / “Saving failed. The preview was rolled back; unsaved changes are retained for review.”**
