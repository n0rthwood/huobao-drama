# 第 3 轮产出：点线面编辑器详设（MapGeoEditor 重写）

约束与事实见随附 `facts.md`。本轮的硬目标是 v2 第三节（V11/V12）、第五节（V17-V21）、第六节（V22-V24），以及 Issue 正文阶段 2 的全部条目。现状代码证据在 `facts.md` 第 2 节 `MapGeoEditor.vue` 条目（912 行、无敌 zoom/pan、双击删点、工具条全局完成、中点把手铺满、`eventGeo` 反投影、unit=max(W,H)/400、datasetBadge 是静态 span）。

不要重复写主界面布局，只给编辑器。编辑器是主界面第三块（点线面核对与编辑），占地最大。

## 必须产出

### 1. 编辑器容器与层级
- 编辑器在面板内的占位（桌面 1440×900、面板可全屏）、是否可全屏/独立窗口。
- 垂直结构：TAB 栏 → 画布（zoom/pan 工具）→ 当前类条目列表 → 状态栏（光标经纬度、缩放级别、registration 摘要、脏标记）。
- 画布与列表的高度比、折叠策略。

### 2. 三类 TAB（V12 硬规则）
- TAB 定义：地点 / 线要素 / 面要素；同一时间只渲染当前类（其余类**不画**，底图保留）；给出切换 TAB 时的确定行为表：
  - 选中要素在别的类 → 清空选中/保留？
  - 有未完成草稿（正在画线）→ 切换时丢弃/暂存/拦截？
  - 平滑滑杆草稿（layer_options 草稿）→ 保留
  - zoom/pan 视图 → 保留还是重置
  - 列表滚动位置
- 给 TAB 栏规格：计数徽标、待核对徽标（proposed）、新增按钮、当前类提示文案。
- 说明「底图保留」的具体做法（底图 img 始终在，SVG 只画当前类），以及隐藏类别的视觉确认（用户如何知道确实隐藏了而不是丢了数据）：建议一条「已隐藏 2 类几何（切换 TAB 查看）」的次级提示。
- 为什么不做「淡显」：写在设计决策记录里（V12 禁止）。

### 3. 画布 zoom/pan（V17/V18）
- 交互规格表：滚轮缩放（步长、min/max、以光标为锚点）、双击空白？（不缩放）、select 模式空白拖拽 = 平移、指针拖把手 = 拖点、按住空格拖 = 平移（可选）、缩放按钮 +/-、重置视图、适配视图（fit）。
- 坐标换算三级链条（这是实现契约，必须写成不含代码的规范）：
  1. 屏幕像素 → 画布像素（考虑 DPR、容器 padding、img 实际渲染尺寸）
  2. 画布像素 → viewBox 坐标（zoom/pan 变换的逆；现有 `preserveAspectRatio=meet` 的信箱边距要先还原）
  3. viewBox → 经纬度（registration 反投影，无 registration 时禁用画布拖拽，只允许数值编辑）
  给一个数值示例：底图 2048×1280、容器 900×620、zoom=2.5、pan=(120,-80)，光标落在 (400,300)，逐步算出 viewBox 坐标并说明每一步公式的文字描述（不要写代码）。
- 命中测试规则表：顶点把手（半径 6px 屏幕恒定）、中点把手、线/面本体、底图空白、边界情况（把手重叠、缩放很小、密点）。触摸/笔同口径，pointer size ≥44px 的可点区域（可给实现规避方式：命中区大于视觉半径）。
- 「只缩放不平移」不得写入几何的守卫（V17 断言），以及拖点期间的捕捉/吸附（可选：吸附到最近的已知要素？给取舍）。
- 缩放级别与中心的深链（`msgeo` 现有 + 新键），越界参数回退规则（clamp + 可读提示）。

### 4. 删点（Issue 2a）
- 三种触发：选中顶点后的显式删除按钮（画布内浮层/条目内）、键盘 Delete/Backspace、双击顶点（保留兼容）；优先级与冲突（双击通常先触发两次 pointerdown）。
- 删除按钮的呈现：位置、尺寸、悬停态、可达性（键盘焦点、aria-label）。
- 点数下限：线 ≥2、面 ≥3；拒绝时的 toast 文案与视觉（不静默）；删除最后一个要素时是否同时删除要素（给规则）。
- 删点后是否立即写 spec（草稿）还是需要保存（与编辑通道一致：草稿 + 保存；给「即时上图 vs 保存」的清晰说明）。

### 5. 点列表弹窗（逐点编辑）
- 线/面条目内「N 点」按钮 → 弹窗规格：标题（要素名 + 类型）、表格列（序号、经度、纬度、操作）、行删除按钮、批量操作（可选）、底部「保存到草稿 / 取消」。
- 地点 TAB 的「全部地点」弹窗（V11）：列（序号、名称、经度、纬度、删除）；与线/面顶点弹窗同构（同组件不同列配置）。
- 弹窗内的编辑语义：改一格即改草稿；点「保存」才 emit update 并写 spec（还是每次 input 即写？给出取舍与理由，必须与拖拽同一 update 通道）；保存按钮与主界面保存按钮的关系（避免双写）。
- 「保存后即时上图」：SVG 覆盖层立即更新；服务端成图重渲是显式动作（V20 文案区分）。
- 弹窗深链（#86）：打开状态 + 要素 id + 可选行号；恢复不触发写、行不存在时回退到要素级。
- 与 zoom/pan 的关系：弹窗打开时画布是否锁定；关闭后保持视图。
- 大数量（50+ 点）的表现：虚拟滚动/分页、搜索框（可选）、极端性能说明。

### 6. 条目内「完成编辑 / 继续编辑」（Issue 2b）
- 现状：只有顶部工具条有「完成（N 点）」，条目内只有「继续编辑此形状」。
- 给按钮的状态机：该条目未在编辑 / 正在编辑（草稿 active）/ 有未保存改动 / 点数不足。
- 每条目按钮与顶部全局工具条的职责分离：条目内 = 收尾该形状草稿；顶部 = 全局草稿收尾与退出编辑模式。
- 文案 zh/en，以及「完成编辑 ≠ 确认几何」的旁注（与第 2 轮语义分离一致，给一句短文案）。
- 数据集要素：改动后转人工（markManual）；继续编辑数据集要素前是否需要提示「改动后将转为人工几何」。

### 7. 平滑偏离警告（V22-V24）
- 现状问题复述一句：整数显示导致「偏离 18px 上限 18px」；默认强度 1 对非数据集要素；提示只有一句「调到 0.95 以下或关闭」。
- 新呈现：每个超限段一行（段号、真实偏离 18.4px、上限 18.0px、建议强度 0.85）。舍入相同时 → 显示「18.4px（超限）/ 18.0px」，并给精确值 tooltip（例如 18.43 / 17.98）。
- 两个动作按钮：「一键降到建议强度（0.85）」与「关闭平滑」；suggested=0 时按钮只有「关闭平滑」，并说明「这条曲线在 0.05 的力度下也会超出容差」。
- 交互规则：按钮 = 人的显式动作（服务端代码不自动改强度）；点击后滑杆值写入 layer_options 草稿（页面保存 PUT）；点击后前端立即用同一 smooth.js 预览重算 deviationProblems，若仍超限则如实列出剩余段。
- 文案族（zh/en）：警告标题、段描述、两个按钮、点击后的成功/仍超限提示、滑杆旁的说明（「强度越高曲线越平滑，但偏离原走势越多」）。
- 一个「可理解」的视觉说明：如何用一句话+一个小示意图让人理解「偏离原走势」；不许用「容差」这种内部词作为唯一解释。
- 验收断言清单（阈值两侧、舍入相同、点击后复算为空或列出剩余、刷新恢复）。
