## IMPLEMENTATION RISKS

1. **同意。** `out/report.json` 是容量的唯一机器来源；DESIGN 中的表只供人读，产品提示或校验不得硬编码其数值。
2. **同意。** 主体／图表 bbox 是选套前置输入；缺失时拒绝生成文本框，不回退默认套。
3. **同意。** 自动缩小须作为可观测失败信号：渲染结果、遥测和产品 UI 都要标黄，不能静默吞掉。
4. **同意。** zone、同拍／相邻拍去重、引文格式、并列转列表均应在生成 schema 层阻断；生成端不暴露自由坐标、字体或颜色。
5. **部分同意。** scrim／渐变参数必须按类型锁死；但不同意在引擎中依据底图明度自动切换或取样做对比度分支。固定的纸白描边／投影和固定局部 scrim 保证双端同源，浅底仍由渲染图人工验收。
