IMPLEMENTATION RISKS:
1. **容量唯一来源必须是引擎 report.json**：产品侧严禁把 DESIGN.md 的容量表硬编码进提示词或校验器；字体、字号、em 规则任何一次调整后若两处失同步，AI 会按旧容量写出溢出文案。构建流水线应从 report.json 生成 AI 提示中的容量段。
2. **bbox 标注是硬前置**：版式选择全部依赖"主体/图表 bbox"输入。实现时该字段必须为必填、缺失即拒绝渲染（而非回退默认套）；H3 类图表底图上回退默认套就是事故。
3. **自动缩小要可观测、不可静默**：5% 步进缩小应上报遥测并在产品 UI 标黄；缩小率升高说明写作规则在失效，不能让"缩到 min_scale 也塞得下"成为常态出口。
4. **校验器前置到生成时**：zone 互斥、同拍/相邻拍去重、引文 pattern、并列分隔符转 bullets，都应在分镜 AI 输出 schema 层做成阻断（schema 里根本不存在自由 x/y/字体/颜色字段），而不是渲染后给警告再返工。
5. **scrim/渐变参数按类型锁死**：extend、feather、opacity 不暴露给 AI 或终端用户；一旦可调，"克制"会在使用中退化为随手压暗半屏。配套在引擎内做浅底对比度自动检查（即第 1 条 TOP FIX 的自动分支），让可读性不依赖人工复核。
