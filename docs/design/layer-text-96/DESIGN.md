# 档案风模板文本框体系：第 3 轮最终版

## 第 3 轮变更摘要

1. `date.main` 固定为 `Noto Sans SC` 700；四种画幅的时间锚不再混用宋、黑体。
2. 线框图顶部由渲染器显示 `layout.id · layout.name`；槽位也显示 `slot · role`。`out/layout-*.png` 可与本文件逐项对照。
3. `statement.main` 出现 **≥2 个并列分隔符（`、`、`；`）** 时，必须改为 `bullets` 或拆拍；H1 末拍已改为三个并列 bullet。
4. 相邻拍的不同槽位之间，任意字段出现 **≥6 个字符的连续重复** 即触发警告。H2 第二拍改为“全国农民缴纳”的制度口径，不复现“漕粮赋税总额”。
5. `h-bottom-left` 的主信息锚点固定为 `x=7%`、`y=63%`；距安全区左缘 2%，最坏三项列表底缘为 80.3%，距字幕安全上限 5.7%。
6. `p-landscape-bottom` 的 `details` 宽度收窄为 35%W；HP 信息场右缘远离长城下行坡道。
7. V2 末拍改为同级事件短语：“大泽乡揭竿而起／咸阳城门打开／两年多后入咸阳”。
8. VP 的片名区域收至 `x=6%–37.1%W`（含柔光外扩），与居中人物轮廓至少留 2%W；定稿按第15项改为两行“十五年／大秦亡”，不切词。
9. 视觉语言从“全是深墨卡片”改为四级：紧凑实底题签、局部柔光压暗标题场、轻量渐变事实场、无底板描边的数据/关键词。横版正文提升至 41px、日期至 43px、次级至 25px；Poster 主标题为全图最大字。
10. 视频每套改为 `context`、`primary`、`emphasis` 三个区位：日期可与主信息同屏，标题/说明/引文/数据/列表在主信息区互斥，关键词独占第三层。
11. **3b**：引擎改为先绘制所有底板再绘制所有文字；`heading` 与 `poster_title` 将会拉到画面边缘的 `gradient` 改为局部 `scrim`（四向羽化），保留描边和投影，只压暗标题周边。

### 定稿

12. 纯时间坐标只用 `date`，不得借 `metric`／`keyword` 放大；V2 拍1改回时间锚。
13. 同拍不同槽位的完全相同或连续≥6字重复为错误；V2 拍3日期副行改为“刘邦入关”。
14. 次级文字不按底图明度自动换色：`heading`、`metric`、`keyword` 的 `sub` 固定纸白、深墨描边与投影；`heading` 的局部 `scrim` 覆盖眉题和主标题。

## 0. 系统边界与视觉原则

本体系只服务可核实的基本信息，辅助旁白和画面；地图点、线、面的地名仍使用地图锚定标注。固定 em 度量不变：全角 1em、空格 0.33em、半角 0.55em，行高按样式声明。数字与紧随单位不拆行。

调色：深墨 `#16130f`、纸白 `#f4efe5`、雾灰 `#d9d0c0`、朱砂 `#b4462b`、暗金 `#d1a35a`。字体仅使用打包字体：`Noto Serif SC`（标题、数字）、`Noto Sans SC`（事实、元数据、日期）、`LXGW WenKai`（可核实引文）。`ZCOOL XiaoWei` 仅登记，不用于任意生产文本，避免生僻字回退。

- **时间锚**：唯一保留的深墨实底，小而紧凑，负责上下文，不承担标题；纯时间坐标只能写入 `date`，不得借 `metric`／`keyword` 放大。
- **主题标题**：大宋体、细朱砂线、完整覆盖 `sub` 与 `main` 的局部 `scrim`、纸白深墨描边／投影；不是方形卡片。
- **事实／引文／列表**：只在文字区用局部轻渐变，保留背景材质；引文更深一档。
- **数据／关键词**：无底板，大字配细朱砂刻线和深墨描边／投影；`sub` 同样固定纸白、深墨描边／投影，不随底图明度自动变体。
- **Poster**：项目名是小题签；片名是全图最大字；信息卡为轻渐变档案场。片名场与人物、器物主体轮廓至少相距 2%W。

长文案的唯一处置顺序：**改短 → 拆拍 → 换正确类型**。仅在类型 `min_scale` 范围内允许 5% 步进缩小；本轮 8 个样例均为 100% scale。

## 3. 提取、写作、去重

1. 先读已核实信息点，再读旁白；只上屏能帮助理解时序、因果、规模、定义或画面对象的信息。
2. `date`：优先“公元前207年11月14日”“1872年”；首次必要时再写“同治十一年（1872年）”。数字和年／月／日／石等单位不可拆。**纯时间坐标只能用 `date`；`metric.main` 不得写年份、朝代或时间段。**
3. `heading`：只保留核心名词或判断；`sub` 仅写地点、类别、段落，不复述标题和时间。
4. `statement`：必须是一句独立理解的事实。`main` 中有 **2 个或以上 `、`／`；`**，一律转换为 `bullets` 或拆为多拍；不得将三个并列短语塞回说明句。
5. `bullets`：最多三项，时间或逻辑排序，同级语法完全平行。例如“条石为基／青砖包砌／顶宽五马并行”，不要混入“相隔只两年多”这种不同句法的关系句。
6. `quote`：仅原句、史料或提问；必须保留成对引号，`sub` 只写可核实的人名、书名或地点。解释句、概述句不是引文。
7. `metric.main` 只写数字与紧随单位；对象、口径、比较进入 `sub`。没有图表不伪造比例图。
8. 同拍任意不同槽位、及相邻拍不同槽位的任意字段，完全相同或有 **≥6 个字符连续重复** 即为错误；`date.sub` 不得等于任一 `bullets.items`。同一槽位的时间锚可持续显示；否则下一拍必须增加新口径、换角度或留空。
9. 不上屏：无来源精确年份、长旁白、情绪化口号、无法从素材或事实库验证的地点，及地图点线面名称。

## 4. 成套位置、分区与底图选择

每套均含本媒介所有类型槽位，并已用最坏内容检查安全区、避让区、间距。视频有三个区：`context`（仅 `date`）、`primary`（`heading`／`statement`／`quote`／`metric`／`bullets` 互斥）、`emphasis`（`keyword`）。因此日期可与一个主信息框同屏，关键词只在需要强落点时叠加；同区永不同时出现。

### 9:16 video：4 套

- `v-left-column`：左上语境／左中主叙事／左下关键词。主体在右、中右，左侧留白时选；V1 使用。
- `v-right-ledger`：右上语境／右中主叙事／右下关键词。右缘硬止 71.2%W；主体在左、右上留白时选；V2 使用。
- `v-center-top`：上中语境／中部主叙事／下中关键词。对称构图或章节转场使用；关键词右缘仍在按钮栏左侧。
- `v-left-low`：左上关键词／左中语境／左下主叙事。主体在右上、左侧中下有空处时选；不入底部字幕区。

### 16:9 video：4 套

- `h-left-stack`：左上语境／左中主叙事／左下关键词。主体在右、左侧天空／水面／墙面留白时选；H1、H4 使用。
- `h-right-stack`：右上语境／右中主叙事／右下关键词。主体在左、右侧负空间时选；H2 使用。
- `h-center-top`：上中语境／中部主叙事／下中关键词。顶部留白、主体在下部时选。
- `h-bottom-left`：左上关键词／左中语境／左下主叙事。图表或主体位于上中／右中时选；H3 使用。主信息 `x=7%`、`y=63%`，已保留左缘及字幕区余量。

### 9:16 poster：4 套

- `p-vertical-left`：左侧留白：栏目／片名／档案信息；VP 使用。片名场右界（含外扩）≤37.1%W，人物在中轴时选。
- `p-vertical-right`：右侧镜像；主体在左时选。
- `p-vertical-top`：上中栏目／片名、左下档案信息；顶部无人物或器物主体时选。
- `p-vertical-bottom`：左上栏目／片名、下中档案信息；上方连续留白、下部无关键主体时选。

### 16:9 poster：4 套

- `p-landscape-left`：左侧片名，主体或纵深线在右时选。
- `p-landscape-right`：右侧片名，主体在左且右下无时长角标时选。
- `p-landscape-bottom`：左上片名／左下收窄档案场；HP 使用，避开长城中轴和下行坡道。
- `p-landscape-top`：上中栏目／片名、左下档案信息；主体在下方、顶部天空留白时选。

右置槽位以右锚固定，文本、底板、描边与柔光外扩后的右缘一律不得超过 `97%W`；`v-right-ledger` 更严格地止于 `71.2%W`。渐变不允许延伸到画面边缘，右缘是否压平台界面必须随渲染图验收。

选择前必须从底图描述标出人物面部和躯干中轴、建筑主轴、道路／城墙行进线、图表绘图区、空白区。文本板、渐变、朱砂线和任何装饰不得进入图表 bbox，不得压人物面部、躯干中轴或建筑主体。主体在左选右套，主体在右选左套；主体居中选上中／下部套并确认上下空白。H3 图表 bbox 约 `x=22%–80%、y=22%–57%`，样例所有框在其外。

## 5. 同屏与节奏

- 视频默认一拍一个主信息框；可在同拍保留 `date + primary`，或 `date + primary + keyword`。V1、V2、H1、H4 已各给出至少一个“上下文 + 主信息”同屏拍。
- `primary` 内的标题、说明、引文、数据、列表互斥；关键词仅在概念必须被记住时加入，不能拿来放大普通句子。
- Poster 固定 `poster_project + poster_title + poster_details` 同拍，三个区独立，片名最大。
- 时间在事实落地前 0.3—0.8 秒出现；标题跟关键名词；事实、数据、引文在旁白说出时出现。单条约≥1.2秒；两行说明约≥2秒。
- 任何布局宁可留白、换套或不加文字，不用大量暗板填满画面。

## 6. 给 AI 的填写规则

### 分镜设计 AI

**输入：**旁白、已核实信息点、每张底图的主体／图表 bbox 与安全区、可选套型，以及当前 `out/report.json` 的 `capacity`／`slot_capacity`。

**步骤：**
1. 去除地图锚点任务；无 bbox 或 bbox 不完整即停止，不选默认套。
2. 按 bbox、留白和右缘硬止选 `layout`；再按 `layout.slot` 从 `slot_capacity`（无覆写时 `capacity`）读取基准上限。
3. 为每拍选合法 role／字段；不输出自由 `x/y`、字体、字号、颜色、`label` 或 `card`。纯时间坐标选 `date`，不能选 `metric`／`keyword`。
4. 每拍最多一个 `primary`；可为 `date + primary` 或 `date + primary + keyword`，但不得同 zone 同屏。
5. 提交前阻断检查：容量、bbox／安全区、引文成对引号及出处、并列转列表、列表语法平行、同拍与相邻拍的≥6字重复。

**失败处置：**容量、缩小、重叠或避让失败时仅可改短、拆拍、换合法类型或换底图；bbox 缺失、无可用套、事实或出处缺失时输出阻断原因并退回补素材，绝不回退默认套或静默缩小。

### Poster 构想 AI

**输入：**项目名、集号、唯一主钩子、副标题、年代、地点、三条已核实要点、构图 bbox／主体描述、候选 Poster 套及当前容量报告。

**步骤：**
1. 只输出 `poster_project`、`poster_title`、`poster_details` 与一个 Poster 套；项目名不得复现为主标题。
2. 先按所选 title 槽位容量断行：左右窄套仅3字×2行，常规上中／下部宽套为6字×2行；不得切开词组。
3. 副标题不得包含项目名连续≥4字；三条要点同级、可核实，且避开人脸、躯干中轴、建筑行进线、图表区域。
4. 提交前校验角色、字段、按槽位容量、2%W主体间距、右缘硬止与信息来源。

**失败处置：**标题放不下时换宽套、改短或退回补文案；无可靠年代／地点／bbox 时不编造，改可核实段落标识或阻断退回补素材。

## 7. 引擎与渲染交付

本轮未改动固定 em 排版逻辑。使用现有渲染器的 zone 同屏阻止、引文 `pattern`、5% 自动缩小、同拍与相邻不同框≥6字重复阻断、线框顶部套名／槽位错行标注能力。最终渲染和报告位于 `out/`；`report.json` 的 `capacity` 与 `slot_capacity` 是唯一机器容量来源。缩小必须被记录并在产品 UI／遥测中标黄；scrim／渐变参数按类型锁死，且不依据底图明度自动取样或切换。
