MAP STUDIO · ISSUE #99 · Q4

先选视觉语言，再确定制图规范

历史纪录片地图 · 20 张开放授权参考 · 5 组候选风格

本目录独立于代码库；全部图片本地保存、最长边不超过 1600 px。没有生成式 AI 图片；下方 SVG 是手写虚构示意。未采用任何默认风格，所有数值均待您审阅。

请先回答这几件事

  1. 默认风格：您更偏好哪一组／哪几组？是否按西伯利亚、东欧、明代边防分别设定，而不是全片一套？
  2. 逐要素偏好：河流要蓝色还是墨色？主支流粗细差多少？区域要平涂、仅描边，还是地形晕渲？边界虚实、路线箭头、城镇点大小希望怎样区分？
  3. 文字：宋体（serif）、黑体（sans）、楷体（kai）、手写（hand）中，哪些可用于标题／区域／城市？河名斜体是否保留？
  4. 取舍：哪些参考或细节应删去（旧纸纹理、花饰、格网、过密地名、旧地图失真的轮廓等）？请可直接引用参考 ID。
  5. 画面优先级：片中出现的实际尺寸以河网／路线为主，还是区域／地形为主？图例、比例尺、经纬网哪些需要常开？

这些是视觉选择，不等于采用老图的疆域／地名／坐标。所有历史几何、年代和证据仍应另行审核；现代 CIA 图的行政边界绝不作为 16–17 世纪疆界。
