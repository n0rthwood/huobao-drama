# 已有画面的定向返工（Issue #129）

适用于用户提供人数、人物关系、站位或前后帧错误反馈，并要求保留剧情的修订。不是重新拆镜或全量重出配方。

1. 先记录本轮用户明确的角色关系与人数，以稳定 storyboard ID 对齐显示镜号。用户本轮纠正优先于旧资产描述，不因旧字段仍写“姐姐”就沿用。剧本、对白、模型、画幅和未受影响帧保持原范围。
2. 打开实际首/中/尾帧和每张实际参考图。检查重复是否来自参考图自身的多视图、场景中已有角色或重复引用。多视图不代表多人；单靠提示词写“只有两人”未奏效时，不应复制同一输入盲重试。可在授权范围选已有单人版本，或用产品确定性裁切生成独立参考，保留原资产、记录来源与裁切。裁切产物也须打开核对，不能把裁切当模型重绘。
3. 提示词只修具体因果：每个角色一份，明确前后/左右/前排后排与成人尺度；物件保持正确平面和接触关系；首中尾保留同一主体，动作连续。原先中帧只剩一个孩子时，补上另一个孩子在同一空间的连续动作，而非靠视频模型凭空补回。不要把多个时间动作或角色正侧背视角堆到单张静帧里。
4. 建立受影响槽位清单；只出 changed/missing 的这些槽位。承接镜首帧来自上一镜生效尾帧，修上镜尾帧后重新核对承接镜、转场和视频签名。Poster 单独检查主角、人数与所选最终版本。
5. 浏览器数据加载后，点击目标分镜并核对 URL 的稳定 ID；操作前重新 snapshot。每个字段保存后读回实际目标与文本，再进入下一个。不能只看 fill/click 成功就认为保存完成；不要并发修改同一份 Poster 草稿。保存不稳定时，在已授权范围使用 hbwf 最小原子 PUT，再读回核对。用户明确要求 UI 编辑时保留前后快照及读回记录。
6. 开图查人数、物种、位置、体型和物件接触后再审核；失败版本保留。记录代理或用户本人审核的真实主体、版本、授权与证据。生成视频后看首中尾及转场，核验原声音轨；只有实际媒体通过本轮反馈才继续完整导出，不能以 completed 替代内容检查。

本轮案例是已有授权项目的生产返工；工具行为自测不借此获得修改其它真实项目或额外计费生成权限。预算与终检沿用主技能及 workflow.md。
