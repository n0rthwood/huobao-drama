# 纪录片项目：分镜拆解附加规范（两栏脚本 + 表达设计）

叠加在 `storyboard-breaker` 基础规范之上，冲突时**以本文件为准**。

纪录片分镜是**两栏脚本**：左栏旁白（讲什么），右栏画面（看什么）。两栏一一对应，同一镜内必须讲同一件事。

## 1. 旁白栏 = 剧本正文逐字照抄（硬规则）

本项目的剧本正文**就是旁白稿**。拆镜时按顺序把正文切成段，逐段**原样**写进 `narration_text`：

- **逐字照抄**：标点、年份、人名、地名、数字全部与原文一致。不改写、不润色、不缩写、不补字。
- **按句切**：只能在句号 / 问号 / 感叹号 / 分号之后切开，不许在半句处断。
- **不新增、不丢段**：正文每一段都要落到某一镜；全集 `narration_text` 顺序拼接后应当等于剧本正文。
  `save_storyboards` 每次返回 `script_coverage.gaps` 与 `must_fix`：**只要还有缺口就继续补镜**，
  在句界处插入新的 `shot_number`，把漏掉的句子逐字切进去。带着缺口收工会让整次拆分分镜任务判失败。
- 每镜 **≤80 字**（语音合成单段硬上限）。原文某段超过 80 字，就在句界处拆成相邻两镜。
- 纯画面镜头（空镜、过渡、地图定场）允许没有旁白：`narration_text` 留空即可，不要为它编一句解说。
- 工具会校验：`narration_text` 必须能在剧本正文中逐字找到，且顺序与正文一致；改写过的文本会被**拒存**。

## 2. 画面栏 = `description` 只写画面（硬规则）

- `description` 里**不写旁白文字**，不写「旁白：…」。旁白有独立字段，双写会被念两遍。
- 纪录片**没有对白**：禁止 `角色名：「台词」`，禁止让画面里的人物开口说解说词。
- `description` 写观众实际看到的：主体、动作、镜头内的变化（展开的地图、行进的队列、翻动的文书）。

## 3. 每镜一个信息点

拆镜的边界由**信息点**决定，不是由时长决定：一镜讲清楚一件事，讲完就切。

每一镜在 `title` 里用一句话写明本镜的信息点（「额尔齐斯河是唯一水道」「近卫团出身决定了指挥权」），
同一句话再写进 `intent.info_point`。画面必须**能把这个信息点显示出来**。

信息点与画面对不上，就**改画面**，不要改旁白。

## 4. 表达设计 `intent`（每一镜必填）

这是纪录片分镜与剧情分镜最大的不同：**先决定怎么表达，再写画面**。
写 `description` 之前先把下面这条链走完，结论写进 `intent`：

```
这一镜要让观众理解什么（info_point，只许一个）
  → 用什么手段表达（device）
  → 为此画面上必须看到哪些具体东西（must_show）
  → 这些东西用哪些图层画出来、按什么顺序显现（overlay_plan）
  → 为什么这样选（rationale）
```

### 4.1 `device`：五种表达手段，按旁白性质选

| device | 用在什么旁白上 | 画面是什么 |
|---|---|---|
| `map_anim` | 地理、路线、范围、同时发生的两条线 | 证据地图 + 高亮/箭头/标签逐层显现 |
| `archival` | 条约、文书、版画、器物原件 | 档案原件本身 + 缓慢推移 + 标签 |
| `card` | 人物首次出场、年代、章节转折 | 肖像/静帧 + 姓名条（姓名/职务/年代） |
| `reenact_still` | 静态状态、肖像、物件、无动作的处境 | 生成的再现静帧 + 缓慢推移 |
| `reenact_video` | **有过程、有动作的事件**（出发、行进、逆流而上、交火、围攻、登船、修筑、觐见、押解） | 生成模型视频 |

判据：**旁白里说的是「在哪儿」「是什么」还是「做了什么」**。
说「在哪儿 / 多大范围 / 走哪条路」一律 `map_anim`；只说身份、来历、年代、数字，用 `card` 或 `archival`；
**句子里有动词描述一个正在发生的动作或过程，就用 `reenact_video`，不要降级成 `reenact_still`**。

`reenact_still` 只用于**画面里确实没有动作**的镜头（肖像、器物、空场、静止的处境）。
「船队逆流而上」「大军向拉萨挺进」「侦察队乘船出发」「双方交火」这类句子属于 `reenact_video`；
把它们写成静帧，等于把纪录片里唯一会动的部分也冻住——一集里如果一个 `reenact_video` 都没有，
几乎可以肯定是判错了，回头逐句复核带动作的旁白。

`reenact_video` 的 `deterministic` 默认 `none`（整镜就是模型视频）；只有需要在模型视频前/后
补一小段确定性图层片段（例如先出年份卡、或结尾压一张地图小图）时才建议 `pre` / `post`。

不要用 `reenact_*` 去演地理关系：一个人在空地上走路表达不了「溯额尔齐斯河北上」。

### 4.2 `must_show`：旁白里的每一个具象名词都要落到图上

- 旁白里出现的**地名 / 水系 / 湖泊 / 城寨 / 政权范围 / 路线**，必须在某张证据素材的
  **语义标注**（`read_storyboard_context` 的 `props[].semantics`）里找到对应项，并写进 `must_show`：
  - 区域 → `{kind:'region', asset_id, semantic:'准噶尔汗国'}`
  - 河流/边界/路线线条 → `{kind:'line', asset_id, semantic:'额尔齐斯河'}`
  - 城市/地点 → `{kind:'point'|'label', asset_id, semantic:'斋桑湖'}`
  - 行军路线 → `{kind:'route', asset_id, from:'西宁', to:'拉萨'}`（两端都要是该图上已标注的地名）
- `semantic` 必须**逐字**取自 `semantics` 列表里的 `name`（或它的 `id`）。自己编一个名字会被标成
  `unresolved`，在表达设计页亮红，等于没写。
- 图上**没有**那一项时不要硬凑：在 `rationale` 里写明「旁白提到 X，资产 N 的标注里没有 X」，
  并把这一镜降级（换 device 或换资产）。必要时用 `read_image` 打开原图确认到底有没有。
- **人物首次出现** → `device='card'`，`must_show` 带 `{kind:'portrait', asset_id:<角色 id>}`，
  `overlay_plan` 里放一层 `card`（字段写姓名/职务/年代）。
- **旁白提到但本镜不出场的组织 / 异地人物 / 异地事件** → 引用
  `read_storyboard_context` 的 `exposition_assets`：`{kind:'exposition', asset_id:<那个载体资产>}`。
  例：旁白说「他出身谢苗诺夫近卫团，那支近卫团是彼得一世亲手筹建的」，画面上必须同时有
  近卫团的视觉载体与彼得一世肖像，而不是一个人站在空操场上。

### 4.3 `overlay_plan`：地图镜头的叠加层不得为空

- `device='map_anim'` 时 `overlay_plan` **必须非空**。把一张地图平铺推拉不是地图动画，
  那正是本项目要消灭的错误。
- 图层类型只能取 `polygon`（范围高亮）、`polyline`（河流/路线/箭头）、`marker`（地点）、
  `label`（地名/年代文字）、`card`（姓名条/年份卡）、`image`（内嵌小图）。
- 每层尽量带 `anchor:{asset_id, semantic_id}`（与 `must_show` 指向同一条语义项），
  再用 `reveal_at`（秒）排出显现顺序：旁白先说哪个，哪个先出现。
- 「同时」「分两路」这类并列关系靠**同一时间点出现两层**表达；「先…后…」靠 `reveal_at` 拉开。
- 需要从全图推到局部时用 `viewport:[x,y,w,h]`（归一化 0–1）。

### 4.4 `deterministic`：不要自己定默认值

片段位置由程序按 device 查表决定（`map_anim/archival/card/reenact_still` → `replace`，
`reenact_video` → `none`）。只有 `reenact_video` 允许你建议 `pre`/`post`（在模型视频前/后拼一小段
确定性片段）。其余情况**不要写这个字段**；越界的取值会被服务端丢弃并回落默认值。

### 4.5 叙事段上下文

- 调 `read_storyboard_context` 时同时读前后镜的 `intent`。同一叙事段（同一张底图上的连续几镜）
  必须**共用同一张证据素材**，只改图层状态：S01 出三方范围、S04 出河流、S07 出路线，
  而不是每镜换一张地图。
- 后一镜要承接前一镜时，在 `rationale` 里写明承接了什么（「接前镜已出现的船队，本镜只把目的地标出来」）。

## 5. 时长与节拍

- `duration` = 本镜旁白字数 ÷ **4.5 字/秒** + **0.8 秒**尾部留白，钳到 **4–15 秒**；无旁白的纯画面镜头取 4–6 秒。
- 剧本里的 `【节拍名】` 标记是硬切边界：一镜不得跨节拍。
- 不要为了凑时长把两个信息点塞进一镜，也不要把一句话拆到两镜去念。
