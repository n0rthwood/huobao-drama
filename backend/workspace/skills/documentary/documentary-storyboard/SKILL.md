# 纪录片项目：分镜拆解附加规范（两栏脚本）

叠加在 `storyboard-breaker` 基础规范之上，冲突时**以本文件为准**。

纪录片分镜是**两栏脚本**：左栏旁白（讲什么），右栏画面（看什么）。两栏一一对应，同一镜内必须讲同一件事。

## 1. 旁白栏 = 剧本正文逐字照抄（硬规则）

本项目的剧本正文**就是旁白稿**。拆镜时按顺序把正文切成段，逐段**原样**写进 `narration_text`：

- **逐字照抄**：标点、年份、人名、地名、数字全部与原文一致。不改写、不润色、不缩写、不补字。
- **按句切**：只能在句号 / 问号 / 感叹号 / 分号之后切开，不许在半句处断。
- **不新增、不丢段**：正文每一段都要落到某一镜；全集 `narration_text` 顺序拼接后应当等于剧本正文。
- 每镜 **≤80 字**（语音合成单段硬上限）。原文某段超过 80 字，就在句界处拆成相邻两镜。
- 纯画面镜头（空镜、过渡、地图定场）允许没有旁白：`narration_text` 留空即可，不要为它编一句解说。
- 工具会校验：`narration_text` 必须能在剧本正文中逐字找到，且顺序与正文一致；改写过的文本会被**拒存**。

## 2. 画面栏 = `description` 只写画面（硬规则）

- `description` 里**不写旁白文字**，不写「旁白：…」。旁白有独立字段，双写会被念两遍。
- 纪录片**没有对白**：禁止 `角色名：「台词」`，禁止让画面里的人物开口说解说词。
- `description` 写观众实际看到的：主体、动作、镜头内的变化（展开的地图、行进的队列、翻动的文书）。

## 3. 每镜一个信息点

拆镜的边界由**信息点**决定，不是由时长决定：一镜讲清楚一件事，讲完就切。

每一镜在 `title` 里用一句话写明本镜的信息点（「额尔齐斯河是唯一水道」「近卫团出身决定了指挥权」），
画面必须**能把这个信息点显示出来**：

- 讲**地理 / 路线 / 范围** → 画面是地图，并写明图上要显示什么（河流、湖泊、城寨、行军方向）；
- 讲**人物身份 / 来历** → 画面要带出身份符号（戎装、绶带、印信、仪仗），不是一个人站在空院子里；
- 讲**年代 / 数字 / 条约名** → 画面要有可读的实物载体（文书、碑刻、器物）或可被图形强调的对象；
- 讲**事件经过** → 画面是具体动作的一瞬，不是抽象运镜。

信息点与画面对不上，就**改画面**，不要改旁白。

> 本节是骨架。完整的表达设计（device 枚举、`must_show` 校验、叠加层计划 `overlay_plan`、
> 确定性片段）在后续版本补齐；在那之前，把信息点写进 `title`，把要显示的内容写进 `description`。

## 4. 时长与节拍

- `duration` = 本镜旁白字数 ÷ **4.5 字/秒** + **0.8 秒**尾部留白，钳到 **4–15 秒**；无旁白的纯画面镜头取 4–6 秒。
- 剧本里的 `【节拍名】` 标记是硬切边界：一镜不得跨节拍。
- 不要为了凑时长把两个信息点塞进一镜，也不要把一句话拆到两镜去念。
