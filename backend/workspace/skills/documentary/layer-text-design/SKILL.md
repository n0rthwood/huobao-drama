# 模板文本框：类型 × 成套位置 × 容量

叠加在 `documentary-storyboard` 之上，只讲**屏幕文字**：图层段里不锚定在底图上的排版文字。
地图上的点、线、面名称仍然用锚定标注（`marker` / 带 `anchor` 的 `label`），不在本规范范围内。

## 1. 你只能填两件事：类型与字段

- 每一条屏幕文字 = `planned_layers` 里的一个条目 `{ type: 'text', role, fields, at_s }`。
- `role` 逐字取自 `read_storyboard_context` 返回的 `text_spec.roles`；
  `fields` 的键逐字取自该 role 的 `fields[].key`（列表字段给字符串数组）。
- 有文本框的镜必须同时给出 `layer_plan.text_layout`，逐字取自 `text_spec.layouts[].id`。
- 位置 `x/y`、字号、颜色、字体、底板都不许写；`card` 类型不再接受；`label` 只用于钉在底图语义位置上的文字（必须带 `anchor`）。
- 容量一律从 `text_spec.capacity[text_layout][role]` 读：`chars_per_line × max_lines` 是这一套这个字段的基准容量，
  列表字段另有 `max_items`；`chars_per_line_at_min` 只是缩到下限时的兜底，**不能当常规容量**。
  不要凭印象估字数，也不要沿用别套别的类型的数字。
- 同一 role 可以在不同拍重复出现（两个不同时间点的 `heading`），但不能在同一拍出现两次。

## 2. 类型边界（先按信息类别选，再按容量确认）

- `date` 时间锚：一个可核实的时间坐标（「公元前207年11月14日」「1872年」）；必要时年号与公历并列。
  **纯时间坐标只能用 `date`**，不许借 `metric` 或 `keyword` 放大年份、朝代、时间段。`sub` 只写时代补充。
- `heading` 主题标题：名词短语或判断短句；`sub` 只写地点、类别或段落，不复述标题与时间。
- `statement` 事实说明：一句可独立理解的主谓事实；`sub` 写限定条件。
- `keyword` 概念落点：一个短概念（2—8 字量级，上限看容量），只在概念必须被记住时使用，不能拿来放大普通句子。
- `quote` 引文：只放原句、史料或提问；`main` 必须保留成对引号，`sub` 只写可核实的人名、书名或地点。
  解释句、概述句不是引文。
- `metric` 数据：`main` 只放数字与紧随单位（不可拆行）；对象、口径、比较写进 `sub`。没有图表不伪造比例。
- `bullets` 列表：最多三条，同级语法完全平行，按时间或逻辑顺序排列；不要混入不同句法的关系句。
- 不上屏：无来源的精确年份、长旁白、情绪化口号、无法核实的细节、地图上的点线面名称。
- Poster 另有三个专用类型（`poster_project` / `poster_title` / `poster_details`），只在 Poster 构想里用，分镜设计卡里不能出现。

## 3. 写作规则（提交前逐条自检）

1. 只上屏能帮助理解**时序、因果、规模、定义或画面对象**的信息；旁白已经讲清楚的细节不再重复一遍。
2. 内容必须有来源：`info_points`、已核实的事实，或旁白里可直接核实的话。不编造数字、年代、地点。
3. `statement.main` 里出现**两个或以上 `、` / `；`** 的并列，一律转成 `bullets` 或拆成多拍。
4. 同拍不同框的任意字段：完全相同，或**连续 6 个字以上重复**即被阻断；相邻拍不同框出现同样的重复会被警告，
   也必须避免。同一框的时间锚可以持续显示；其余情况下一拍必须换新口径、换角度，或者留空。
5. 装不下的处置顺序只有三步：**改短 → 拆拍（不同 `at_s`）→ 换更合适的类型**。
   自动缩小只是兜底，不能当作常规容量使用。
6. 数字与紧随的单位（年/月/日、石/里/吨/℃…）不拆行；标点不出现在行首。
7. 宁可留白、换套、少写一句，也不要把文字塞满画面。

## 4. 选套：先看底图，再看套

`text_spec.layouts` 给出本画幅的若干套，每套有槽位 `{ role, zone }`。zone 的含义：

- `context`：只有 `date`（时间锚），可以和一个主信息框同屏；
- `primary`：`heading` / `statement` / `quote` / `metric` / `bullets`，**互斥**——同一拍只能出现一个；
- `emphasis`：`keyword`，只在概念必须被记住时叠加。

选套前必须先读底图（必要时 `read_image`），在画面描述里标出：人物面部与躯干中轴、建筑主轴、
道路或城墙的行进线、图表绘图区、空白区。

- 主体在右、左侧有留白 → 选左侧的套；主体在左、右侧有留白 → 选右侧的套；
- 主体居中、上部留白 → 选上中或顶部的套；图表或主体在上中、右中 → 选左下的套；
- 文本板、渐变、装饰都不得压人物面部、躯干中轴、建筑主体或图表 bbox；
- 底图主体位置说不清时先读图，不要默认套。

## 5. 同屏与节奏

- 视频默认**一拍一个主信息框**；允许 `date + primary`，或 `date + primary + keyword`。
- **同 zone 后出现的框替换先出现的**：`heading`（2s）之后 `statement`（4s）出现，2s 的标题就被顶掉，
  这是同一条主叙事线；`date` 在 `context` 区，下一个时间锚出现时才换；`keyword` 在 `emphasis` 区同理。
  所以同一条叙事线的多个 primary 框**必须用不同的 `at_s`**。
- 同一个 `at_s`（同一时刻出现）的框互不替换：同一 zone 里同时出现两个框会被阻断，必须错开时间或合并成一条。
- 时间锚在事实落地前 0.3—0.8 秒出现；标题跟着关键名词；事实、数据、引文在旁白说出来时出现。
- 单条约 ≥1.2 秒，两行说明约 ≥2 秒：`at_s` 落在实测配音的时间轴上，后一句的信息不能先出现，
  前一句也不能拖到下一句之后才出现。
- `at_s` 不得超过本镜的 `budget.layer_s`。

## 6. 提交流程

1. `read_storyboard_context`：读 `text_spec`（`layouts` / `roles` / `capacity`）、本镜旁白、底图与资产语义。
2. 先决定这一镜要让观众记住的信息点（`info_points`），再决定哪些落在屏幕文字、哪些交给生成段、
   哪些只由旁白承担。
3. 按第 4 节选套，按第 2 节选 role，按第 3 节与 `capacity` 写字段。
4. 逐条过第 3、5 节的自检（容量、并列、重复、时间）。
5. 调用 `update_storyboard` 保存整张设计卡。工具会按同一套规则复核，拒绝信息里会带上
   该套该类型每个字段的容量数字，按它改正后重试。

## 7. 失败处置

- 容量放不下：改短 → 拆拍 → 换到更宽的套 → 换类型。四步都试过仍放不下，说明这条信息不适合上屏，
  退回旁白或生成段。
- 没有可用槽位（例如主体占满整幅画面）：不要硬塞文字，改用不依赖屏幕文字的表达，并在 `rationale` 里说明。
- 缺事实、缺出处、缺 bbox：不要编；缩到能核实的部分，或放弃这条文字。
- 工具返回文本框问题（`text_plan_issues` / 溢出、缺字段、同拍冲突）：按返回的具体字段与容量改正后重试；
  不要删掉文本框改回 `label` / `card`，不要改走旁白绕过。

## 8. 例子

合格：

- 底图右侧是立像、左侧大片留白 → 选左侧的套；`date.main` 写「1872年」，`heading.main` 写「轮船招商局创办」。
- 旁白「条石为基、青砖包砌、顶宽五马并行」 → `bullets.items` 三条同级短语，而不是塞进一句 `statement.main`。
- 「5730 年」这种唯一数字 → `metric.main = '5730年'`，口径写进 `sub`。

不合格：

- 用 `card` 写「序章」，或用没有 `anchor` 的 `label` 做屏幕标题 —— 工具直接拒绝。
- `date.main` 写「同治十一年（1872年）·轮船招商局创办」 —— 时间锚只放时间，主题进 `heading`。
- 相邻两拍都写「轮船招商局」 —— 相邻拍重复，第二拍必须换新信息。
- 把一长段旁白抄成 `statement.main` —— 先改短，仍然放不下就拆拍。
- 同一个 `heading` 在一拍里写两条 —— 同槽位同拍重复。
