# 纪录片 / 历史题材：提取附加规范（叠加在 extractor 基础规范之上）

本技能只在项目题材被判定为纪录片/历史片时注入。基础提取规范全部继续生效，**本文件是对它的加严与补充**；两者冲突时以本文件为准。

## 一、先懂字段怎么流动，再决定内容写哪

火宝的资产字段在「提取 → 提示词 → 生图」三环节被读取的方式不同，内容必须按流向分配：

| 字段 | 谁读 | 结论 |
| --- | --- | --- |
| `appearance` / `styling` | 提示词 Agent **和**生图兜底提示词都读，直接进画面 | **可画的东西只有写在这里才画得出来** |
| `description` | 只有提示词 Agent 读（兜底在 appearance 为空时才用它） | 写身份背景、势力、年代、叙事作用 |
| `role` | 展示与提示词 Agent 读，不进兜底提示词 | 只写**短身份标签** |

所以：**一切可穿戴、可持有、肉眼可见的身份符号，必须落在 `appearance` / `styling`**；身份的来历与作用写 `description`；`role` 保持短。

## 二、角色字段的纪录片写法

- **role**：短身份标签，不超过 12 个字，形如「沙皇 · 谕令签发者」「清朝皇帝 · 决策者」。不写长句、不写生平。
- **description**：1–3 句，必须包含 ① 身份与地位 ② 所属势力/朝代/国家 ③ 年代（本集事件发生时此人的处境与年龄段）④ 在本集中的叙事作用。
- **appearance**：静态可见特征——年龄感、体态、脸型、五官、发型、髭须形状。历史人物按已确证的画像特征写（髭形、发际、脸型轮廓、是否蓄须），不写情绪与动作。
- **styling**：**至少 2 项可穿戴或可持有的身份符号**，逐项写死款式与颜色。可用的符号类别：
  冠冕 / 头饰 / 发辫形制、绶带与勋章、胸甲与戎装、朝服与补子、袍服纹样与腰带、佩剑与权杖、印信与文书、仪仗持物。
- **辨识度优先（硬规则）**：同一人物在史实上往往有多套成立的造型，**必须选其中身份辨识度最高的那套**，而不是任意一套。例：彼得一世写「胸甲戎装 + 圣安德烈蓝绶带」，不写同样属实但看着像平民的素色长外套；清代皇帝写「朝服 + 朝珠 + 朝冠」，不写便服。

## 三、三视图禁背景（反直觉但必须遵守）

角色设定图的版式是**纯白背景**的正脸特写 + 三视图。因此：

- 身份**只能**靠穿戴与持物表达；
- **禁止**用宫殿、战场、地图、旗帜、桌案、仪仗队列等背景或环境元素表达身份；
- 任何「站在冬宫前」「背后是舰队」式的描写都不要写进字段——它会被提示词 Agent 落进画面，破坏设定图版式。

## 四、史实忠实与联网求证

- 只允许使用**剧本原文**与**检索工具返回内容**中的事实。记不准、查不到的一律不写，宁可少写一项符号，也不编造。
- 历史人物、条约、机构、器物名出现时，按这个顺序求证：
  1. `wiki_search(query, subject_kind, subject_name)` 找到条目标题；
  2. `wiki_summary(title, …)` 取身份与年代；
  3. 需要服饰/仪仗细节时再 `wiki_extract(title, section='肖像'/'服饰'/'生平', …)`。
  调用时**务必传 `subject_kind` 与 `subject_name`**（名字与保存时完全一致），否则这条资料不会出现在该资产的「资料来源」里。
- 工具返回 `degraded: true` 时（检索不可用或次数用尽）：**不要重试到底**，改为只用剧本原文完成本资产，不要凭印象补史实细节。提取任务本身不因此失败。
- 每个关键历史人物至少求证一次；剧本已写死的细节不必再查。

## 五、禁止来源污染（硬规则）

`name` / `role` / `description` / `appearance` / `styling` / 场景 `prompt`、`lighting` / 道具 `description` **任何一个字段里都不得出现**：

- URL、链接、域名；
- 「据维基百科」「参见」「资料来源」「[1]」这类来源标注；
- 条目标题的引用格式。

溯源由「资料来源」记录自动保存，不需要写进字段；写进去会顺着提示词链污染最终提示词与画面。

## 六、场景的纪录片写法

`prompt` 里必须能读出三件事：

1. **年代**：建筑形制、材料工艺、陈设样式属于哪个时期（如「17 世纪末俄式木构驿站」）；
2. **地域**：地理与气候特征（如「西伯利亚针叶林边缘，冻土与积雪」）；
3. **功能**：这个空间是干什么用的（谈判厅、驿站、工坊、军帐），功能决定陈设。

并且：**不得出现任何晚于该年代的物件**——电线、沥青路面、玻璃幕墙、现代字体招牌、塑料制品一律不写。`time` 仍然必填，光影与时段一致。

## 七、道具的纪录片写法

`description` 必须包含 **年代 + 用途 + 材质工艺**（如「17 世纪末手抄羊皮纸文书，鹅毛笔书写，蜡封朱印，边缘磨损」）。器物的形制按年代写死；禁止现代加工痕迹（激光切边、机制螺丝、塑料件），除非年代本身允许。
