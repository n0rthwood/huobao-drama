# 纪录片 / 历史题材：提取附加规范

叠加在 extractor 基础规范之上，冲突时以本文件为准。工具怎么调用看工具描述，这里只写**写什么**。

## 角色

**谁该建卡（硬规则）**：解说词里被点名、且对本集事件有**决策或行动**的历史人物，一律建卡——
包括只在远方下令、本集没有正面出场的君主（如同时在南线出兵的清朝皇帝）。
不建卡的是：只被旁白一笔带过且无决策无行动的人物、后世的史家与转述者、
以及无名群体（士兵、随从、俘虏、船工）——群体写进场景与分镜，不占角色卡。

- `role`：短身份标签，≤12 字（「沙皇 · 谕令签发者」）。
- `description`：1–3 句，含 ①身份地位 ②所属势力/朝代 ③年代与此时处境 ④本集叙事作用。
- `appearance`：年龄感、体态、脸型、发型、髭须形状；历史人物按已确证的画像特征写。
- `styling`：**≥2 项可穿戴或可持有的身份符号**，逐项写死款式与颜色。符号类别：冠冕/头饰/发辫形制、
  绶带与勋章、胸甲与戎装、朝服与补子、袍服纹样与腰带、佩剑与权杖、印信与文书、仪仗持物。
- **辨识度优先（硬规则）**：一个人物有多套史实成立的造型时，选身份辨识度最高的那套。
  彼得一世写「胸甲戎装 + 圣安德烈蓝绶带」，不写同样属实却像平民的素色长外套；清帝写朝服朝珠朝冠，不写便服。

## 三视图禁背景（硬规则）

角色设定图是纯白背景。身份**只能**靠穿戴与持物表达；**禁止**把宫殿、战场、地图、旗帜、桌案、
仪仗队列等环境元素写进任何字段——它们会被提示词 Agent 落进画面，毁掉设定图版式。

## 场景

`prompt` 必须能读出 ①年代（建筑形制、材料工艺，写具体形制不写「古代风格」）②地域（地理气候植被）
③功能（谈判厅/驿站/工坊/军帐，功能决定陈设）。禁止晚于该年代的物件。
`time` 仍是**时段**（清晨/正午/黄昏/夜晚…），年代写进 `prompt`，不要把年份填进 `time`。
`lighting` 只用该年代可得的光源（日光、月光、烛火、油灯、炉火、火把），并与 `time` 一致。

## 道具

`description` 必须含 **年代 + 用途 + 材质工艺**（「17 世纪末手抄羊皮纸文书，鹅毛笔书写，蜡封朱印，边缘磨损」）。
禁止现代加工痕迹（激光切边、机制螺丝、塑料件），除非年代本身允许。

## 史实与来源（硬规则）

- 只用**剧本原文**与**检索工具返回内容**中的事实；记不准、查不到的不写，宁可少写一项符号也不编造。
- 关键历史人物按工具描述里的纪律求证一次；工具返回 `degraded` 时只用剧本原文，提取不失败。
- 任何字段里都**不得出现** URL、域名、「据维基百科」「参见」「资料来源」「[1]」等来源标注。
  溯源由「资料来源」记录自动保存。
