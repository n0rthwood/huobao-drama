# ドキュメンタリー / 歴史題材：小道具最終プロンプト追加仕様

本スキルはプロジェクトの題材がドキュメンタリー／歴史ものと判定された場合にのみ注入され、`prop-prompt` に重ねられる。基本レイアウト（白背景に単品、標準的な製品撮影のアングル、正確な比率、縁が完全、背景は物語を担わない）はすべて引き続き有効。

## 一、年代 / 用途 / 材質と工法（すべて出現必須）

プロンプトからは次が読み取れなければならない：

1. **年代**：器物の形式がどの時期に属するか（例「17 世紀末」「康熙朝」）。「古代風」ではなく具体的な形式を書く；
2. **用途**：当時それが何に使われたか（境界画定文書、測量器、信符、印章、兵器）。用途が形状の細部を決める；
3. **材質と工法**：手鍛造、鋳造、木工、羊皮紙、桑皮紙、漆、鍍金、鏨刻、蝋封など。使用痕（摩耗、酸化、折れ皺、虫食い）も併せて確定して書く。

## 二、白背景と器物の完全性（第 2 ラウンドのブラインド評価で追加したハードルール）

- **背景**：プロンプトに「純白・無影の背景、グラデーションなし、投影なし」と明記すること。第 2 ラウンドの 3 サンプルのうち 2 つが
  「白に近いが投影とグレーのグラデーションがある」と判定された。「白背景」とだけ書くのでは足りない。
- **構造の完全性**：器物の支持構造と固定構造を一項目ずつ書き出すこと。さもないとモデルは部品の欠けた継ぎはぎ物を生成する。
  長銃には「前床が銃身の全長を覆い、銃身の下に槊杖（通し棒）と槊杖溝があり、バンドで固定」と明記すること；
  第 2 ラウンドの火縄銃サンプルはこれを書かなかったため「銃身が機関部より後ろで完全に露出し、前床も槊杖もない」という成立しない構造が生成された。
- **機構は年代で確定する**：火縄銃には「側面の火挟みが緩燃性の火縄を挟み、火門と火皿がある」と書き、火打石の撃鉄と火鎌に**してはならない**；
  逆に燧発銃に火縄を書かない。機構の語を間違えると、画面に時代違いの鎖機が現れる。
- **付属品**：基本仕様は白背景に単品である。その器物と不可分の付属品（撥、鞘、ペン）だけは書いてよく、
  書くときは同一器物の付属品であることを示し、本体と同じ画面内に並べて配置すること。

## 三、時代考証（禁止項目）

- 近代的な加工痕の禁止：レーザー切断の縁、機械ねじと標準部品、射出成形部品、電気めっきの光沢面、印刷バーコード；
- 年代より後の材料の禁止（プラスチック、ステンレス、合成ゴム、現代紙の漂白された白さ）；
- 器物上の文字は当時の書体と言語でその形状を描写し、読める現代文字に**してはならない**。

## 四、史料との一致

小道具の `description` にある検証済みの形式の細部は一項目ずつ落とし込み、勝手に置き換えてはならない。形式が不確かなものは書かない方がよく、文様や銘文を捏造しないこと。

## 五、出典汚染の禁止

プロンプトに URL、ドメイン、「ウィキペディアによると」「資料出典」などの出典表記を書いてはならない。
