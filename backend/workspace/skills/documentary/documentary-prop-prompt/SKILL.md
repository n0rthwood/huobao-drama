# 纪录片 / 历史题材：道具最终提示词附加规范

本技能只在项目题材被判定为纪录片/历史片时注入，叠加在 `prop-prompt` 之上。基础版式（白底单品、标准产品摄影视角、比例准确、边缘完整、背景不承载叙事）全部继续生效。

## 一、年代 / 用途 / 材质工艺（必须全部出现）

提示词里必须能读出：

1. **年代**：器物形制属于哪个时期（如「17 世纪末」「康熙朝」），写具体形制而非「古代风格」；
2. **用途**：它在当时是做什么用的（勘界文书、测绘仪、信符、印信、军械），用途决定形状细节；
3. **材质与工艺**：手工锻打、铸造、木作、羊皮纸、桑皮纸、漆、鎏金、錾刻、蜡封等，连同使用痕迹（磨损、氧化、折痕、虫蛀）一并写死。

## 二、白底与器物完整性（第 2 轮盲评加的硬规则）

- **背景**：提示词必须明写「纯白无影背景、无渐变、无投影」。第 2 轮三件样本中有两件被盲评判为
  「近白但有投影与灰度渐变」，只写「白底」不够。
- **结构完整**：器物的承重与固定结构必须逐项写出，否则模型会生成缺件的拼接物。
  长枪必须写明「前托包覆枪管全长、枪管下有通条与通条槽、箍管固定」；
  第 2 轮的火枪样本因为没写这些，生成出「枪管自锁体之后完全裸露、无前托无通条」的不成立结构。
- **机构按年代写死**：火绳枪写「侧面火绳夹夹持缓燃火绳、火门与药池」，**不要**写成燧石击锤与火镰；
  反之燧发枪不写火绳。机构词写错，图上就会出现错代的锁机。
- **配套件**：基础规范是白底单品；允许且仅允许写该器物不可分的配套件（鼓槌、刀鞘、笔），
  写时要说明它是同一件器物的配件并与主体同框摆放。

## 三、时代考据（禁止项）

- 禁止现代加工痕迹：激光切割边、机制螺丝与标准件、注塑件、电镀亮面、印刷条码；
- 禁止晚于年代的材料（塑料、不锈钢、合成橡胶、现代纸张的漂白洁白度）；
- 器物上的文字按当时书体与语言描述其形貌，**不要**写成可读的现代文字。

## 四、与史料一致

道具 `description` 中来自检索求证的形制细节必须逐项落地，不得自行发挥替换；拿不准的形制宁可不写，也不要编造纹样与铭文。

## 五、禁止来源污染

提示词中不得出现 URL、域名、「据维基百科」「资料来源」等来源标注。
