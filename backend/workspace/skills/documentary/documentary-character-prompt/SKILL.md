# 纪录片 / 历史题材：角色最终提示词附加规范

本技能只在项目题材被判定为纪录片/历史片时注入，叠加在 `character-prompt` 之上。**版式规则一个字都不改**，本文件只规定在这个版式内写什么。

## 一、版式不可改（最高优先级）

无论题材如何，角色最终提示词必须仍然是：

```
角色设定参考图，左侧为正脸特写，右侧并列展示正面、90 度侧面、背面三张等高全身视图，…纯白背景，柔和均匀的光线，电影质感
```

- **不得**改成单帧剧照、半身像、环境人像、历史油画复刻；
- **不得**省略「正脸特写」「三张等高全身视图」「纯白背景」中的任何一句；
- 历史题材不是放弃设定图版式的理由——纪录片同样需要形象锚点。

## 二、身份只能靠穿戴与持物表达

因为背景必须是纯白，**禁止**用任何环境元素表达身份：

- 禁止：宫殿、王座、战场、舰队、地图、旗帜、帷幔、桌案、仪仗队列、建筑剪影、场景光效；
- 允许且必须写足：冠冕/头饰/发辫形制、绶带与勋章、胸甲与戎装、朝服与补子、袍服纹样、腰带与佩剑、权杖、印信与文书等**穿在身上或拿在手里**的符号。

`styling` 里记录的身份符号必须**逐项落进提示词的服装/配饰段**，不得概括成「华贵的服装」。

## 三、年代考据

- **服装段必须带年代限定词**（硬规则）：写「十八世纪初俄式墨绿色军礼服外套」而不是「墨绿色立领军官长礼服外套」，
  写「康熙朝明黄缎面朝袍」而不是「明黄色龙袍」。缺年代限定词时模型会按更晚的通行形制作画——
  第 2 轮实测：带年代限定词的样本（彼得一世）盲评无穿越物件，未带的样本（利哈列夫）被判为
  「剪裁与弯柄佩刀属 1780–1800 年」。每一件外套、帽、靴、佩器都要各自带年代限定词，不能只在开头写一次年代。
- 发型、须型、配饰的形制必须与 `description` 中的年代一致；
- 禁止出现晚于该年代的元素（现代眼镜、拉链、手表、工业印花、现代军装剪裁、后世样式的刀剑护手）；
- 不同文明的符号不得混用（清代朝服不配欧式绶带，反之亦然）。

## 四、忠实于史料画像（文本级）

当 `readCharacters` 返回 `has_archival_reference: true` 时，该角色已有入库的史料画像，其可见特征已经由提取环节文本化写进 `appearance` / `styling`：

- 脸型、发际、发型、髭须形状、是否蓄须、面部显著特征**严格按 `appearance` 原文落地**，不得美化、年轻化、改换发型或自行发挥；
- `readCharacters` 返回的 `archival_images` 给出画像路径时，可以用 `read_image` 直接看图核对（例如问「这张画像里人物的发式、髭须、朝服纹样分别是什么」），把确认到的可见特征写进提示词；看图是为了写准人物形象，不是把画像当素材；
- 不得把画像的油画笔触、画框、背景、半身构图带进提示词——**忠实的是人物形象，不是那幅画**；
- 画像本身不参与生图（它不在 `reference_images` 里）：不要在提示词里提及「油画」「肖像画」「参考画像」等字样，也不得把画像写成来源（例如「据这幅肖像画」）。

## 五、参考图引用（有参考图时必做）

`readCharacters`/`readScenes`/`readProps` 返回的 `reference_count` / `reference_images` 是该资产的参考图清单：**编号 = 列表序（资产编号，稳定身份）**，磁盘上已不存在的图会被排除，不在列表里。`description_citations` 是用户在描述字段里已引用的编号。

- **生图只发送最终提示词实际引用的那几张**（零引用则一张不发）。按需引用：用到哪张就写哪张，写法 `@参考图1`、`@参考图2`…（资产编号），每一处写清这张图提供什么；这是厂商无关写法，提交时由系统换成该模型认识的连续标签；
- **描述字段里用户已引用的参考图（`description_citations`）必须原样保留引用并写明贡献**，不得丢弃或改编号；
- 不用的参考图不必提及，也不得虚构未引用图的内容；只取参考图里的要素，不得整体照搬它的构图、画框、背景；
- `reference_count = 0`：提示词里不得出现任何参考图引用标记，也不得虚构参考图的形制与细节；
- 引用不存在的编号、或漏掉描述引用时，保存工具会拒绝并指出问题；**保存前先调用 `check_final_prompt_references` 自查**，按返回的 `will_send` / `description_citations_missing` 修正后再保存。

## 六、禁止来源污染

提示词中不得出现 URL、域名、「据维基百科」「资料来源」等任何来源标注或引用格式。

## 七、自检（保存前逐条确认）

1. 含「角色设定参考图 / 正脸特写 / 三张等高全身视图 / 纯白背景」四要素；
2. 至少 2 项可穿戴或可持有的身份符号，且与 `styling` 一致；
3. 没有任何场景、背景、环境、道具桌面元素；
4. 没有晚于年代的物件；
5. 没有 URL 与来源标注；
6. `reference_count > 0` 时每张生图参考图都被 `@参考图N` 引用并写明贡献，画像没有被写成参考图或来源。
