# ドキュメンタリー / 歴史題材：キャラクター最終プロンプト追加仕様

本スキルはプロジェクトの題材がドキュメンタリー／歴史ものと判定された場合にのみ注入され、`character-prompt` に重ねられる。**レイアウト規則は一字も変えない**。本ファイルはそのレイアウトの中で何を書くかだけを定める。

## 一、レイアウトは変更不可（最優先）

題材が何であれ、キャラクター最終プロンプトは必ず次の形でなければならない：

```
キャラクター設定参考図、左側に正面顔のクローズアップ、右側に正面・90 度側面・背面の等高全身図 3 枚を横並びで表示、…純白背景、柔らかく均一な光、シネマティックな質感
```

- 単一のスチル、バストアップ、環境ポートレート、歴史油絵の複製に**変えてはならない**；
- 「正面顔のクローズアップ」「等高全身図 3 枚」「純白背景」のいずれも**省略してはならない**；
- 歴史題材であることは設定図レイアウトを捨てる理由にならない。ドキュメンタリーにも造形のアンカーは必要である。

## 二、身分は着用物と所持品でしか表現できない

背景が純白でなければならないため、いかなる環境要素で身分を表現することも**禁止**する：

- 禁止：宮殿、玉座、戦場、艦隊、地図、旗、帷幕、机、儀仗の隊列、建築のシルエット、情景的な光の効果；
- 許可され、かつ十分に書くべきもの：冠／頭飾り／弁髪の形式、綬と勲章、胸甲と軍装、朝服と補子、袍の文様、帯と佩剣、笏・杖、印章と文書など、**身に着けている、または手に持っている**シンボル。

`styling` に記録された身分シンボルは**一項目ずつプロンプトの服装／装飾パートに落とし込む**こと。「豪奢な服装」とまとめてはならない。

## 三、年代考証

- **服装パートには年代限定語を必ず付ける**（ハードルール）：「立襟の深緑色将校用ロングコート」ではなく「18 世紀初頭ロシア式の深緑色軍礼服外套」と書き、
  「明黄色の龍袍」ではなく「康熙朝の明黄緞子の朝袍」と書く。年代限定語がないと、モデルはより後世の一般的な形式で描く——
  第 2 ラウンドの実測：年代限定語付きのサンプル（ピョートル 1 世）はブラインド評価で時代錯誤の品なし、付いていないサンプル（リハリョフ）は
  「裁断と湾曲柄のサーベルは 1780〜1800 年のもの」と判定された。外套、帽子、ブーツ、携行武器のそれぞれに年代限定語が必要であり、冒頭に一度書くだけでは足りない。
- 髪型、髭の形、装飾品の形式は `description` の年代と一致させる；
- その年代より後の要素（現代の眼鏡、ファスナー、腕時計、工業プリント、現代的な軍服の裁断、後世様式の刀剣の護拳）を出してはならない；
- 異なる文明のシンボルを混用してはならない（清朝の朝服に欧州式の綬は付けない。逆もまた同様）。

## 四、史料肖像への忠実（テキストレベル）

`readCharacters` が `has_archival_reference: true` を返す場合、そのキャラクターには登録済みの史料肖像があり、その可視的特徴は抽出工程で `appearance` / `styling` にテキスト化されている：

- 顔の輪郭、生え際、髪型、口髭の形、髭の有無、顔の顕著な特徴は**`appearance` の原文どおりに厳密に落とし込む**。美化、若返らせ、髪型の変更、独自の創作は禁止；
- 肖像画の油彩の筆致、額縁、背景、バストアップ構図をプロンプトに持ち込まない——**忠実であるべきは人物像であって、その絵ではない**；
- 肖像そのものは生成に参加しない。プロンプトに「油絵」「肖像画」「参考肖像」などの語を書かないこと。

## 五、出典汚染の禁止

プロンプトに URL、ドメイン、「ウィキペディアによると」「資料出典」などの出典表記や引用形式を書いてはならない。

## 六、セルフチェック（保存前に一項目ずつ確認）

1. 「キャラクター設定参考図／正面顔のクローズアップ／等高全身図 3 枚／純白背景」の 4 要素を含む；
2. 着用または所持できる身分シンボルが 2 項目以上あり、`styling` と一致している；
3. 情景・背景・環境・小道具の台面要素が一切ない；
4. 年代より後の品物がない；
5. URL と出典表記がない。
