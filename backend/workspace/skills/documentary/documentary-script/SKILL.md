# 纪录片项目：剧本整理附加规范（narration-first）

叠加在 `script-rewriter` 基础规范之上，冲突时**以本文件为准**。

纪录片项目的「剧本」不是戏剧剧本，而是**旁白稿**：保存下来的正文会被分镜拆解逐段原样取用，
成为每一镜的解说词（`narration_text`），再合成配音与字幕。你整理的每一个字最终都会被念出来。

## 非旁白内容（硬规则）

识别并剔除出处块、版权许可、URL/永久链接、贡献者及编辑历史、书目或引用尾注（包括 ISBN 和出版社）、模板或编辑说明，以及「不作为朗读稿」的声明。例：`参考：某书，ISBN 123` 不进入正文；可朗读的正文归属「据《异域录》记载」必须保留。

## 1. 基础规范里对纪录片失效的三条（硬规则）

- **不做「对话驱动」**：基础规范的「用对白推动情节，减少旁白」在这里**反向**——纪录片以解说词推进，
  旁白是正文而不是补充。
- **不写对白行**：任何 `角色名：（状态）台词` 格式一律禁止，也不要写「某某说道：『…』」这类代言。
  历史人物的原话只能以**解说词转述**的方式出现（「他在奏折里写道，……」），不另起对白行。
- **不写场景头**：不要 `## S01 | 内景 · 咖啡厅 | 黄昏` 这类戏剧场景头。
  `rewrite_to_screenplay` 工具返回的 instruction 里带着短剧格式说明，纪录片项目**忽略那段格式要求**，按本文件排版。

## 2. 保真（硬规则）

- **不新增事实**：不补人物、不补对话、不补心理活动、不补细节场面。原文没有的，一个字都不加。
- **年份、数字、人名、地名、官职、条约名、引文原样保留**，不改写、不近似、不换算、不翻译成今名。
- **作者归属与出处表述照抄**（「据《异域录》记载」「图理琛在回程途中写下」），不要删成无主句。
- 记不准、原文没有的，宁可少写一句，也不编造。

## 3. 排版（整理，不是改写）

整理动作只有四个：**分段、去口水、补标点、统一专名写法**。顺序一律照原文，不得重排叙事顺序。

```
【开场】
1715 年秋，彼得堡的冬宫尚未落成，沙皇彼得一世已经把目光投向东方。

北线的准噶尔与南线的清朝之间，额尔齐斯河是唯一一条能把军队送进腹地的水道。

【远征】
这一年冬天，布赫霍尔茨奉命率领近三千人，从托博尔斯克溯流而上。
```

- 用 `【节拍名】` 标记叙事节拍（开场 / 背景 / 转折 / 高潮 / 收尾等），分镜会按节拍边界切段。
- 节拍标记之外的每一个自然段都是**可直接朗读的解说段落**：
  - 每段**一个完整意思**，长度控制在 **80 字以内**（语音合成单段硬上限，超长会被分镜拒收）；
  - 段内按句号/问号/感叹号收尾，不要在半句处断段；
  - 不在段内写括号注释、镜头语言（景别/角度/运镜）、画面指示——画面由分镜写。
- 内容量与原文**基本持平**（±5%）；明显变长说明你在扩写，明显变短说明你在删事实，两者都是回归。

## 4. 步骤

1. `read_episode_script` 读原始内容。
2. `rewrite_to_screenplay` 取原文（只用 `source_content`，忽略其中的短剧格式 instruction）。
3. 按本文件整理为旁白稿。
4. 自检：没有对白行、没有场景头、没有新增事实、每段 ≤80 字、年份人名与原文逐字一致。
5. `save_script` 保存。
