# ドキュメンタリープロジェクト：脚本整理追加仕様（ナレーション第一）

`script-rewriter` の基本仕様の上に重ねられる。矛盾する場合は**本ファイルを優先**する。

ドキュメンタリープロジェクトの「脚本」は戯曲脚本ではなく**ナレーション原稿**である：保存された本文は絵コンテ分解で段落ごとにそのまま取り込まれ、
各ショットの解説（`narration_text`）となり、音声と字幕に合成される。あなたが整理した一語一語は、最終的にすべて読み上げられる。

## ナレーションではない内容（必須）

出典ブロック、著作権・ライセンス、URL・永久リンク、寄稿者・編集履歴、書誌・引用注（ISBN・出版社を含む）、テンプレート・編集上の説明、読み上げない旨の声明を識別して除く。例えば「参考：書籍、ISBN 123」は本文に入れない。一方、読み上げる本文の「旅行記によれば」のような出典表現は残す。

## 1. 基本仕様のうちドキュメンタリーで無効になる三つの規則（ハードルール）

- **「セリフ駆動」はしない**：基本仕様の「セリフで物語を進め、ナレーションを減らす」はここでは**逆**になる — ドキュメンタリーは解説で進行し、
  ナレーションは補足ではなく本文である。
- **セリフ行を書かない**：`キャラクター名：（状態）台詞` 形式は一切禁止。「誰それが言った：『…』」のような代弁も書かない。
  歴史上の人物の原語は**解説の間接引用**としてのみ現れる（「彼は上奏文にこう書いた、……」）。別のセリフ行を起こさない。
- **シーン見出しを書かない**：`## S01 | 屋内 · 喫茶店 | 夕暮れ` のような戯曲のシーン見出しは書かない。
  `rewrite_to_screenplay` ツールが返す instruction には短編ドラマ形式の説明が含まれるが、ドキュメンタリープロジェクトは**その形式指定を無視**し、本ファイルのレイアウトに従う。

## 2. 忠実さ（ハードルール）

- **事実を追加しない**：人物を補わない、台詞を補わない、心理描写を補わない、細部の場面を補わない。原文にないものは一字も加えない。
- **年代・数字・人名・地名・官職名・条約名・引用は原文どおり**。書き換えない、近似しない、換算しない、現代名に訳さない。
- **著者の帰属と出典の表現はそのまま写す**（「『異域録』によれば」「トゥリシェンは帰路の途中で書き留めた」）。主語のない文に削らない。
- 正確に覚えていないもの、原文にないものは、でっち上げるより一句少なく書く方がよい。

## 3. レイアウト（整理であって書き換えではない）

整理の動作は四つだけ：**段落分け、口水（無駄口）の除去、句読点の補完、固有名表記の統一**。順序は常に原文どおりで、叙事の順序を並べ替えてはならない。

```
【幕開き】
1715 年の秋、ペテルブルクの冬宮殿はまだ完成していなかったが、皇帝ピョートル一世の視線はすでに東方に向けられていた。

北線のジュンガルと南線の清朝の間で、イルティシ川は軍を奥地へ送り込める唯一の水路であった。

【遠征】
その冬、ブフホルツは約三千人の兵を率いてトボリスクから川をさかのぼるよう命じられた。
```

- `【拍名】` で叙事のビートを示す（幕開き / 背景 / 転換 / クライマックス / 結びなど）。絵コンテはビート境界で文を切る。
- ビートマーカー以外のすべての段落は**そのまま読み上げ可能な解説段落**である：
  - 各段落は**一つの完全な意味**だけを持ち、**80 字以内**に収める（音声合成の一段あたりのハード上限。超過すると絵コンテに拒否される）；
  - 段落は句点・疑問符・感嘆符で終え、文の途中で段落を切らない；
  - 段内に括弧注、ショット用語（サイズ／アングル／カメラワーク）、画面指示を書かない — 画面は絵コンテが書く。
- 分量は原文と**ほぼ同等**（±5%）。明らかに長いのは書き足し、明らかに短いのは事実削除で、どちらも退行である。

## 4. 手順

1. `read_episode_script` で元の内容を読む。
2. `rewrite_to_screenplay` で原文を取得する（`source_content` のみを使い、短編ドラマ形式の instruction は無視する）。
3. 本ファイルに従ってナレーション原稿に整理する。
4. 自己点検：セリフ行がない、シーン見出しがない、追加事実がない、各段落 ≤80 字、年代と人名が原文と一字一句一致。
5. `save_script` で保存する。
