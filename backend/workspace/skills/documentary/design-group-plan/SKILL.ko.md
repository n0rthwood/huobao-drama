# 다큐멘터리 스토리보드 설계: 그룹 수준 시각 계획

당신이 받는 것은 **하나의 논리 그룹**이다: 최종 내레이션 원고의 자연 문단 하나. 원저자는 한 문단으로 하나의 뜻을 표현하며,
이 문단은 이미 여러 숏으로 나뉘어 있다(각 숏은 한 문장 또는 몇 문장의 내레이션, 더빙은 완료되었고 길이는 실측값이다).

당신의 과제: **먼저 그룹 전체에 대해 한 번 시각 계획을 세운다**. 이후 숏별로 설계 카드를 채우는 단계가 당신의 계획에 따라 쓴다.
당신은 설계 카드도 프롬프트도 쓰지 않고, 5절의 JSON만 출력한다.

## 1. 왜 그룹 단위로 계획하는가

완성본은 숏 번호 기준 **하드컷**으로 이어 붙인다. 레이어 구간은 숏마다 **깨끗한 전체 화면 베이스 이미지에서 다시 시작**하고, 앞 숏에서 그린 레이어는 이어지지 않는다.
모든 숏이 “먼저 지도, 그다음 실사”를 반복하면 관객이 보는 것은: 같은 지도 → 실사 → 같은 지도 → 실사……
의 왕복, 곧 제자리걸음이다. 이것은 소재의 문제가 아니라 **그룹 단위로 통괄하지 않은** 문제다.

## 2. 두 가지 화면이 각각 무엇을 하는가(판단 기준)

- **레이어 구간 = 시각 보조와 기억의 앵커.** 내레이션만으로는 기억할 수 없는 것 — 어디에 무엇이 있는지, 강이 어떻게 흐르는지, 범위가 얼마나 되는지, 누가 누구인지, 몇 년인지 — 를
  베이스 이미지(지도 / 원본 / 기물 도해) 위에 표기하고 설명 문자를 붙여 관객의 이해와 기억을 돕는다.
  - 지리적 위치 / 범위 / 경로 / 기물을 **처음 언급**할 때: 한 숏에서 **완전히 확립**한다 — 베이스 이미지에 그것을 표기하고 설명 문자를 붙인다
    (앵커된 지명 라벨, 또는 템플릿 문자 상자).
  - **바로 이어 다시 언급**할 때 관객은 이미 개념을 갖고 있다: 필요한 것은 **짧은 힌트**, 또는 힌트 없음. 짧은 힌트의 수단:
    ① 화면 속 화면(다른 베이스 이미지 위에 작은 그림을 놓는다, `pip`); ② 조합 D: 먼저 실사를 연기하고 끝에서 지도에 착지해 결과를 못 박는다;
    ③ 내레이션에만 맡긴다(이 숏에는 레이어를 놓지 않는다). **매 숏 같은 지도를 전체 화면으로 다시 놓지 않는다**.
- **생성 구간 = 상상으로 채우는 장면, 분위기, 몰입감.** 사건의 과정, 인물의 동작, 환경의 질감. 지리 관계를 생성 구간으로 연기시키지 않는다.
- “이 일은 어느 장소에서 일어났다”는 **지도를 놓는 이유가 되지 않는다** — 거의 모든 일은 어느 장소에서 일어난다.

## 3. 구간 조합

- **A** 레이어 구간만: 위치 파악, 목록화, 계보, 연대, 문단의 마무리 프레임. 실측 30초 이하.
- **B** 생성 구간만: “무슨 일이 일어났는가”를 말한다. 이 숏에 화면에 올릴 새 항목이 없을 때의 첫 선택. 실측 15초 이하.
- **C** 레이어 구간 → 생성 구간: 먼저 위치를 잡고 장면으로. **이 숏에 화면에 올릴 새 항목이 있을 때만** 쓴다. 실측 45초 이하.
- **D** 생성 구간 → 레이어 구간: 먼저 장면을 연기하고 끝에서 결과를 지도에 되돌려 못 박는다(점령, 승리, 사상, 연대),
  또는 다음 숏을 위해 “이미지 → 이미지” 연결을 만든다(다음 숏이 같은 이미지로 시작할 때 이 숏은 D로 이미지에 멈추므로 컷이 “실사 → 이미지”가 되지 않는다). 실측 45초 이하.

## 4. 배치 규칙(서버가 하나씩 검증하며, 불합격이면 반환된다)

1. **이 그룹의 각 숏에 정확히 하나**의 `shots` 항목, 많지도 적지도 않게. “잠금”으로 표시된 숏(사람이 고쳤거나 이미 확인됨)은 주어진 조합과 베이스 이미지를 **그대로 복사**한다.
2. **조합이 실측 더빙을 수용할 것**: B ≤15초, A ≤30초, C/D ≤45초.
   15초를 넘는데 추가 항목도 없는 숏: **지도가 아닌 베이스 이미지**(기록화, 장면 정지 화면, 기물 도해) + 문자 상자의 C 또는 D를 쓰고, 지도로 돌아가지 않는다.
3. 레이어 구간(A/C/D)이 있는 숏은 `base`가 필수이며 `mode`는 `no_layer`일 수 없다. B는 `base`가 null, `mode`가 `no_layer`, 화면 속 화면을 놓지 않는다.
   베이스 이미지와 화면 속 화면에는 에셋 목록에서 **이미지가 있는** 에셋만 쓸 수 있고, 화면 속 화면은 베이스 이미지와 같은 이미지일 수 없다.
4. **회귀 컷**: 앞 숏이 같은 이미지의 레이어 구간으로 끝나지 않았는데 이 숏이 **이미 나온** 베이스 이미지로 시작한다(A 또는 C). 회귀 컷은 다음 중 하나를 만족해야 한다:
   - 이 숏에 추가 항목이 배정되어 있다(`geo_additions`에 이 숏으로 배정해 적는다);
   - **재진입**: 이 이미지의 지난 등장에서 이미 3숏 이상 지났다(한동안 비었다가, 또는 서사가 다른 선에서 돌아와 위치를 다시 잡아야 한다).
   아니면 B, D, 지도가 아닌 베이스 이미지로 바꾸거나, 다른 베이스 이미지 위에 화면 속 화면으로 힌트를 준다.
5. **같은 베이스 이미지로 연속 회귀 컷을 시작하는 것은 최대 2숏**(그룹을 넘어 세어 본다: 에셋 목록 아래에 제시되는 “앞의 숏”도 포함한다). 3숏째는 방법을 바꿔야 한다.
6. 연속한 두 숏이 같은 이미지의 레이어 구간이고, 앞 숏이 레이어로 끝나며 이 숏이 같은 이미지로 시작한다(A→A, D→A, A→C, D→C):
   이것은 **한 장면의 연속된 지도 연출**이며 회귀 컷이 아니다. 이 숏은 앞 숏에서 이미 그린 상태를 이어서(이어받기) 그리며, 처음부터 다시 그리지 않는다.
7. 목록화, 계보, 병렬 열거 같은 그룹은 긴 순수 레이어(연속 A)를 허용한다.
8. 추가 항목(`geo_additions`): 이 그룹의 내레이션에서 **처음** 나오고 화면에 올려야 하는 지명 / 수계 / 범위 / 경로 진행 구간 / 연대 / 인물이나 기물 설명.
   각 항목은 **단 하나의 숏**에 배정되고, 그 숏은 레이어 구간을 가져야 한다. 앞에서 이미 확립한 항목은 추가로 세지 않는다.
9. 지도 에셋에 `map_pip`가 있을 때: 전체 추세·범위·방위를 말할 때는 **전체도**, 특정 지리적 특징에 초점을 둘 때는 대응하는 **상세도**를 쓴다.
   상세도에는 전체도의 동반이 필요하다(같은 그룹의 인접 숏에 전체도를 두어 위치를 알려 주거나, 상세도 위에 전체도를 화면 속 화면으로 놓는다).

## 5. 출력(엄격한 JSON, 코드 블록도 설명도 없이)

```json
{
  "task": "한 문장: 관객이 이 그룹을 본 뒤 이해·기억해야 할 것",
  "geo_additions": [{ "text": "투라강과 토볼강 합류점(복격 지점)", "storyboard_id": 997 }],
  "asset_roles": [
    { "asset_kind": "prop", "asset_id": 259, "name": "西伯利亚推进据点网络图", "role": "establish",
      "establish_storyboard_id": 991, "exit_after_storyboard_id": 997, "note": "원정 경로 주도: #61에서 남하 구간을 확립, #62에서 복격 지점을 짚은 뒤 퇴장" }
  ],
  "shots": [
    { "storyboard_id": 991, "combo": "C", "base": { "asset_kind": "prop", "asset_id": 259 }, "pip": [],
      "mode": "new_items", "task": "그려진 경로를 이어받아 타길강→투라강 하구 남하 구간을 추가" },
    { "storyboard_id": 992, "combo": "C", "base": { "asset_kind": "prop", "asset_id": 269 }, "pip": [],
      "mode": "carry_only", "task": "실측 15.7초, 지리 추가 없음: 선단 판화 + 문자 상자로 밤 복격 실사로 넘어간다" }
  ],
  "junction": "앞 그룹과의 이음매: 앞 그룹은 #60의 실사로 끝나고, 이 그룹의 첫 숏은 노선도로 돌아와 새 구간을 진행한다. 컷이 성립한다"
}
```

- `role`: `establish`(이 그룹의 어느 숏에서 완전히 확립한다) / `hint`(짧은 힌트만: 화면 속 화면, D의 마무리 착지, 문자) / `background`(장면의 기조).
- `mode`: `new_items`(이 숏이 지도에 항목을 추가한다) / `carry_only`(기존 상태를 이어받거나 배경으로만 쓰고 추가하지 않는다) / `no_layer`(레이어 구간이 없다).
- `storyboard_id`는 반드시 주어진 스토리보드 ID를 쓰고, 숏 번호를 쓰지 않는다.

## 6. 예(ep 27 원정 구간, 발췌)

불합격: #59–#75의 모든 숏이 C이고 모두 「西伯利亚推进据点网络图」를 전체 화면으로 연다 — #60은 군기와 군사를 강에 수장시킨 일을 말하고, #63–#65는 같은 복격 지점의 경과를 말하며,
#70은 성 안에서 식량을 찾은 일을 말한다. 내레이션에는 새로운 지리 정보가 없는데도 매 숏 지도로 회귀 컷을 하고, 상태는 숏마다 0으로 돌아간다.

합격: #59 C로 노선도에 처음 산 넘는 경로와 겨울 주둔지를 확립; #60 B(군기, 지리 추가 없음); #61 C 이어받아 남하 구간을 추가;
#62 C 복격 지점을 짚는다(연속 회귀 컷이 상한에 도달); #63(15.7초, 추가 없음) 선단 판화 + 문자 상자의 C; #64, #65 B;
#66 C 카시리크로 향하는 전진 구간을 추가; #67 D 먼저 대치를 연기하고 끝에서 지도에 착지해 결전 지점을 못 박음; #68 B; #69 D 결과를 지도에 착지해 카시리크를 점등;
#70–#72 B; #74 C 귀로 노선을 추가; #75 A로 「출발지에서 약 90킬로미터」를 마무리.
