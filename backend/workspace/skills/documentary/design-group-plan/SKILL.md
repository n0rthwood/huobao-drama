# 纪录片分镜设计：组级视觉规划

你拿到的是**一个逻辑组**：最终旁白稿里的一个自然段。原文作者用一个段落表达一个意思，
这一段已经被切成若干镜（每镜一句或几句旁白，配音已完成，时长是实测值）。

你的任务：**先为整组做一次视觉规划**，之后逐镜填设计卡的环节会照着你的规划写。
你不写设计卡、不写提示词，只输出第 5 节的 JSON。

## 1. 为什么要按组规划

成片按镜号**硬切**拼接。图层段每一镜都从**干净、满幅的底图重新开始**，上一镜画过的图层不会延续。
如果每一镜都「先放地图、再演实拍」，观众看到的就是：同一张地图 → 实拍 → 同一张地图 → 实拍……
来回切、原地踏步。这不是素材的问题，是**没有按组统筹**。

## 2. 两种画面各干什么（判据）

- **图层段 = 视觉辅助与记忆锚点。** 单听旁白记不住的东西——某地在哪、河怎么走、范围多大、谁是谁、哪一年——
  在底图（地图 / 档案原件 / 器物图）上标出来并配说明文字，帮观众理解和记忆。
  - **第一次提到**某个地理位置 / 范围 / 路线 / 器物时：在一镜里**完整建立**——底图上标出它，并配说明文字
    （锚定的地名标签，或模板文本框）。
  - **紧接着再提到**时，观众已经有概念了：只需要**简短提示**，或者不提示。简短提示的手段：
    ① 画中画（在另一张底图上放一张小图，`pip`）；② 组合 D：先演实拍，结尾落到图上把结果钉住；
    ③ 只靠旁白（这一镜不放图层）。**不要**每一镜都把同一张图满幅再放一遍。
- **生成段 = 脑补场景、氛围、身临其境。** 事件的过程、人物的动作、环境的质感。不要用生成段演地理关系。
- 「这件事发生在某地」**不是**放地图的理由——几乎所有事都发生在某地。

## 3. 段组合

- **A** 只有图层段：定位、盘点、谱系、年代、段落收束帧。图层段是确定性渲染，**没有时长上限**。
- **B** 只有生成段：讲「发生了什么」，本镜没有新增需要落图的条目时的首选。实测 ≤15 秒。
- **C** 图层段 → 生成段：先定位再入戏。**仅当**本镜有新增条目要落图时使用。图层段没有时长上限，长旁白照常装得下。
- **D** 生成段 → 图层段：先入戏，结尾把结果钉回图上（占领、胜利、伤亡、年代），
  或为下一镜铺「图接图」的衔接（下一镜要用同一张图开场时，本镜用 D 停在图上，切点就不是「实拍 → 图」）。图层段没有时长上限。

## 4. 排布规则（服务端逐条校验，不合格会退回给你）

1. **本组每一镜恰好一条** `shots`，不多不少。标了「已锁定」的镜（人工改过或已确认）必须**照抄**给出的组合与底图。
2. **组合要装得下实测配音**：只有 B 有硬上限（整镜就是一个生成段，≤15 秒）；A/C/D 的图层段没有上限——实测更长的镜用 C 或 D，
   把余下时长交给图层段（AI 填卡时服务端会把差额自动补进 `layer_s`，只加不减）。
   超过 15 秒、又没有新增条目的镜：用**非地图底图**（档案画、场景静帧、器物图）+ 文字框的 C 或 D，而不是回到地图。
3. 有图层段（A/C/D）的镜必须给 `base`，`mode` 不能是 `no_layer`；B 的 `base` 为 null、`mode` 为 `no_layer`、不放画中画。
   底图与画中画只能用资产清单里**有图**的资产；画中画不能与底图是同一张。
4. **回切**：上一镜不是以同一张图的图层段收尾，本镜却以一张**已经出现过的**底图开场（A 或 C）。回切必须满足其一：
   - 本镜被指派了新增条目（写进 `geo_additions`，指派给本镜）；
   - **再入**：距这张图上次出现已经 ≥3 镜（隔了较久、或叙事从别的线回来，需要重新定位）。
   否则改用 B、D、非地图底图，或在别的底图上用画中画提示。
5. **同一张底图连续回切开场最多 2 镜**（跨组计数：资产清单下面给出的「前面的镜头」也算）。第 3 镜必须换做法。
6. 连续两镜都用同一张图的图层段、上一镜以图层收尾、本镜以同一张图开场（A→A、D→A、A→C、D→C）：
   这是**一场连续的地图戏**，不算回切；本镜要接着上一镜已经画出的状态继续画（承接），不要从头重画。
7. 盘点、谱系、并列枚举这类组允许较长的纯图层（连续 A）。
8. 新增条目（`geo_additions`）：本组旁白里**第一次**出现、需要落图的地名 / 水系 / 范围 / 路线推进段 / 年代 / 人物或器物说明，
   每条指派给**唯一一镜**，且那一镜必须有图层段。前面已经建立过的条目不算新增。
9. 地图资产带 `map_pip` 时：讲整体趋势/范围/方位用**全览**，聚焦某个地理特征用对应的**细节**；
   细节图需要全览配套（同组里相邻一镜用全览建立位置，或在细节底图上用全览作画中画）。

## 5. 输出（严格 JSON，不要代码块、不要解释）

```json
{
  "task": "一句话：观众看完本组应当理解/记住什么",
  "geo_additions": [{ "text": "图拉河与托博尔河交汇处（伏击点）", "storyboard_id": 997 }],
  "asset_roles": [
    { "asset_kind": "prop", "asset_id": 259, "name": "西伯利亚推进据点网络图", "role": "establish",
      "establish_storyboard_id": 991, "exit_after_storyboard_id": 997, "note": "远征路线主图：#61 建立南下段，#62 点出伏击点后退出" }
  ],
  "shots": [
    { "storyboard_id": 991, "combo": "C", "base": { "asset_kind": "prop", "asset_id": 259 }, "pip": [],
      "mode": "new_items", "task": "承接已画路线，新增塔尔吉河→图拉河口南下段" },
    { "storyboard_id": 992, "combo": "C", "base": { "asset_kind": "prop", "asset_id": 269 }, "pip": [],
      "mode": "carry_only", "task": "实测 15.7 秒、无新增地理：用船队版画 + 文字框过渡到夜伏实拍" }
  ],
  "junction": "与上一组的接缝：上一组以 #60 的实拍收尾，本组首镜回到路线图并推进新的一段，切点成立"
}
```

- `role`：`establish`（本组在某一镜完整建立它）/ `hint`（只做简短提示：画中画、D 收尾、文字）/ `background`（场景定调）。
- `mode`：`new_items`（本镜在图上新增条目）/ `carry_only`（只承接已有状态或作背景，不新增）/ `no_layer`（没有图层段）。
- `storyboard_id` 一律用给你的分镜 ID，不要用镜号。
- 资产引用一律写 `{ "asset_kind": "character" | "scene" | "prop", "asset_id": 数字 }`：地图、档案画、器物图都是 `prop`，不存在 `map` 这一类。

## 6. 示例（ep 27 远征段，节选）

不合格：#59–#75 每一镜都是 C、都以「西伯利亚推进据点网络图」满幅开场——#60 讲军纪沉河、#63–#65 讲同一个伏击点的经过、
#70 讲城里找到粮食，旁白里都没有新的地理信息，却每镜回切一次地图，状态还每镜清零。

合格：#59 C 在路线图上首次建立翻山路线与冬营地；#60 B（军纪，无新增地理）；#61 C 承接并新增南下段；
#62 C 点出伏击点（连续回切到顶）；#63（15.7 秒、无新增）用船队版画 + 文字框的 C；#64、#65 B；
#66 C 新增向喀什里克推进段；#67 D 先演对峙、结尾落图钉住决战点；#68 B；#69 D 结果落图点亮喀什里克；
#70–#72 B；#74 C 新增回程线；#75 A 收束「距出发地约 90 公里」。
