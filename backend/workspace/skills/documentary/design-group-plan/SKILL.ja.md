# ドキュメンタリー絵コンテ設計：グループレベルの視覚計画

あなたが受け取るのは**一つの論理グループ**である：最終ナレーション原稿の一つの自然段落。原作者は一段落で一つの意味を表し、
この段落はすでに複数のショットに切られている（各ショットは一句か数句のナレーション、音声は完了しており、尺は実測値）。

あなたの課題：**まずグループ全体に対して一度だけ視覚計画を立てる**。その後、ショットごとに設計カードを記入する工程があなたの計画に従って書く。
あなたは設計カードもプロンプトも書かず、第5節の JSON だけを出力する。

## 1. なぜグループ単位で計画するのか

完成映像はショット番号順の**ハードカット**でつながる。レイヤー段は各ショットごとに**きれいな全画面のベース画像からやり直し**になり、前ショットで描いたレイヤーは引き継がれない。
各ショットが「まず地図、それから実写」を繰り返すと、観客が見るのは：同じ地図 → 実写 → 同じ地図 → 実写……
の往復になり、その場で足踏みしているだけになる。これは素材の問題ではなく、**グループ単位で統括していない**ことの問題である。

## 2. 二種類の画面がそれぞれ何をするか（判断基準）

- **レイヤー段 = 視覚補助と記憶のアンカー。** ナレーションだけでは覚えられないもの——どこに何があるか、川がどう流れるか、範囲はどれほどか、誰が誰か、何年か——を、
  ベース画像（地図 / 原本 / 器物図）の上に示し、説明文字を添えて、観客の理解と記憶を助ける。
  - 地理的位置 / 範囲 / 経路 / 器物を**初出**するとき：一つのショットで**完全に確立**する——ベース画像の上にそれを示し、説明文字を添える
    （アンカーした地名ラベル、またはテンプレート枠）。
  - **直後に再言及**するとき、観客はすでに概念を持っている：必要なのは**短い提示**だけで、場合によっては提示も不要。短い提示の手段：
    ① ピクチャー・イン・ピクチャー（別のベース画像の上に小図を置く、`pip`）；② 組み合わせ D：まず実写を演じ、最後に図に落として結果を釘付けする；
    ③ ナレーションだけに任せる（このショットはレイヤーを置かない）。**毎ショット同じ図を全画面で出し直してはならない**。
- **生成段 = 想像で補う場面、雰囲気、臨場感。** 出来事の過程、人物の動作、環境の質感。地理関係を生成段で演じさせない。
- 「この出来事はある場所で起きた」は**地図を出す理由にならない**——ほとんどすべての出来事はどこかで起きている。

## 3. 段の組み合わせ

- **A** レイヤー段のみ：位置づけ、棚卸し、系譜、年代、段落の収束フレーム。実測 30 秒以内。
- **B** 生成段のみ：「何が起きたか」を語る。本ショットに画面へ落とす追加項目が無いときの第一選択。実測 15 秒以内。
- **C** レイヤー段 → 生成段：まず位置づけ、それから場面へ。**本ショットに画面へ落とす追加項目があるときだけ**使う。実測 45 秒以内。
- **D** 生成段 → レイヤー段：まず場面を演じ、最後に結果を図に戻して釘付けする（占領、勝利、死傷、年代）、
  または次のショットのために「図 → 図」の接続を用意する（次のショットが同じ図で始まるとき、本ショットは D で図に止め、切れ目を「実写 → 図」にしない）。実測 45 秒以内。

## 4. 配置ルール（サーバが一つずつ検証し、不合格は返却される）

1. **本グループの各ショットにちょうど一つ**の `shots` 項目、過不足なし。「ロック済み」と記されたショット（人が変更した、または確認済み）は、与えられた組み合わせとベース画像を**そのまま写す**。
2. **組み合わせが実測音声を収容できること**：B ≤15 秒、A ≤30 秒、C/D ≤45 秒。
   15 秒を超え、しかも追加項目が無いショット：**地図以外のベース画像**（档案画、場面の静止画、器物図）＋ 文字枠の C または D を使い、地図には戻らない。
3. レイヤー段（A/C/D）を持つショットは `base` が必須で、`mode` を `no_layer` にしてはならない。B は `base` が null、`mode` が `no_layer`、ピクチャー・イン・ピクチャーを置かない。
   ベース画像とピクチャー・イン・ピクチャーには、アセット一覧の中で**画像を持つ**アセットだけを使え、ピクチャー・イン・ピクチャーはベース画像と同じ一枚にはできない。
4. **回切**：前のショットが同じ図のレイヤー段で終わっていないのに、本ショットが**すでに現れた**ベース画像で始まる（A または C）。回切は次のいずれかを満たすこと：
   - 本ショットに追加項目が割り当てられている（`geo_additions` に本ショットへ割り当てて書く）；
   - **再入**：この図の前回の登場からすでに 3 ショット以上経っている（しばらく間が空いた、または語りが別の線から戻り、位置づけをやり直す必要がある）。
   どちらも満たさない場合は B、D、地図以外のベース画像に変えるか、別のベース画像の上にピクチャー・イン・ピクチャーで提示する。
5. **同じベース画像で連続して回切の開始になるのは最大 2 ショット**（グループを跨いで数える：アセット一覧の下に示される「前のショット」も含む）。3 ショット目はやり方を変えなければならない。
6. 連続する二つのショットが同じ図のレイヤー段で、前のショットがレイヤーで終わり、本ショットが同じ図で始まる（A→A、D→A、A→C、D→C）：
   これは**一続きの地図の場面**であり、回切には当たらない。本ショットは前のショットがすでに描いた状態から描き続け（引き継ぎ）、最初から描き直さない。
7. 棚卸し、系譜、並列の列挙のようなグループは、長めの純レイヤー（連続 A）を許す。
8. 追加項目（`geo_additions`）：本グループのナレーションで**初出**し、画面に落とす必要がある地名 / 水系 / 範囲 / 経路の前進区間 / 年代 / 人物や器物の説明。
   各項目は**ただ一つのショット**に割り当て、しかもそのショットはレイヤー段を持たなければならない。すでに前で確立した項目は追加に数えない。
9. 地図アセットが `map_pip` を持つ場合：全体の趨勢・範囲・方位を語るときは**全体図**、ある地理的特徴に焦点を当てるときは対応する**詳細図**を使う。
   詳細図には全体図の同伴が必要（同じグループの隣接ショットに全体図を置いて位置を示す、または詳細図の上に全体図をピクチャー・イン・ピクチャーで置く）。

## 5. 出力（厳格な JSON、コードブロックも説明も不要）

```json
{
  "task": "一文：観客がこのグループを見終えたときに理解・記憶すべきこと",
  "geo_additions": [{ "text": "トゥラ川とトボル川の合流点（伏撃点）", "storyboard_id": 997 }],
  "asset_roles": [
    { "asset_kind": "prop", "asset_id": 259, "name": "西伯利亚推进据点网络图", "role": "establish",
      "establish_storyboard_id": 991, "exit_after_storyboard_id": 997, "note": "遠征経路の主図：#61 で南下区間を確立、#62 で伏撃点を示して退出" }
  ],
  "shots": [
    { "storyboard_id": 991, "combo": "C", "base": { "asset_kind": "prop", "asset_id": 259 }, "pip": [],
      "mode": "new_items", "task": "描かれた経路を引き継ぎ、タギル川→トゥラ川河口の南下区間を追加" },
    { "storyboard_id": 992, "combo": "C", "base": { "asset_kind": "prop", "asset_id": 269 }, "pip": [],
      "mode": "carry_only", "task": "実測 15.7 秒、地理の追加なし：船団版画 ＋ 文字枠で夜の伏撃実写へ移る" }
  ],
  "junction": "前のグループとの接縫：前のグループは #60 の実写で終わり、本グループの初ショットは路線図に戻って新しい区間を進める。切れ目は成立する"
}
```

- `role`：`establish`（本グループのいずれかのショットで完全に確立する）/ `hint`（短い提示だけ：ピクチャー・イン・ピクチャー、D の末尾着地、文字）/ `background`（場面の基調）。
- `mode`：`new_items`（本ショットが図に項目を追加する）/ `carry_only`（既存の状態を引き継ぐか背景にするだけで追加しない）/ `no_layer`（レイヤー段が無い）。
- `storyboard_id` は与えられた絵コンテ ID を必ず使い、ショット番号は使わない。

## 6. 例（ep 27 遠征の段、抜粋）

不適格：#59–#75 のすべてのショットが C で、すべて「西伯利亚推进据点网络图」を全画面で開く——#60 は軍紀と兵を川に沈めた件を語り、#63–#65 は同じ伏撃点の経過を語り、
#70 は城内で糧食を見つけたことを語る。ナレーションに新しい地理情報は無いのに、毎ショット地図に回切し、しかも状態は毎ショットゼロに戻る。

適格：#59 C で路線図上に初めて山越えの経路と冬営地を確立；#60 B（軍紀、地理の追加なし）；#61 C 引き継いで南下区間を追加；
#62 C 伏撃点を示す（連続回切は上限に達する）；#63（15.7 秒、追加なし）船団版画 ＋ 文字枠の C；#64、#65 B；
#66 C カシュリクへ向かう前進区間を追加；#67 D まず対峙を演じ、最後に図に落として決戦点を釘付け；#68 B；#69 D 結果を図に落としてカシュリクを点灯；
#70–#72 B；#74 C 帰路の線を追加；#75 A「出発地から約 90 キロ」で収束。
