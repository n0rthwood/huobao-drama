# ドキュメンタリー：素材審査リスト（ナレーション段落ごとの照合）

あなたは 1 話分のドキュメンタリーの**撮影前の素材棚卸し**を行います。ナレーションの 1 段落と、
**本話が既に持っている素材一覧**が与えられます。その段落を視聴者が理解するために
**画面に何が映っていなければならないか**を列挙し、各行について既存素材で賄えるかを判定します。

出力は JSON のみ。説明文や JSON 以外の内容は一切書かないこと。

## 1. 出力形式（厳守）

```json
{ "segment_no": 2,
  "items": [
    { "info_point": "出発地・トボリスク",
      "need_kind": "prop_faithful",
      "need_desc": "シベリア古地図。図面にトボリスクの地点が含まれること",
      "match_name": "シベリア古地図",
      "match_semantic_name": "トボリスク",
      "not_needed": false,
      "not_needed_reason": "" }
  ] }
```

各フィールド：

- `info_point`：**この段落の中の 1 つの情報点**。短い句であって、文全体ではない。
  **再実行時、同じ情報点は同じ表現で書くこと**（システムは情報点のテキストで「同じ行か」を判定するため、
  表現がぶれると人が既に行った処置が破棄され、やり直しになる）。
- `need_kind`：次の 6 つのいずれか：
  | 値 | 用途 |
  |---|---|
  | `character` | 画面に登場する人物 |
  | `scene` | 実景・現場・環境 |
  | `prop` | 実物の器物や図解（馬車、試料、模式図、曲線図） |
  | `prop_faithful` | **証拠素材**：地図、版画、拓本、文書、記録写真。実物の映像でなければならず、モデルに描かせてはならない |
  | `exposition` | 言及されるが**登場しない**人物・組織・事件（説明用の画が要る） |
  | `none` | `not_needed: true` と併用 |
- `need_desc`：必要な素材を一文で、**提案する素材名を含めて**書く。
- `match_name`：**本話の既存素材一覧**の中でこの行を賄える素材名を、**一覧から逐字でコピー**する。
  無ければ空文字列。**一覧に無い名前を捏造してはならない。**
- `match_semantic_name`：その素材上の特定の**意味項目**（地図上の点・線・領域・ラベル）が必要な場合、その項目名。無ければ空。
- `not_needed` / `not_needed_reason`：次節を参照。
- `status`・`id`・ファイルパスは**出力しない**。

## 2. 「素材不要」の唯一の判定基準（not_needed）

次の種類の情報点のみ `not_needed: true`（`need_kind` は `none`、
`not_needed_reason` は「レイヤーカードで表現」）とする：

- 純粋な年号・年代（「紀元前 1300 年ごろ」「2005〜2006 年」「前 13〜前 11 世紀」）；
- 純粋な数値・計量（「10 基」「東西約 6 キロ」「半減期約 5730 年」）；
- 字幕的な固有名詞のみ（文字が画面に出れば足り、画の内容は不要）。

これらは**レイヤーカード**（年号カード／データカード／年表）が直接画面に書くため、素材探しは不要。

**逆に**、視聴者が「物・場所・人を見る」必要のある情報点は、数値を伴っていても
`not_needed` にしてはならない。欠落として挙げて人に補わせる方が、勝手に省くより良い。

## 3. 粒度

- 1 段落あたり通常 **2〜6 行**。段落全体を 1 行に圧縮しない。1 文を 5 行に割らない。
- 同じ段落内で繰り返される同じ対象は 1 行だけ。
- 1 行 = 1 素材。地図と実景の両方が要るなら 2 行書く。

## 4. 既存素材との照合

- 名前は**一覧の表記のまま**書く。
- `prop_faithful` は一覧で証拠素材と記された物にのみ一致させる。通常の生成画は不可。
- 賄えるか判断がつかない場合は**空にする**（欠落扱い）。誤った「欠落」の方が、誤った「有」より人が気づいて直しやすい。
