# 纪录片 / 历史题材：场景最终提示词附加规范

本技能只在项目题材被判定为纪录片/历史片时注入，叠加在 `scene-prompt` 之上。基础版式（固定机位广角建立镜头、前/中/后景分层、无人物、必须原样写出 `time`）全部继续生效。

## 一、年代 / 地域 / 功能三要素（必须全部出现）

提示词里必须能读出：

1. **年代**：建筑形制、结构材料、工艺与陈设样式所属的时期（如「17 世纪末俄式原木构造」「清代官式木构」），写具体形制而不是「古代风格」；
2. **地域**：地理、气候、植被、土壤或城市肌理（如「西伯利亚针叶林边缘，冻土与残雪」）；
3. **功能**：这个空间用来做什么（谈判厅 / 驿站 / 工坊 / 军帐 / 档案库），功能决定核心陈设与它们的固定相对位置。

## 二、时代考据（禁止项）

不得出现晚于该年代的任何元素：

- 电线、电灯、空调、金属窗框、玻璃幕墙、沥青路面、水泥路缘、斑马线；
- 塑料、不锈钢、现代五金、机制标准件；
- 现代字体招牌、印刷海报、现代交通工具。

材料与工艺要与年代匹配：手工锻造的铁件、手刨木料、夯土与石砌、油灯/烛火/炉火等时代光源。

**使用痕迹是硬规则**：建筑与陈设必须写出风化与使用的痕迹——原木灰化开裂、斧劈面而非锯切平面、
苔痕与水渍、泥脚与车辙、烟熏痕、磨亮的门槛与把手。不写这些，模型会画出崭新的复建景点：
第 2 轮的「亚梅什盐湖堡」样本就被盲评判为「墙体原木过于新鲜、锯切面平直、无风化与苔痕，
与旁边风化的船形成年代反差，像复建景点而非同期实景」。

## 三、光源与氛围

`lighting` 按该年代**真实可得的光源**描写：日光、月光、烛火、油灯、炉火、火把。禁止现代灯具与人工色光。光线仍必须与 `time` 一致。

## 四、禁止项（与基础规范叠加）

- 任何人物（含背影、剪影、倒影、画中人）——基础规范的最高优先级规则继续生效；
- 可读的现代文字、水印、签名；
- URL、域名、来源标注。
