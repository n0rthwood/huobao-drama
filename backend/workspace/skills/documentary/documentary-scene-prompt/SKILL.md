# 纪录片 / 历史题材：场景最终提示词附加规范

本技能只在项目题材被判定为纪录片/历史片时注入，叠加在 `scene-prompt` 之上。基础版式（固定机位广角建立镜头、前/中/后景分层、无人物、必须原样写出 `time`、必须逐字写出 `read_scenes` 返回的 `{aspect_ratio} {composition}`）全部继续生效。

画幅是硬规则：场景图按项目画幅出图。竖构图（9:16 / 3:4）项目的建立镜头沿高度方向组织——城楼、塔、门楼、院落这类主体建筑必须**全貌完整入画、顶部不被截断**，上方留天空与屋顶纵深，下方留地面、台阶、前景陈设；横构图（16:9）按原有的左右＋纵深展开。写错方向或漏写画幅短语会被 `saveSceneFinalPrompt` 退回。

## 一、年代 / 地域 / 功能三要素（必须全部出现）

提示词里必须能读出：

1. **年代**：建筑形制、结构材料、工艺与陈设样式所属的时期（如「17 世纪末俄式原木构造」「清代官式木构」），写具体形制而不是「古代风格」；
2. **地域**：地理、气候、植被、土壤或城市肌理（如「西伯利亚针叶林边缘，冻土与残雪」）；
3. **功能**：这个空间用来做什么（谈判厅 / 驿站 / 工坊 / 军帐 / 档案库），功能决定核心陈设与它们的固定相对位置。

## 二、时代考据（禁止项）

不得出现晚于该年代的任何元素：

- 电线、电灯、空调、金属窗框、玻璃幕墙、沥青路面、水泥路缘、斑马线；
- 塑料、不锈钢、现代五金、机制标准件；
- 现代字体招牌、印刷海报、现代交通工具。

材料与工艺要与年代匹配：手工锻造的铁件、手刨木料、夯土与石砌、油灯/烛火/炉火等时代光源。

**使用痕迹是硬规则**：建筑与陈设必须写出风化与使用的痕迹——原木灰化开裂、斧劈面而非锯切平面、
苔痕与水渍、泥脚与车辙、烟熏痕、磨亮的门槛与把手。不写这些，模型会画出崭新的复建景点：
第 2 轮的「亚梅什盐湖堡」样本就被盲评判为「墙体原木过于新鲜、锯切面平直、无风化与苔痕，
与旁边风化的船形成年代反差，像复建景点而非同期实景」。

## 三、光源与氛围

`lighting` 按该年代**真实可得的光源**描写：日光、月光、烛火、油灯、炉火、火把。禁止现代灯具与人工色光。光线仍必须与 `time` 一致。

## 四、禁止项（与基础规范叠加）

- 任何人物（含背影、剪影、倒影、画中人）——基础规范的最高优先级规则继续生效；
- 可读的现代文字、水印、签名；
- URL、域名、来源标注。

## 五、参考图引用（有参考图时必做）

`readCharacters`/`readScenes`/`readProps` 返回的 `reference_count` / `reference_images` 是该资产的参考图清单：**编号 = 列表序（资产编号，稳定身份）**，磁盘上已不存在的图会被排除，不在列表里。`description_citations` 是用户在描述字段里已引用的编号。

- **生图只发送最终提示词实际引用的那几张**（零引用则一张不发）。按需引用：用到哪张就写哪张，写法 `@参考图1`、`@参考图2`…（资产编号），每一处写清这张图提供什么；这是厂商无关写法，提交时由系统换成该模型认识的连续标签；
- **描述字段里用户已引用的参考图（`description_citations`）必须原样保留引用并写明贡献**，不得丢弃或改编号；
- 不用的参考图不必提及，也不得虚构未引用图的内容；只取参考图里的要素，不得整体照搬它的构图、画框、背景；
- `reference_count = 0`：提示词里不得出现任何参考图引用标记，也不得虚构参考图的形制与细节；
- 引用不存在的编号、或漏掉描述引用时，保存工具会拒绝并指出问题；**保存前先调用 `check_final_prompt_references` 自查**，按返回的 `will_send` / `description_citations_missing` 修正后再保存。
