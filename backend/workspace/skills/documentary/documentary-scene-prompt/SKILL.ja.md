# ドキュメンタリー / 歴史題材：シーン最終プロンプト追加仕様

本スキルはプロジェクトの題材がドキュメンタリー／歴史ものと判定された場合にのみ注入され、`scene-prompt` に重ねられる。基本レイアウト（固定カメラの広角エスタブリッシングショット、前景／中景／後景のレイヤー分け、人物なし、`time` をそのまま書き出すこと）はすべて引き続き有効。

## 一、年代 / 地域 / 機能の三要素（すべて出現必須）

プロンプトからは次が読み取れなければならない：

1. **年代**：建築形式、構造材、工法と調度の様式が属する時期（例「17 世紀末のロシア式丸太構造」「清代官式木造」）。「古代風」ではなく具体的な形式を書く；
2. **地域**：地理、気候、植生、土壌または都市の肌理（例「シベリア針葉樹林の縁、凍土と残雪」）；
3. **機能**：その空間が何に使われるか（交渉の間 / 駅逓 / 工房 / 陣幕 / 文書庫）。機能が中心となる調度とその固定的な相対位置を決める。

## 二、時代考証（禁止項目）

その年代より後の要素を一切出してはならない：

- 電線、電灯、エアコン、金属サッシ、ガラスカーテンウォール、アスファルト舗装、コンクリート縁石、横断歩道；
- プラスチック、ステンレス、現代の金物、機械製の標準部品；
- 現代書体の看板、印刷ポスター、現代の乗り物。

材料と工法は年代に合わせる：手鍛造の鉄部品、手鉋の木材、版築と石積み、油灯／ろうそく／炉火などの時代の光源。

**使用痕はハードルール**：建築と調度には風化と使用の痕跡を必ず書き出す——丸太の灰化と亀裂、鋸の平滑面ではなく斧で削った面、
苔と水垢、泥汚れと轍、煤の跡、磨り減って光る敷居と取っ手。これを書かないと、モデルは真新しい復元観光地を描く：
第 2 ラウンドの「ヤムィシュ塩湖の砦」サンプルはブラインド評価で「壁の丸太が新しすぎ、鋸断面が平直で、風化も苔もなく、
隣の風化した舟と年代の落差がある。同時代の実景ではなく復元施設のようだ」と判定された。

## 三、光源と雰囲気

`lighting` はその年代に**実際に得られる光源**で描写する：日光、月光、ろうそく、油灯、炉火、松明。現代照明器具と人工的な色光は禁止。光は引き続き `time` と一致させること。

## 四、禁止項目（基本仕様に重ねる）

- いかなる人物も（後ろ姿、シルエット、水面の映り込み、絵中の人物を含む）——基本仕様の最優先規則は引き続き有効；
- 読める現代文字、ウォーターマーク、署名；
- URL、ドメイン、出典表記。
