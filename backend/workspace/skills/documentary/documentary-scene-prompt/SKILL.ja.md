# ドキュメンタリー / 歴史題材：シーン最終プロンプト追加仕様

本スキルはプロジェクトの題材がドキュメンタリー／歴史ものと判定された場合にのみ注入され、`scene-prompt` に重ねられる。基本レイアウト（固定カメラの広角エスタブリッシングショット、前景／中景／後景のレイヤー分け、人物なし、`time` をそのまま書き出すこと、`read_scenes` が返す `{aspect_ratio} {composition}` をそのまま書き出すこと）はすべて引き続き有効。

画面比率は厳格なルール：シーン画像はプロジェクトの画面比率で生成される。縦構図（9:16 / 3:4）のプロジェクトではエスタブリッシングショットを高さ方向に構成し、城楼・塔・門楼・中庭などの主体建築は**全景が完全に入り、上部が切れない**ようにする。上に空と屋根の奥行き、下に地面・階段・前景の調度を残す。横構図（16:9）は従来どおり左右＋奥行き方向に展開する。向きの誤りや画面比率の語句の欠落は `saveSceneFinalPrompt` が差し戻す。

## 一、年代 / 地域 / 機能の三要素（すべて出現必須）

プロンプトからは次が読み取れなければならない：

1. **年代**：建築形式、構造材、工法と調度の様式が属する時期（例「17 世紀末のロシア式丸太構造」「清代官式木造」）。「古代風」ではなく具体的な形式を書く；
2. **地域**：地理、気候、植生、土壌または都市の肌理（例「シベリア針葉樹林の縁、凍土と残雪」）；
3. **機能**：その空間が何に使われるか（交渉の間 / 駅逓 / 工房 / 陣幕 / 文書庫）。機能が中心となる調度とその固定的な相対位置を決める。

## 二、時代考証（禁止項目）

その年代より後の要素を一切出してはならない：

- 電線、電灯、エアコン、金属サッシ、ガラスカーテンウォール、アスファルト舗装、コンクリート縁石、横断歩道；
- プラスチック、ステンレス、現代の金物、機械製の標準部品；
- 現代書体の看板、印刷ポスター、現代の乗り物。

材料と工法は年代に合わせる：手鍛造の鉄部品、手鉋の木材、版築と石積み、油灯／ろうそく／炉火などの時代の光源。

**使用痕はハードルール**：建築と調度には風化と使用の痕跡を必ず書き出す——丸太の灰化と亀裂、鋸の平滑面ではなく斧で削った面、
苔と水垢、泥汚れと轍、煤の跡、磨り減って光る敷居と取っ手。これを書かないと、モデルは真新しい復元観光地を描く：
第 2 ラウンドの「ヤムィシュ塩湖の砦」サンプルはブラインド評価で「壁の丸太が新しすぎ、鋸断面が平直で、風化も苔もなく、
隣の風化した舟と年代の落差がある。同時代の実景ではなく復元施設のようだ」と判定された。

## 三、光源と雰囲気

`lighting` はその年代に**実際に得られる光源**で描写する：日光、月光、ろうそく、油灯、炉火、松明。現代照明器具と人工的な色光は禁止。光は引き続き `time` と一致させること。

## 四、禁止項目（基本仕様に重ねる）

- いかなる人物も（後ろ姿、シルエット、水面の映り込み、絵中の人物を含む）——基本仕様の最優先規則は引き続き有効；
- 読める現代文字、ウォーターマーク、署名；
- URL、ドメイン、出典表記。

## 五、参照画像の引用（参照画像がある場合は必須）

読み取りツールが返す `reference_count` / `reference_images` は資産の参照画像一覧です：**番号 = 一覧順（資産番号、安定した識別子）**。ディスク上に無い画像は除外されます。`description_citations` はユーザーが説明フィールドで既に引用した番号です。

- **生成では最終プロンプトが実際に引用した画像だけを送信します**（引用ゼロなら 1 枚も送らない）。必要な画像だけ `@参考图1`、`@参考图2`…（資産番号）で引用し、それぞれが何を提供するかを書き添える。表記はベンダー非依存で、送信時に連続ラベルへ自動変換される；
- **説明フィールドでユーザーが引用した画像（`description_citations`）は引用と貢献説明を必ず保持**し、削除や番号変更をしない；
- 使わない参照画像は言及不要。未引用画像の内容を捏造しない。要素のみを取り、構図・画框・背景を丸ごと写さない；
- `reference_count = 0`：引用マーカーを一切書かず、参照画像の造形や細部も捏造しない；
- 存在しない番号や説明引用の欠落は保存ツールが拒否する。**保存前に `check_final_prompt_references` で自己検査**し、`will_send` / `description_citations_missing` に従って修正する。
