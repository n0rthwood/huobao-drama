# 다큐멘터리 / 역사 소재: 장면 최종 프롬프트 추가 규범

이 스킬은 프로젝트 소재가 다큐멘터리/역사물로 판정될 때만 주입되며 `scene-prompt` 위에 덧씌워진다. 기본 판형(고정 카메라 광각 설정 숏, 전경/중경/후경 레이어링, 인물 없음, `time`을 원문 그대로 기재)은 모두 계속 유효하다.

## 1. 연대 / 지역 / 기능 세 요소(모두 나와야 함)

프롬프트에서 다음을 읽어낼 수 있어야 한다:

1. **연대**: 건축 형식, 구조 재료, 공법과 집기 양식이 속한 시기(예: 「17세기 말 러시아식 통나무 구조」「청대 관식 목구조」) — 「고대풍」이 아니라 구체적 형식을 쓴다;
2. **지역**: 지리, 기후, 식생, 토양 또는 도시 조직(예: 「시베리아 침엽수림 가장자리, 동토와 잔설」);
3. **기능**: 그 공간이 무엇에 쓰이는가(협상실 / 역참 / 공방 / 군막 / 문서고). 기능이 핵심 집기와 그 고정된 상대 위치를 결정한다.

## 2. 시대 고증(금지 항목)

해당 연대보다 늦은 어떤 요소도 나와서는 안 된다:

- 전선, 전등, 에어컨, 금속 창틀, 유리 커튼월, 아스팔트 포장, 콘크리트 연석, 횡단보도;
- 플라스틱, 스테인리스, 현대 철물, 기계제 표준 부품;
- 현대 서체 간판, 인쇄 포스터, 현대 교통수단.

재료와 공법은 연대에 맞춘다: 수작업 단조 철물, 손대패 목재, 판축과 석축, 기름등/촛불/화로불 같은 시대의 광원.

**사용 흔적은 하드 룰이다**: 건축과 집기에는 풍화와 사용의 흔적을 반드시 써야 한다 — 회색으로 풍화되어 갈라진 통나무, 톱으로 자른 평면이 아니라 도끼로 깎은 면,
이끼와 물때, 진흙과 바퀴자국, 그을음 자국, 닳아 반질거리는 문지방과 손잡이. 이를 쓰지 않으면 모델은 새것 같은 복원 관광지를 그린다:
2라운드의 「야미시 염호 요새」 샘플은 블라인드 평가에서 「벽체 통나무가 지나치게 새것이고 톱 절단면이 평직하며 풍화와 이끼가 없어
옆의 풍화된 배와 연대 차이가 나, 동시대 실경이 아니라 복원 관광지 같다」고 판정되었다.

## 3. 광원과 분위기

`lighting`은 그 연대에 **실제로 가능한 광원**으로 묘사한다: 햇빛, 달빛, 촛불, 기름등, 화로불, 횃불. 현대 조명기구와 인공 색광은 금지. 빛은 여전히 `time`과 일치해야 한다.

## 4. 금지 항목(기본 규범에 덧씌움)

- 어떤 인물도 금지(뒷모습, 실루엣, 반영, 그림 속 인물 포함) — 기본 규범의 최우선 규칙은 계속 유효하다;
- 읽을 수 있는 현대 문자, 워터마크, 서명;
- URL, 도메인, 출처 표기.
