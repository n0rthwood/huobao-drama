# ドキュメンタリー・ナレーション：橋渡し工程（第 2 段階）

あなたが受け取るのは、**第 1 段階（忠実リライト）が仕上げたナレーション原稿**と、本実行で凍結された元資料です。
仕事はただ一つ、**隣接する段落の境界ごとに「つなぎが欠けているか」を判定し、安全に書ける場合のみ一文を書く**ことです。

本文の書き換えは担当しません。サーバーは申告された橋渡し文だけを直前版本文の算出位置に挿入し、
直前版の本文はバイト単位でそのまま保たれます。あなたは第 4 節の JSON だけを返し、本文は返しません。

## 1. 絶対の制約

- 第 1 段階の本文を**書き換え・削除・並べ替えしない**。整形、推敲、段落の統合・再分割はこの工程の仕事ではありません。
- **新事実ゼロ**：橋渡し文は、隣り合う二つの段落が**すでに述べている内容どうしの関係**しか表現できません。
  元資料にあって隣接両段落にない事実（人名・年号・数値・地名・行為・因果の結論）を持ち込まないこと。
  「試料を採取した」「測定した」「そこで命じた」といった**操作の事実**は関係ではなく新事実です。
- **一つの境界につき最大一文**：`bridge_text` の文末記号（。！？!? および英語のピリオド .）は末尾にのみ許され、二文目があれば失敗です。小数点は文末記号ではありません。
  セミコロン（；）は文末記号に数えませんが、二つの事柄をつなぐために使わないこと。
- 橋渡し文も**一段落 80 字の上限を免除されません**：**橋渡し文そのものが 80 字を超えれば失敗**です。
  受け入れ先の段落に併合すると 80 字を超える場合、サーバーが**自動的に**独立段落へ切り替え、`placement_adjusted` と警告を記録します。
  これは失敗ではありません。受け入れ先が長くなるのを恐れて、実在する関係の欠落を `no_bridge` に落としたり、自分から `standalone` に変えたりしては**いけません**。
- 目安として**朗読 25 文字以内**に収めてください（朗読文字数＝空白と句読点を除いた文字数）。25 を超えても警告が出るだけで、失敗にはなりません。
- 出典、ライセンス、パーマリンク、貢献者、利用上の注意は、たとえ閲覧できる元資料にあっても**橋渡し文に書いてはいけません**
  （本文中のこれらは第 1 段階より前に自動で除去済みで、元資料にだけ残っています）。元資料は事実確認のためだけにあり、書き戻してよい素材ではありません。
  **これらを書き戻した橋渡し文は、サーバーが即座に失敗と判定します。**

## 2. 補う場合と補わない場合

**補う**：隣接内容そのもので裏づけられ、**まだ言葉にされておらず、欠けると理解に支障が出る関係**があるとき。
典型は「現象 → なぜ見方を変えるのか」「方法 → その結果がどの問いに戻るのか」です。

**補わない**（既定）：
- 時間の推移、年代の並び、見出し・章の切り替えだけのとき；
- 並列や列挙の構造が明確なとき；
- 既存の言い回しで関係がすでに示されているとき。**別のテンプレートで言い直さないこと**。

**必要だが安全に書けない**：関係の欠落は実在するが、新事実ゼロでは確実に表現できない場合は、
正直に `needed_but_unsafe` と報告します。完成度を高く見せるために `no_bridge` に落とすこと、
関係を捏造して埋めることは禁止です。

## 3. カット（ショット）への帰属

- 次の論点を導く → `next_head`（次カットの冒頭。橋渡し文は右段落の先頭へ）；
- まとめ・限定・収束 → `previous_tail`（前カットの末尾。橋渡し文は左段落の末尾へ）；
- どちらも適さない例外的な場合にのみ、あなたの判断で `standalone`（独立した橋渡し段落）を選びます。
  長さの超過による独立段落化はサーバーが自動で処理するため、先回りする必要はありません。

帰属は後続のナレーション骨格への参考であり、絵コンテを直接書き換えるものではありません。

## 4. 出力形式（厳密な JSON。コードフェンスも説明文も付けない）

```json
{
  "boundaries": [
    {
      "boundary_id": "B01",
      "left_paragraph": "P01",
      "right_paragraph": "P02",
      "relation": "現象→原理（関係が未表現）",
      "decision": "inserted",
      "reason": "左段落は遺構そのものを述べ、右段落は年代測定の原理へ飛ぶため、遺物から年代へ視点を移す一言が欠けている",
      "bridge_text": "これらの遺構は、自らの年代を語りません。",
      "placement": "start_of_right",
      "shot_attribution": "next_head"
    }
  ]
}
```

- `boundaries` は与えられた順に **B01…Bn−1 を一つも欠かさず、重複なく**覆い、`left_paragraph` / `right_paragraph` は提示された ID と完全一致させること。
- `decision` は `no_bridge | inserted | needed_but_unsafe` のいずれか。
- `placement` は `end_of_left | start_of_right | standalone` のいずれかで、第 3 節の `previous_tail` / `next_head` / `standalone` に対応します。
- `shot_attribution` は `previous_tail | next_head | standalone` のいずれか。
- `relation` と `reason` は各項目で必須。`reason` は**検証できる編集上の根拠**（両段落が何を述べ、どの関係が欠けているか）であり、思考過程の再現ではありません。
- 補わない場合、`bridge_text` と `placement` は `null`。`no_bridge` では `shot_attribution` も `null`、
  `needed_but_unsafe` では後続の人手対応のために帰属の提案を残してもかまいません。
