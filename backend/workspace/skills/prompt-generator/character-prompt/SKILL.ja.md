# キャラクター最終プロンプト（左に正面顔アップ ＋ 右に三面図）

生成するのはキャラクター設定参照図（キャラクターリファレンスシート）で、構図は固定：

- **左：正面顔アップ**——頭部と肩の正面クローズ。顔立ち、髪型、肌質が明瞭に見え、顔の識別性のアンカーとなる
- **右：正面、90度側面、背面の3枚の等身高の全身図を並べて提示**——同一キャラクターの3つの全身図を等しい高さで並べ、頭頂と足元を揃える

**中核原則：一貫性 ＞ 美しさ。** この画像は以降のすべてのキャラクター画像・動画参照のイメージアンカーであり、中立的で明瞭、再利用可能でなければならない。

## 基本イメージ vs 造型バージョン

- この三面図が示すのはキャラクターの**基本イメージ**：通常の髪型、通常の服装、通常のアクセサリーで、`styling`（基本のヘアメイク・衣装）と一致する。**単話限定の造型（バカンス服、スノーウェアなど一式の衣装）は基本イメージ図に入れない**
- 基本イメージは appearance/styling のテキストと完全に一致させること。テキストに曖昧さ（「薄いピンクまたはベージュ」）を見つけたら、まずユーザーに報告し、自分で二択を決めて生成しない
- 単話限定の造型は**造型バージョン画像**（文末参照）で扱い、絵コンテはバージョン選択の仕組みで自動的に参照する

## 出力構造（この順序でひと続きの文章に組み立てる。言語は会話言語の指示に従う）

```
キャラクター設定参照図、左は正面顔アップ、右は正面・90度側面・背面の3枚の等身高の全身図を並べて提示、
アップと全身図は同一キャラクター、全身が画面に入る、中立のAスタンス、3枚の全身図は等しい高さで並び頭頂と足元が揃う、
[年齢感 ＋ 性別感 ＋ 体つき]、[顔立ちの特徴]、[髪型]、[服装 ＋ アクセサリー]、
正面顔アップと3つの視図の顔・髪型・服装は完全に一致、
純白の背景、柔らかく均一な光、映画的質感
```

## 記述順序の規則

**最も識別性の高い特徴を前に置き**、この順序で `appearance` と `styling` の各要素を漏れなく具現化する：

1. アイデンティティのアンカー：年齢感、性別感、体つき
2. 顔立ち：輪郭、目、その他の顕著な特徴——正面顔アップは特にこの部分に依存する
3. 髪型：色、長さ、スタイル
4. 服装：デザイン、色、素材、状態
5. アクセサリー：識別性のあるものだけを書き、盛りすぎない

規則：
- **確定性**：「または」「かもしれない」などの不確定な書き方を禁止。すべての色とデザインを一度で確定させる
- キャラクターの性格は外見の雰囲気と表情の描写に変換し、性格を表す語をそのまま出さない
- 非人間キャラクターの手足の形態（指の本数、手と足が同形かどうか）を明記する。これは以降の四肢安定性の源となる情報である

## 構図と一貫性

- 左の正面顔アップ：正面をカメラに向け、中立の表情、頭頂から肩まで完全に画面に入る
- 右の3枚の全身図：正面、90度側面、背面。**等しい高さで並べ、間隔を均等に**し、頭頂と足元が同じ水平線上にある
- 「正面顔アップと3枚の全身図の顔・髪型・服装は完全に一致」と明記する
- 中立の立ち姿、自然な表情。柔らかく均一なスタジオ照明で、劇的な陰影にしない
- 会話言語の指示で指定された目標言語で出力する

## 禁止事項

- 動的なポーズ、誇張した表情、小道具を持つ、他者との同フレーム
- 身体の切れ（全身図は頭頂から足元まで完全に、アップは頭と肩が完全に）
- 文字、ラベル、ウォーターマーク、署名
- 濃い影、色付きの背景光、背景の小道具

## 造型バージョン画像（image_edit による着替え）

ある話でキャラクターに造型バージョン（styling_version）が登録された場合、**基本イメージ図**をもとに画像編集で「その衣装を着た」キャラクター画像を1枚生成する：

- プロンプトの核となる言い回し：「キャラクターの顔、顔立ち、毛色／肌色、体型、髪型を参照画像と完全に一致させたまま、服装のみを次に差し替える：[造型バージョンの description を1項目ずつ具現化]」
- 全身が完全に画面に入り、中立の立ち姿、純白の背景、柔らかく均一な光で、基本イメージ図と同じ規格
- 衣服のみを替え、顔を変えず、体型を変えず、アクセサリーを足さない（帽子・眼鏡などの付属品は小道具であり、造型バージョン画像に入れない）
- 生成後、人が画像上で「衣装が記述と一致し、顔がぶれていない」ことを確認してから絵コンテで使用する

## 参照画像の予算（ハード制約）

- キャラクター画像（造型バージョン画像を含む）は絵コンテの参照画像の供給源である：1カットあたり参照画像は最大9枚、動画生成時は先頭キーフレームが先に1枚を占めるため、シーン 1 ＋ キャラクター N ＋ 小道具 M ≤ 8
- 予算超過時は絵コンテ層が優先度で取捨する：シーン ＞ 登場キャラクター ＞ 使用される／寄りで映る小道具 ＞ 見えているだけの小道具。外された小道具は紐付けと @ 参照を同時に失うので、「@ したのに紐付けがない」名前を残さない
- 1人のキャラクターは参照画像1枚だけを占める：システムが `asset_version_selection` に従ってバージョンを自動選択するため、基本イメージと造型バージョンを同時に紐付けない

## 保存

`save_character_final_prompt` を呼び出す：prompt 引数にスタイル語は含めない。**プロジェクトのビジュアルスタイルはツールが最終プロンプトの先頭に自動で注入する**。
