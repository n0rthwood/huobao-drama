# 캐릭터 최종 프롬프트(왼쪽 정면 얼굴 클로즈업 + 오른쪽 삼면도)

생성되는 것은 캐릭터 설정 참조 이미지(캐릭터 레퍼런스 시트)이며 구도는 고정입니다:

- **왼쪽: 정면 얼굴 클로즈업** — 머리와 어깨의 정면 근경으로, 이목구비·헤어스타일·피부 질감이 또렷이 보이며 얼굴 식별성의 앵커가 됩니다
- **오른쪽: 정면, 90도 측면, 후면의 등신 높이가 같은 전신 뷰 세 장을 나란히 제시** — 같은 캐릭터의 전신 뷰 세 개를 같은 높이로 나란히 두고 머리 꼭대기와 발바닥을 맞춥니다

**핵심 원칙: 일관성 > 아름다움.** 이 이미지는 이후 모든 캐릭터 이미지·비디오 참조의 이미지 앵커이므로 중립적이고 명료하며 재사용 가능해야 합니다.

## 기본 이미지 vs 스타일링 버전

- 이 삼면도가 보여 주는 것은 캐릭터의 **기본 이미지**입니다: 평상시 헤어스타일, 평상시 의상, 평상시 액세서리로 `styling`(기본 스타일링)과 일치합니다. **단일 화 전용 스타일링(휴가복, 스노우웨어 등 한 벌 의상)은 기본 이미지에 넣지 않습니다**
- 기본 이미지는 appearance/styling 텍스트와 완전히 일치해야 하며, 텍스트에 모호함("연분홍 또는 베이지")이 있으면 먼저 사용자에게 보고하고 임의로 둘 중 하나를 골라 생성하지 마세요
- 단일 화 전용 스타일링은 **스타일링 버전 이미지**(문서 끝 참조)로 처리하며, 스토리보드는 버전 선택 메커니즘으로 자동 참조합니다

## 출력 구조(이 순서로 한 단락의 연속 묘사를 조립, 언어는 대화 언어 지시를 따름)

```
캐릭터 설정 참조 이미지, 왼쪽은 정면 얼굴 클로즈업, 오른쪽은 정면·90도 측면·후면의 등신 높이가 같은 전신 뷰 세 장을 나란히 제시,
클로즈업과 전신 뷰는 같은 캐릭터, 전신이 화면에 들어옴, 중립 A 스탠스, 세 전신 뷰는 같은 높이로 나란하고 머리 꼭대기와 발바닥이 정렬,
[나이감 + 성별감 + 체형], [이목구비 특징], [헤어스타일], [의상 + 액세서리],
정면 클로즈업과 세 뷰의 얼굴·헤어스타일·의상이 완전히 동일,
순백 배경, 부드럽고 균일한 조명, 영화적 질감
```

## 묘사 순서 규칙

**가장 식별성이 높은 특징을 앞에 두고**, 이 순서로 `appearance` 와 `styling` 의 모든 핵심 요소를 빠짐없이 구현합니다:

1. 정체성 앵커: 나이감, 성별감, 체형
2. 이목구비: 얼굴형, 눈, 기타 두드러진 특징 — 정면 클로즈업은 특히 이 부분에 의존합니다
3. 헤어스타일: 색상, 길이, 스타일
4. 의상: 디자인, 색상, 재질, 상태
5. 액세서리: 식별성 있는 것만 쓰고 쌓아 올리지 않습니다

규칙:
- **확정성**: "또는" "아마" 같은 불확정 표현 금지, 모든 색상과 디자인을 한 번에 확정합니다
- 캐릭터의 성격은 외적인 분위기와 표정 묘사로 전환하고 성격 단어를 직접 쓰지 않습니다
- 비인간 캐릭터의 손발 형태(발가락 수, 손과 발이 같은 형태인지)를 명확히 씁니다. 이는 이후 사지 안정성의 원천 정보입니다

## 구도와 일관성

- 왼쪽 정면 클로즈업: 정면으로 카메라를 향하고 중립적 표정, 머리 꼭대기부터 어깨까지 온전히 화면에
- 오른쪽 전신 뷰 세 장: 정면, 90도 측면, 후면을 **같은 높이로 나란히, 간격을 균등하게** 두고 머리 꼭대기와 발바닥이 같은 수평선 위에
- "정면 클로즈업과 세 전신 뷰의 얼굴·헤어스타일·의상이 완전히 동일"하다고 명시합니다
- 중립 자세, 자연스러운 표정, 부드럽고 균일한 스튜디오 조명, 극적인 명암 금지
- 대화 언어 지시가 지정한 목표 언어로 출력합니다

## 금지 사항

- 역동적 포즈, 과장된 표정, 소품 들기, 타인과 한 화면에 등장
- 신체 잘림(전신 뷰는 머리 꼭대기부터 발바닥까지 온전히, 클로즈업은 머리와 어깨가 온전히)
- 문자, 라벨, 워터마크, 서명
- 짙은 그림자, 색이 있는 배경 조명, 배경 소품

## 스타일링 버전 이미지(image_edit 의상 교체)

어떤 화에서 캐릭터에 스타일링 버전(styling_version)이 등록되면, **기본 이미지**를 바탕으로 이미지 편집을 통해 "그 의상을 입은" 캐릭터 이미지 한 장을 만듭니다:

- 프롬프트 핵심 문형: "캐릭터의 얼굴, 이목구비, 털색/피부색, 체형, 헤어스타일을 참조 이미지와 완전히 동일하게 유지하고, 의상만 다음으로 교체: [스타일링 버전 description 을 항목별로 구현]"
- 전신이 온전히 화면에, 중립 자세, 순백 배경, 부드럽고 균일한 조명으로 기본 이미지와 같은 규격
- 의상만 바꾸고 얼굴을 바꾸지 않으며 체형을 바꾸지 않고 액세서리를 더하지 않습니다(모자, 안경 등 부속품은 소품이며 스타일링 버전 이미지에 넣지 않습니다)
- 생성 후 사람이 이미지에서 "의상이 묘사와 일치하고 얼굴이 흔들리지 않았음"을 확인한 뒤에 스토리보드에 투입합니다

## 참조 이미지 예산(강제 제약)

- 캐릭터 이미지(스타일링 버전 이미지 포함)는 스토리보드 참조 이미지의 공급원입니다: 컷당 참조 이미지는 최대 9장, 비디오 생성 시 첫 키프레임이 먼저 1장을 차지하므로 장면 1 + 캐릭터 N + 소품 M ≤ 8
- 예산을 넘으면 스토리보드 층에서 우선순위로 버립니다: 장면 > 등장 캐릭터 > 사용되거나 클로즈업되는 소품 > 보이기만 하는 소품. 밀려난 소품은 바인딩과 @ 참조를 함께 잃으므로 "@ 했는데 바인딩이 없는" 이름을 남기지 마세요
- 한 캐릭터는 참조 이미지 한 장만 차지합니다: 시스템이 `asset_version_selection` 에 따라 버전을 자동 선택하므로 기본 이미지와 스타일링 버전을 동시에 바인딩하지 마세요

## 저장

`save_character_final_prompt` 를 호출합니다: prompt 인자에는 스타일 단어를 넣지 않습니다. **프로젝트 비주얼 스타일은 도구가 최종 프롬프트 맨 앞에 자동으로 주입합니다.**
