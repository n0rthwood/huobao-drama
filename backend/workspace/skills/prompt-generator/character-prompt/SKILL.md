# 角色最终提示词（左侧正脸特写 + 右侧三视图）

生成的是一张角色设定参考图（character reference sheet），构图固定为：

- **左侧：正脸特写**——头部与肩部的正面近景，五官、发型、肤质清晰可见，作为脸部辨识度的锚点
- **右侧：并列展示正面、90 度侧面、背面三张等高全身视图**——同一角色的三个全身视图等高并排，头顶与脚底对齐

**核心原则：一致性 > 美观。** 这张图是后续所有角色图片、视频参考的形象锚点，必须中性、清晰、可复用。

## 基础形象 vs 造型版本

- 这张三视图呈现的是角色的**基础形象**：常规发型、常规服装、常规配饰，与 `styling`（基础妆造）一致。**单集造型（度假装、雪服等成套衣着）不进基础形象图**
- 基础形象必须与 appearance/styling 文本完全一致；发现文本有歧义（「浅粉色或米色」）时，先向用户报告，不要自行二选一出图
- 单集造型走**造型版本图**（见文末），分镜通过版本选择机制自动引用

## 输出结构（按此顺序组装单段连贯描述，语言跟随会话语言指令）

```
角色设定参考图，左侧为正脸特写，右侧并列展示正面、90 度侧面、背面三张等高全身视图，
特写与全身视图都是同一角色，全身入镜，中性 A 字站姿，三张全身视图等高并排、头顶脚底对齐，
[年龄感 + 性别感 + 体态]，[五官特征]，[发型]，[服装 + 配饰]，
正脸特写与三个视图的脸、发型和服装完全一致，
纯白背景，柔和均匀的光线，电影质感
```

## 描述顺序规则

把**最有辨识度的特征放在前面**，按此顺序落地 `appearance` 与 `styling` 的每个关键元素，不遗漏：

1. 身份锚点：年龄感、性别感、体态
2. 五官：脸型、眼睛、其他显著特征——正脸特写尤其依赖这部分
3. 发型：颜色、长度、样式
4. 服装：款式、颜色、材质、状态
5. 配饰：只写有辨识度的，不堆砌

规则：
- **确定性**：禁止「或」「可能」等不定写法，所有颜色、款式一次写死
- 角色的性格转化为外在气质与神态描写，不直接出现性格词汇
- 非人角色的手足形态写清楚（趾数、是否手脚同形），这是后续肢体稳定性的源头信息

## 构图与一致性

- 左侧正脸特写：正面朝向镜头、中性表情、头顶到肩膀完整入镜
- 右侧三张全身视图：正面、90 度侧面、背面，**等高并排、间距均匀**，头顶与脚底在同一水平线
- 明确写出「正脸特写与三张全身视图的脸、发型和服装完全一致」
- 中性站姿、自然表情；柔和均匀的棚拍光，不要戏剧性光影
- 输出使用会话语言指令指定的目标语言

## 禁止事项

- 动态姿势、夸张表情、手持道具、与他人同框
- 裁切身体（全身视图必须头顶到脚底完整，特写必须头肩完整）
- 文字、标签、水印、签名
- 重阴影、彩色背景光、背景道具

## 造型版本图（image_edit 换装）

当某集为角色登记了造型版本（styling_version）时，基于**基础形象图**做图像编辑出一张「穿着该套装」的角色图：

- 提示词核心句式：「保持角色的脸、五官、毛色/肤色、体型、发型与参考图完全一致，仅将服装更换为：[造型版本 description 逐项落地]」
- 全身完整入镜、中性站姿、纯白背景、柔和均匀光线，与基础形象图同规格
- 只换衣着，不改脸、不改体型、不加配饰（帽、眼镜等配件是道具，不进造型版本图）
- 出图后由人工在图上确认「穿着与描述一致、脸未漂移」后再投入分镜使用
