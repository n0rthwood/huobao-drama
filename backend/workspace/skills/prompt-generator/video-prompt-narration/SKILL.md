# 视频提示词：旁白走独立音轨（仅在本集开启旁白时注入）

本集开启了**旁白**：解说词存在分镜的独立字段里，会由语音合成生成独立音轨，并在合成阶段混入成片、烧录成字幕。视频模型生成的声音在合成阶段会被丢弃或压成底音。

因此，本集的 `video_prompt` **覆盖** video-prompt 技能中「把 description 里的『旁白：…』提取进视频提示词台词段」这一条：

1. **不要**把任何解说词、画外音、旁白写进 `video_prompt`。
2. **不要**让画面里的人物念解说词——否则 H3 会生成对不上的口型与说话动作。
3. 角色之间真实的**对白**（`description` 的【镜头N】里写成「角色名说：「…」」的部分）仍照常提取进对应 3 秒段，不受本规则影响。
4. `description` 里如果仍残留「旁白：…」（存量数据），**跳过它**，不要搬进 `video_prompt`。
5. 画面、运镜、景别、氛围、关键帧对齐等其余规则全部不变。

## 无资产人物必须有专属可见标识

画面中出现**没有角色资产的人物**（随从、士兵、宫人、属吏、百姓、路人、群演等）时：

- **必须**写明：人数、站位（在画面/主体的什么位置）、身份/职能；**禁止**只写「随从」「两人」「几名士兵」这类不带标识的泛称
- **必须**从服色、服制/款式、冠帽/头饰、持物中至少写两项可见标识，且与同画面**每一个** `@角色` 都不同——不得与任何 `@角色` 同色同制，否则模型会把 `@角色` 的参考图造型直接套到他们身上
- 同一批无名人物在多个分镜反复出现时，**必须沿用同一套标识**：先用 `read_storyboard_context` 读相邻分镜已保存的提示词，照抄其中已定下的写法，禁止另造新描述
- 本条**只适用于无资产的无名人物**；有资产的 `@角色` 仍按「绝对规则：图像优先」执行，一个外观字都不写
- **禁止**为无名人物新建角色资产
- 反例：「左右两侧各有一名随从扶住他」；正例：「左右两侧各有一名随从（灰褐无纹短衣、无冠束髻、腰束布带），各自一手扶住他的手臂」

与 video-prompt 技能同一条，旁白集同样适用；无名人物在多个 3 秒段中出现时，每段首次指代都要带上这套标识，不得只在第一段写明、后面改回「两人」「他们」。

## 锁定衔接帧（C/D 组合）

与 video-prompt 技能的「锁定衔接帧」同一条，旁白集同样适用：

- `read_storyboard_context` 的 `locked_frames.caption` 是那张衔接帧 PNG 的真实画面描述（视觉模型看的），不是底图提示词的转述。
- **C**（锁定首帧）：第一个时间分段必须复述 caption 的构图（机位/景别/画面里有什么/光线/留白），人物随后入画；**第一段内禁止切镜**。
- **D**（锁定尾帧）：最后一个时间分段必须收束到 caption 的构图，**末段内禁止切镜**。
- `caption` 为 `null` 时读 `caption_note`（未渲染 / 无视觉配置 / 底图验证未通过）：照样不切镜，也不编画面。
- 保存时 C 的首段或 D 的末段出现「切到/切回/切换为/切换到/转到/硬切」等切镜写法会被退回；退回信息带 caption，按它重写后再保存。
