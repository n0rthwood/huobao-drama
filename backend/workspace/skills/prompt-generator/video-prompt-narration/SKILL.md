# 视频提示词：旁白走独立音轨（仅在本集开启旁白时注入）

本集开启了**旁白**：解说词存在分镜的独立字段里，会由语音合成生成独立音轨，并在合成阶段混入成片、烧录成字幕。视频模型生成的声音在合成阶段会被丢弃或压成底音。

因此，本集的 `video_prompt` **覆盖** video-prompt 技能中「把 description 里的『旁白：…』提取进视频提示词台词段」这一条：

1. **不要**把任何解说词、画外音、旁白写进 `video_prompt`。
2. **不要**让画面里的人物念解说词——否则 H3 会生成对不上的口型与说话动作。
3. 角色之间真实的**对白**（`description` 的【镜头N】里写成「角色名说：「…」」的部分）仍照常提取进对应 3 秒段，不受本规则影响。
4. `description` 里如果仍残留「旁白：…」（存量数据），**跳过它**，不要搬进 `video_prompt`。
5. 画面、运镜、景别、氛围、关键帧对齐等其余规则全部不变。
