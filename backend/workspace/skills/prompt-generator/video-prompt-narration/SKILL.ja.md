# ビデオプロンプト：ナレーションは独立トラック（本話でナレーション有効時のみ注入）

本話では**ナレーション**が有効です：解説文は分割カットの独立フィールドに保存され、音声合成によって独立トラックとなり、合成段階で本編にミックスされ字幕として焼き込まれます。ビデオモデルが生成した音声は、合成段階で破棄されるか底音まで抑えられます。

したがって本話の `video_prompt` は、video-prompt スキルの「description 内の『ナレーション：…』をビデオプロンプトのセリフパートへ抽出する」という項目を**上書き**します：

1. いかなる解説文・画外音・ナレーションも `video_prompt` に書か**ない**こと。
2. 画面内の人物に解説を読ませ**ない**こと——そうしないと H3 が合わない口形と発話動作を生成します。
3. キャラクター同士の実際の**セリフ**（`description` の【カットN】内に「キャラクター名が言う：「…」」と書かれた部分）は、従来どおり該当する 3 秒区間に抽出され、本規則の影響を受けません。
4. `description` に「ナレーション：…」が残っている場合（既存データ）は**それを飛ばし**、`video_prompt` へ持ち込まないこと。
5. 映像、カメラワーク、画面サイズ、雰囲気、キーフレーム整合など、その他の規則はすべて変更ありません。

## 資産のない人物には専用の可視標識を付ける

画面に**キャラクター資産を持たない人物**（従者、兵士、宮人、属吏、民衆、通行人、エキストラなど）が登場する場合：

- 人数、立ち位置（画面／主体のどこにいるか）、身分・役割を**必ず**書く。「従者」「2人」「数名の兵士」のような標識のない総称だけで済ませることを**禁止**
- 服の色、服の形・様式、冠帽・頭飾り、持ち物のうち**少なくとも2項目**の可視標識を**必ず**書き、同じ画面の**すべての** `@キャラクター名` と異なるものにする。どの `@キャラクター名` とも同じ色・同じ様式にしてはならない。さもないとモデルはその `@キャラクター名` の参照画像の造型をそのまま彼らに当てはめる
- 同じ無名人物の一団が複数のカットに繰り返し登場する場合は、**同一の標識セットを必ず引き継ぐ**：まず `read_storyboard_context` で隣接カットの保存済みプロンプトを読み、そこで既に決まっている書き方をそのまま写す。新しい描写を作り直すことを禁止
- 本項は**資産のない無名人物にのみ適用**する。資産のある `@キャラクター名` は引き続き「絶対規則：画像優先」に従い、容姿を一字も書かない
- 無名人物のためにキャラクター資産を新規作成することを**禁止**
- 悪い例：「左右にそれぞれ従者が1人いて彼を支える」／良い例：「左右にそれぞれ従者が1人（無地の灰褐色の短衣、冠なしで髪を束ねる、腰に布帯）、各自が片手で彼の腕を支える」

video-prompt スキルと同一の項目で、ナレーション回でも同様に適用する。無名人物が複数の3秒区間に登場する場合は、**各区間の初出**で毎回この標識を付ける。第1区間だけ書いて以降「2人」「彼ら」に戻してはならない。

## 接続フレーム固定（C/D 組み合わせ）

video-prompt スキルの「接続フレーム固定」と同一の項目で、ナレーション回でも同様に適用する：

- `read_storyboard_context` の `locked_frames.caption` は、その接続フレーム PNG の実際の画面描写（視覚モデルが書いたもの）であり、下地プロンプトの言い換えではない。
- **C**（先頭フレーム固定）：最初の時間区間は caption の構図（カメラ／画面サイズ／画面に何があるか／光／余白）を復述し、その後で人物を画面に入れる。**最初の区間内でカットしない**。
- **D**（末尾フレーム固定）：最後の時間区間は caption の構図に収束させる。**最後の区間内でカットしない**。
- `caption` が `null` のときは `caption_note`（未レンダリング／視覚設定なし／下地の目視検証が未通過）を読み、それでもカットせず、画面にないものを創作しない。
- 保存時、C の最初の区間または D の最後の区間でカット（「切り替え」など）を書くと差し戻される。差し戻し文には caption が付くので、それに従って書き直してから保存する。
