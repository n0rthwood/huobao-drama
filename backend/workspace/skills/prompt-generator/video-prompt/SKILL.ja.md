# 動画プロンプト（絵コンテパラグラフ → video_prompt）

単一の絵コンテパラグラフの description（`【镜头N】` のサブカット構造と台詞／ナレーションを含む）／ atmosphere ／ duration に基づき、AI 動画生成を駆動する `video_prompt` を生成する。**1つの絵コンテパラグラフ＝8〜15秒の動画1本で、内部でのカット割りは許可**。ただし**全編を通してシーンをまたがず**、回想も入れない。

## フォーマット

`video_prompt` の**1行目は情報ヘッダー**：まずこの動画にどの人物とシーンが登場するかを紹介し、その後に時間分割を続ける。人物・シーン・小道具は一律 @ で参照する。

```
登場人物：@シャオミン、@シャオホン；シーン：@カフェ；小道具：@手紙。
0-3秒：@カフェ、クローズ寄りの固定カメラ、@シャオミン が窓際のボックス席に座り、右手で机上の @手紙 をつまみ、左手はカップの縁を支え、両脚はテーブルの下で自然に揃い、うつむいて手紙を読み、眉をわずかに寄せる。
3-6秒：入口のフルショットに切り替え、ドアベルが鳴り、@シャオホン がドアを押して入ってくる。右手でドア枠を支え、左手でバッグを提げ、両脚で店内へ踏み出す。
6-9秒：ミディアムショットに切り戻し、@シャオホン がテーブルの脇まで来て座り、両手を机上に置く。@シャオミン が顔を上げ、右手は依然 @手紙 をつまんだまま、「やっと来たね」と言う。
```

情報ヘッダーの規則：
- その絵コンテパラグラフに実際に登場する人物と、紐付けられたシーン・小道具のみを列挙する
- 情報ヘッダーは独立した1行で句点で終え、その後に時間分割を置く

3秒を1段として、各段を1行ずつ改行で区切り、時間範囲は連続して接続する（重複なし、欠落なし）。

## 冒頭トランジション段（transition-prompt 技能と連携）

引き継ぎカット（`inherits_first` が true）は**冒頭トランジション段**を持つことがある（transition-prompt 技能が生成し、動画プロンプトの先頭に書かれる。提出尺＝min(内容尺 ＋ トランジション尺 T, 15s)）：

- **削除しない、トランジション段の構造を書き換えない**。トランジション文は transition-prompt 技能の規則どおり先頭に残す
- 本技能の四肢状態と「一段一動」の規則は、**トランジション段の後の最初の内容段から段ごとに適用**する
- トランジション段にも参照規則の段ごとの資産アンカリングが等しく適用される：シーンとその段に登場するすべての資産（手持ち・着用物以外の静止資産を含む）を各段で @ する
- トランジション段がない場合、第1段は先頭キーフレーム画面から続けて演じる（規則は「キーフレーム整合」を参照）

## 絵コンテ記述との対応

`description` が video_prompt の唯一の内容源：

- 各 `【镜头N】` は**連続する3秒段の1〜2段**に対応させる。順序は一致させ、抜かさず、統合せず、サブカットを新設しない
- 台詞／ナレーションは対応する `【镜头N】` から抽出し、そのサブカットに対応する段へ割り当てる。**新しい台詞を創作しない**
- 画面の動作は `description` に従う。`atmosphere` は光・色調・雰囲気の補足にのみ使う

## 段内の構造

各段は次の順序で組み立てる（内容のない項目は省略可、ただし動作／画面は必須）：

**時間範囲 ＋ シーンの@参照（各段必須、カット／寄りも例外なし） ＋ 画面サイズ／カメラワーク ＋ キャラクターの@参照＋主体の動作・四肢状態・表情 ＋ 小道具の@参照と状態 ＋ 台詞／ナレーション ＋ 雰囲気と光**
- **小道具の識別要素**：@小道具名 を含む文には識別要素（機能部位／明示的な保持部位／使用動作、「参照規則」参照）が必須。「支える／掛かる／置かれている」類の弱い状態動詞のみでは不合格。静止小道具は位置＋部位状態で書く（例：「テーブルの上の @リモコン、ボタン面を上向きに」）

- **一段一主動作**：各段で1人のキャラクターが1つの肢体状態を変えることのみ許す。動詞は具体的で可視（歩く、振り向く、顔を上げる、握りしめる）。動作の連鎖（置く—体をひねる—組み直す）を1段に詰め込むことを禁止
- **四肢状態**：登場キャラクターは各段で両手（持ち物がどちらの手かを含む）と両脚の現在の姿勢を明記する。高リスク姿勢（あぐら、しゃがみ込み、片脚立ち、脚組み、振り向き）は肯定形で完全に列挙：「両脚を体の前に引き寄せて組み、両足は体の下に収め、両手で膝を抱える」。**否定指示は禁止**（「三本脚にしない」は無効）
- **遮蔽動作の書き換え**：背後や胴体に隠れる動作は、体を斜めにして見える同等の動作に変える
- **接触の相互作用**：2人のキャラクターが接触する場合は双方の四肢の最終状態を書き、接触点は1箇所のみ
- **着用状態**：帽子、眼鏡、サングラスは各段で宣言する（着用中／どちらの手に持つ／画面外）。着脱はそれぞれ1つの主動作を占有する
- **カット割り**：カット段の冒頭は「〜に切り替え／切り戻し」で始め、画面サイズと主体を改めて提示する。カット点は `【镜头N】` に揃える。純粋な寄りの段は連続1段まで、寄りの段の前後には全身／ミディアムのアンカー段を置く
- **感情は可視の描写に変換**：「彼はとても悲しい」ではなく「彼はうつむき、両手でカップの縁を握りしめる」と書く

## キーフレーム整合（ハードルール）

`read_storyboard_context` は `first_frame_prompt`、`mid_frame_prompt`、`mid_frame_time`、`last_frame_prompt`、`inherits_first` を返す。これらに必ず合わせること：

- **先頭フレーム**：トランジション段がない場合、第1段は先頭キーフレーム画面から続けて演じる（`inherits_first` が true のときは前の絵コンテの末尾キーフレーム。前カットの `last_frame_prompt` / `result` を読んで画面を把握してよい）。同じカメラ位置と人物配置を保ち、空間を作り直さず、0秒でカットしない。トランジション段がある場合は空間の接続をトランジション段が担い、その後の最初の内容段はトランジション終了画面から続ける
- **中間フレーム**：`mid_frame_time` に値がある場合、いずれかの段の**開始点が正確にその秒数に一致**し、その段の冒頭画面が `mid_frame_prompt` と一致すること
- **末尾フレーム**：最後の段は `last_frame_prompt` の画面に着地し、キャラクターの手持ち／着用状態もそれと一致させる
- キーフレームプロンプトは静止した一瞬を描く。動画プロンプトは2つのフレームの間の動きと芝居を書く。丸写ししない

## 絶対規則：画像優先

- キャラクターの種族、人種、服装、色、髪型、体型、年齢、顔立ちの描写を**禁止**。キャラクターは `@キャラクター名` のみで指す。服装は造型バージョン参照画像が決めるので、服装を文字で書かない
- **許可**：相対的な体格比（「@ネズミママ の身長は @ブタパパ のおよそ3分の2」）、着用系小道具の着用状態（「鼻の上に @サングラス を掛けている」）
- 見える位置、姿勢、四肢状態、動作、表情、視線、小道具との関わり、および画面サイズ、カメラワーク、光と雰囲気のみを書く

## 参照規則（段ごとの資産アンカリング）

- `@シーン名` / `@キャラクター名` / `@小道具名` は read_storyboard_context が返すリストと完全に一致させる（自動的に参照画像マークに置換されるため、省略形や記号の追加をしない）。この絵コンテに紐付け済みの資産のみ参照する。情報ヘッダーは本カットの紐付け資産の全体集合を、各時間段は**その段に登場する部分集合**を列挙し、両者は互いに代用しない
- **シーンは各段で @（ハードルール）**：すべての時間段（冒頭トランジション段、カット段、純粋な寄り段を含む）の本文に、本カットに紐付けされた `@シーン名` が必ず含まれること。段の最初の参照にするのを推奨する。画面サイズの変化はシーンの変化ではない：カット・プッシュイン・寄りも例外なし。シーンを @ することは、モデルに「まだここにいる」と伝えることである
- **登場資産は各段で @（ハードルール）**：その段の画面に見えるすべての紐付けキャラクター／小道具（背景、前景のぼかし、鏡像、静止物を含む）は各段で @ し、それぞれ短い可視状態句を添える（位置＋姿勢で十分、動作である必要はない）。資産が画面を離れる段では @名前 で退場の仕方を明記し、以降の段では言及しないか、バイパス参照禁止に従い `@名前（画面外）` で言及する。音もなく消えて、また音もなく戻ることを禁止
- **小道具は保持・使用・着用の文中でのみ、かつ識別要素とともに**：`@小道具名` を含む文は、誰が・どの部位で・どう保持・使用・着用するかを書き、識別要素を最低1つ含むこと — **機能部位**（チャンネルボタン、レンズ、帽子のつば）、**明示的な保持部位**（右手の親指、鼻筋）、**使用動作**（押す、掲げて指す、着ける）。弱い状態動詞（支える、置かれている、掛かる、持っている、接触している）単独＋@小道具 は不合格 —「黒い長方形を両手で支えている」はリモコン／ゲームパッド／スマートフォンに共通の先入観である。「一段一主動作」との接続：識別要素は部位レベルの**状態**として表現するのを優先する（「右手で @リモコン を握り、親指をチャンネルボタンの上に軽く添える」は状態であり主動作の枠を消費しない）。その段の主動作自体が小道具操作である場合のみ使用動作として書く
- **バイパス参照の禁止（素のテキスト）**：@ 可能な資産は `@名前` の形でのみ登場できる。画面外・鏡中・ぼかし・音源など非主体の言及は `@名前（画面外）`・`@名前（鏡中）` と書き、括弧注記は @ 参照の**後ろ**に付け、置き換えない。「画面外の鏡」「あの鏡」「テーブルの上のリモコン」のような素のテキストでの指示は禁止：素のテキストはその資産の参照画像をバイパスし、モデルが言葉だけで外見を再発明する
- **集合呼称の禁止**：集合呼称（父母、父さんと母さん、二人、彼ら、家族、みんな）は、その段で構成員を指す**最初の**指示になってはならない。段内ではまず一人ずつ @名前 で呼び、以降の再言及でのみ「二人／彼ら」を使える。段をまたいで引き継がない：新しい段ごとに再び @名前 から始める
- 鏡面の画面：同一段では鏡像か実体のどちらか一方のみを主体とし、鏡の中の内容を明記して実体と一致させる。画面内のテレビは番組のみを流し、本作のキャラクターの登場を禁止

## 参照画像の予算（ハード制約）

- 1カットあたり参照画像は最大9枚。動画生成時は先頭キーフレームが先に1枚を占めるため、実際に使えるのは：シーン 1 ＋ キャラクター N ＋ 小道具 M ≤ 8
- 予算超過時は優先度で取捨する：シーン ＞ 登場キャラクター ＞ 使用される／寄りで映る小道具 ＞ 見えているだけの小道具
- 外された小道具は紐付けと @ 参照を同時に削除する。「@ したのに紐付けがない」名前を残さない
- この絵コンテに紐付け済みの資産のみ @ する

## タイムライン規則

- 内容段の数＝絵コンテパラグラフの duration ÷ 3秒（切り上げ）。各段の時間範囲の合計はパラグラフの総尺に等しい。トランジション段がある場合、内容段のタイムラインはトランジション段終了後から起算し、総尺は提出尺に従う
- 内容のリズム：第1の内容段はアンカーフレーム画面から続けて演じる → 中盤の段で動作を進める（`mid_frame_time` の位置で中間フレームに合わせる）→ 最終段は末尾フレーム画面に着地する

## 禁止事項

- シーンをまたぐ切り替え、回想
- 参照リスト外の名前、キャラクターの外見描写、否定形の四肢指示
- @ 可能な資産の素のテキストでの指示（「画面外の鏡」「あの鏡」「テーブルの上のリモコン」）。段内の最初の指示としての集合呼称（父母／二人／彼ら）
- 1段に複数の主動作、2段以上連続する純粋な寄りでの進行
- 抽象的な心理描写、文学的な比喩
- 冒頭トランジション段の構造の削除や書き換え
- 会話言語の指示と一致しない言語

## 保存

`update_storyboard` を呼び出し、その絵コンテパラグラフの `video_prompt` フィールドのみを更新する。他のフィールドを変更せず、話全体を再分解しない。
