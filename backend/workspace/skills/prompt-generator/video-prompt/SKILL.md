# 视频提示词（分镜段落 → video_prompt）

根据单个分镜段落的 description（含【镜头N】子镜头结构与台词/旁白）/ atmosphere / duration，生成驱动 AI 视频生成的 `video_prompt`。**一个分镜段落 = 一段 8-15 秒的视频，内部允许切镜**；但**全程不跨场景**、不闪回。

## 格式

`video_prompt` 的**第一行是信息头**：先介绍这条视频有哪些人物和场景，然后再接时间分段。人物、场景、道具一律用 @ 引用。

```
出场人物：@小明、@小红；场景：@咖啡厅；道具：@信件。
0-3秒：@咖啡厅，近景固定镜头，@小明 坐在靠窗卡座，右手捏着 @信件 搁在桌面，左手扶着杯沿，双腿在桌下自然并拢，低头看信，眉头微皱。
3-6秒：切到门口全景，门铃响，@小红 推门走入，右手扶门框，左手拎包，双腿迈步进店。
6-9秒：切回中景，@小红 走到桌旁坐下，双手放在桌面，@小明 抬头，右手仍捏着 @信件，说：「你终于来了。」
```

信息头规则：
- 只列该分镜段落实际出场的人物、绑定的场景与道具
- 信息头独立一行，以句号结尾，之后是时间分段

按 3 秒为一段，每段单独一行、换行分隔，时间范围连续衔接（无重叠、无空缺）。

## 开场转场段（与 transition-prompt 技能协同）

承接镜（`inherits_first` 为 true）可能带有**开场转场段**（由 transition-prompt 技能产出、写在视频提示词开头，提交时长 = min(内容时长 + 转场时长 T, 15s)）：

- **不要删除、不要改写转场段的结构**；转场文本按 transition-prompt 技能的规则保留在开头
- 本技能的四肢状态与一段一动规则，**从转场段之后的第一个内容段开始逐段适用**
- 转场段同样适用「引用规则」的逐段资产锚定：场景与该段在场资产（含持续存在的手持物/穿戴物之外的静置资产）逐段 @
- 无转场段时，第一段从首关键帧画面继续演（规则见「关键帧对齐」）

## 与分镜描述的映射

`description` 是 video_prompt 的唯一内容来源：

- 每个 `【镜头N】` 映射为 **1-2 个连续的 3 秒段**，顺序一致、不遗漏、不合并、不新增子镜头
- 台词/旁白从对应 `【镜头N】` 提取，分配到该子镜头映射的段；**不要创作新台词**
- 画面动作以 `description` 为准；`atmosphere` 只用于补光线、色调与氛围

## 段内结构

每一段按此顺序组织（可省略无内容的项，但动作/画面必须有）：

**时间范围 ＋ 场景@引用（每段必填，切镜/特写不豁免） ＋ 景别/运镜 ＋ 角色@引用＋主体动作·四肢状态·表情 ＋ 道具@引用及状态 ＋ 对白/旁白 ＋ 氛围光线**
- **道具辨识性要素**：@道具名 所在句必须含辨识性要素（功能部件 / 明确持握部位 / 使用动作，详见「引用规则」）；只配「扶着/搭在/放着」类弱状态动词不合格，静置道具写位置 + 部件状态（如「茶几上的 @遥控器 按键面朝上」）

- **一段一个主动作**：每段只允许一个角色改变一个肢体状态；动词具体可见（走、转身、抬头、攥紧）。禁止把动作链（放下—扭身—盘回去）塞进一段
- **四肢状态**：出场角色每段写明双手（含持物在哪只手）与双腿的当前姿态；高风险姿态（盘腿、蹲缩、单腿站、翘腿、转身）用正向完整枚举：「双腿向身前收拢盘起，双脚收于身下，双手抱膝」；**禁止**负向指令（「不要三条腿」无效）
- **遮挡动作改写**：身后/被躯干挡住的动作改为侧身可见的等效动作
- **接触互动**：两角色接触时双方肢体终态都写，接触点唯一
- **穿戴状态**：帽、眼镜、墨镜每段声明（戴着/拿在哪只手/不在画面）；摘戴各自独占一个主动作
- **切镜**：切镜段开头用「切到/切回」，重新交代景别与主体；切镜点对齐 `【镜头N】`；连续纯特写段不超过 1 段，特写段前后要有全身/中景锚定段
- **情绪转为可见描写**：不写「他很伤心」，写「他低下头、双手攥紧杯沿」

## 关键帧对齐（硬规则）

`read_storyboard_context` 返回 `first_frame_prompt`、`mid_frame_prompt`、`mid_frame_time`、`last_frame_prompt` 与 `inherits_first`，必须据此对齐：

- **首帧**：无转场段时，第一段从首关键帧画面继续演（`inherits_first` 为 true 时是上一分镜尾关键帧，可读上一镜的 `last_frame_prompt` / `result` 了解画面），保持同一机位与人物位置，不重新建立空间、不在 0 秒切镜；有转场段时由转场段完成空间衔接，其后第一个内容段从转场结束画面继续
- **中间帧**：`mid_frame_time` 有值时，必须有某个分段的**起点正好落在该秒数**，且该段开头画面与 `mid_frame_prompt` 一致
- **尾帧**：最后一段收在 `last_frame_prompt` 的画面上，角色的手持/穿戴状态与其一致
- 关键帧提示词描述静止瞬间，视频提示词写出两帧之间的运动与表演，不要照抄

## 绝对规则：图像优先

- **禁止**描写角色的物种、种族、服装、颜色、发型、体型、年龄、五官；角色只用 `@角色名` 指代；服装由造型版本参考图决定，不写服装文字
- **允许**：相对体型比例（「@鼠妈妈 身高约为 @猪爸爸 的三分之二」）；穿戴类道具的佩戴状态（「鼻梁上架着 @墨镜」）
- 只写可见的位置、姿态、四肢状态、动作、表情、视线、道具交互，以及景别、运镜、光线氛围

## 引用规则（逐段资产锚定）

- `@场景名` / `@角色名` / `@道具名` 必须与 read_storyboard_context 返回列表完全一致（自动替换为参考图片标记，不要缩写或加符号）；只引用本分镜已绑定的资产。信息头列本镜绑定资产全集，每个时间分段列**该段在场子集**，二者分工不互相替代
- **场景逐段 @（硬规则）**：每个时间分段——含开场转场段、切镜段、纯特写段——的正文必须出现本分镜绑定的 `@场景名`，建议作为该段第一个引用。景别变化不是场景变化：切镜、推拉、特写不豁免，@ 场景是告诉模型「仍在这里」
- **在场资产逐段 @（硬规则）**：凡该段画面内可见的绑定角色/道具——包括背景、前景虚化、镜中像、静止不动者——每段都 @，并带一个可见状态短语（位置+姿态即可，不必是动作）。资产离开画面的那一段用 @名字 写明出画方式；此后各段不再提及，或按旁路指代禁令以 `@名字（画外）` 提及，禁止无声蒸发后又无声回归
- **道具只在持有/使用/穿戴句中出现，且须有辨识性要素**：`@道具名` 所在句必须写明谁、用哪个部位、怎样持有/使用/穿戴，并至少含一项辨识性要素——**功能部件**（换台键、镜片、帽檐）、**明确持握部位**（右手拇指、鼻梁）、或**使用动作**（按下、举起指向、戴上）。单独弱状态动词（扶着、放着、搭在、拿着、挨着）+ @道具 = 不合格——「双手扶着黑色矩形物」是遥控器/手柄/手机的共同先验。与「一段一个主动作」的衔接：辨识性要素优先用部件/部位级**状态**表达（「右手握着 @遥控器、拇指虚搭在顶端换台键上」是状态，不占主动作名额），仅当该段主动作本就是道具操作时才写成使用动作
- **禁止旁路指代（裸文本）**：可 @ 的资产只允许以 `@名字` 形式出现。画外/镜中/虚化/声源等非主体提及写 `@名字（画外）`、`@名字（镜中）`——括号注记**跟在 @ 引用之后**，不替代它。禁止「画外穿衣镜」「那面镜子」「桌上的遥控器」类裸文本指代：裸文本 = 旁路该资产参考图，模型按文字重新发明外观
- **集体称呼禁令**：集体称呼（父母、爸爸妈妈、两人、他们、一家人、大家）不得作为某段内成员的**首次**指代；段内先逐一 @名字，其后的回指才可用「两人/他们」。跨段不继承：每个新段重新从 @名字 开始
- 镜面画面：同一段只以镜中像或真身之一为主体，镜中内容写明且与真身一致；画面内电视只播节目，禁止出现本片角色

## 时间轴规则

- 内容段数 = 分镜段落 duration ÷ 3 秒（向上取整），各段时间范围相加等于段落总时长；有转场段时，内容段时间轴从转场段结束后起算，总时长以提交时长为准
- 内容节奏：第一个内容段从锚帧画面接着演 → 中段推进动作（`mid_frame_time` 处对齐中间帧）→ 末段收在尾帧画面

## 禁止事项

- 跨场景切换、闪回
- 引用列表之外的名字；角色外观描写；负向肢体指令
- 裸文本指代可 @ 的资产（「画外穿衣镜」「那面镜子」「桌上的遥控器」）；集体称呼（父母/爸爸妈妈/两人/他们）作为段内首次指代
- 一段多个主动作；连续两段以上纯特写推进
- 抽象心理描写、文学化比喻
- 删除或改写开场转场段的结构
- 语言与会话语言指令不符

## 保存

调用 `update_storyboard` 仅更新该分镜段落的 `video_prompt` 字段，不要改动其他字段，不要重新拆分整集。
