# キーフレームプロンプト（絵コンテパラグラフ → first/mid/last_frame_prompt）

各絵コンテパラグラフは、動画を生成する前にまず**静止キーフレーム画像**を一式作る：先頭フレーム、（任意の）中間フレーム、末尾フレーム。動画生成時は先頭フレームが第0フレームのアンカーとなり、中間フレーム／末尾フレームはタイムライン上のアンカーとなる。さらにシーン／キャラクター／小道具の参照画像が重ねられる。したがってキーフレームが動画全体の画面品質と人物の一貫性を決める。

1本のキーフレームプロンプトが描くのは**そのパラグラフ内のある静止した一瞬**であり、動きではない。時間の進行を書かず、「そして」「続いて」も書かない。

## 3枚のキーフレームの定義

| スロット | フィールド | 対応する瞬間 |
|---|---|---|
| 先頭フレーム | `first_frame_prompt` | `【镜头1】` の冒頭の一瞬 |
| 中間フレーム | `mid_frame_prompt` ＋ `mid_frame_time` | `mid_frame_time` 秒の時点にあるサブカットの開始の一瞬 |
| 末尾フレーム | `last_frame_prompt` | パラグラフ終了の一瞬。`result` の記述と一致 |

- `mid_frame_time` の単位は**秒**（パラグラフ先頭からの相対）。必ずいずれかの `【镜头N】`（N ≥ 2）の開始時刻と正確に一致し、かつ 0.5 秒と `duration - 0.5` 秒の間に厳密に収まること
- 中間フレームは最初のサブカット以外で**最も重要なサブカット**の開始時点を選ぶ。パラグラフにサブカットが1つしかない場合は両方とも書かない
- 引き継ぎパラグラフ（`continuity` が `continue`、`inherits_first` が `true`）：`first_frame_prompt` は必ず空にする。その代わり、前パラグラフの `last_frame_prompt` が安定して情報が明瞭で、そのまま本パラグラフの冒頭画面として使える画面であることを保証する

## 絶対規則：画像優先

キャラクターの容姿と服装は資産参照画像（造型バージョン画像を含む）が完全に決める。**文字の記述が参照画像と矛盾した瞬間に生成画像は破綻する**。

- キャラクターの種族、人種、服装、色、髪型、体型、年齢、顔立ちを描写することを**禁止**
- キャラクターは一律 `@キャラクター名` でのみ指す。**名前は単なる符号**であり、名前から容姿を推測しない
- シーン・小道具も同様：`@シーン名` / `@小道具名` で参照し、「今この瞬間の状態」だけを補う
- **許可**：相対的な体格比（「@ネズミママ の身長は @ブタパパ のおよそ3分の2」——比率は容姿ではない）、着用系小道具の着用状態（「鼻の上に @サングラス を掛けている」「@パナマ帽 を左手に持つ」——これは小道具参照）
- 書いてよいもの：画面サイズ、カメラアングル、構図、人物の位置、姿勢、手足の動作、表情、視線、小道具との関わり、光と雰囲気

## 四肢状態セルフチェックリスト（プロンプトごとに1項目ずつ確認）

画面に登場する**すべて**のキャラクターについて：

1. **両手**：それぞれどこで何をしているか。持ち物は「どちらの手か」を明記。空いている手も書く（「左手は体側に自然に垂れている」）
2. **両脚**：立つ／座る／しゃがむ／組むの具体的な収め方と可視性——高リスクな姿勢は肯定形で完全に列挙する：「左脚を右脚の上に組み、両足は体の下に収め、画面内に両足裏が見える」。**「三本脚にしない」のような否定指示は書かない**（無効）
3. **遮蔽**：胴体に完全に隠れる手足の動作は書かない。「手を背後に回す」が必要なら、体を斜めにして見える同等の姿勢に書き換える
4. **接触**：2人のキャラクターが接触する場合は双方の四肢の最終状態を書き、接触点は1箇所のみ（「@ネズミママ の右前足が @サルの赤ちゃん の左膝に乗り、@サルの赤ちゃん は両手で椅子の座面を支える」）
5. **着用状態**：帽子、眼鏡、サングラスなどは毎フレーム宣言する——着用中／どちらの手に持つ／画面外
6. **非人間体型**：四肢が短く丸い体のキャラクターに人間の標準姿勢を当てはめず、その体型で実行可能な版にする（「両腕を体側に垂らしてダンベルを持つ」ではなく、両前足を胸の前で抱える）
7. **資産アンカリング（段ごとアンカリングの単一フレーム版）**：このフレームに見えるすべての紐付け資産（背景、ぼかし、鏡像（`@名前（鏡中）` と注記）、画面外の音源（`@名前（画面外）` と注記）を含む）は @ で参照し、それぞれ短い可視状態句を添える。`@小道具名` を含む文には機能部位／明示的な保持部位／使用動作のいずれかが必須（静止画では部位レベルの状態として表現、例：「親指を @リモコン のチャンネルボタンの上に軽く添える」）。@ 可能な資産の素のテキストでの指示、および集合呼称（父母／二人／彼ら）による最初の言及は禁止——まず @名前、その後に再言及する

## 鏡と画面の規則

- 画面に姿見や反射が含まれる場合、同一フレームでは**鏡像**か**実体**のどちらか一方だけを主体にする：鏡像を撮るなら鏡枠を完全に画面に入れ、実体は背面の一部だけを見せて明記する。実体を撮るなら鏡面は画面の端に置くかボケさせる
- 鏡の中の内容は1項目ずつ明記し（誰が、どんな姿勢で、何を着用しているか）、実体と一致させる
- 画面内のテレビ／スクリーンは番組映像（風景、ニュース映像など）だけを流し、**本作のキャラクターを映すことを禁止**
- 複数キャラクター＋鏡面は最もリスクの高い組み合わせ。避けられるなら避ける：「実体のカット」と「鏡面の切り返しカット」の2つのサブカットに分けることを優先する

## 参照画像の予算（ハード制約）

- 1カットあたり参照画像は最大9枚。動画生成時は先頭キーフレームが先に1枚を占めるため、実際に使えるのは：シーン 1 ＋ キャラクター N ＋ 小道具 M ≤ 8
- 予算超過時は優先度で取捨する：シーン ＞ 登場キャラクター ＞ 使用される／寄りで映る小道具 ＞ 見えているだけの小道具
- 外された小道具は紐付けと @ 参照を同時に削除する。「@ したのに紐付けがない」名前を残さない
- キーフレームプロンプトでは、この絵コンテに紐付け済みのシーン／キャラクター／小道具のみ @ する

## 各キーフレームプロンプトは自己完結すること

各キーフレームは独立して生成される（資産参照画像＋この1本のプロンプトだけ）：

- 「前のフレームと同じ」「変わらない」「前の構図を引き継ぐ」は禁止
- 各プロンプトが自ら説明すること：`@シーン名` ＋ 画面サイズ／カメラアングル／構図 ＋ 各 `@キャラクター名` の位置・姿勢・四肢状態・表情 ＋ 主要な `@小道具名` と着用・把持状態 ＋ `atmosphere` から取った光と雰囲気
- ひと続きの文章として書き、箇条書きや番号付けをしない

## 執筆構造（推奨順序）

**@シーン名 ＋ 時間／光 → 画面サイズとカメラアングル → 構図（誰が画面のどこにいるか） → 主体 @キャラクター名 の姿勢・四肢状態・表情・視線 → 主要 @小道具名 と相互作用／着用状態 → 雰囲気と光 → 締めの語句**

末尾には一律で付ける：16:9 横構図の映画的スチル、単一静止フレーム。

例（先頭フレーム、小道具と四肢状態を含む）：

```
@ベランダ、早朝、明るく暖色の朝日が床一面に均等に広がる、16:9 横構図の映画的スチル。ミディアムショット、目線の高さ、固定カメラ。@ジーニ が画面中央の @トレーニングマット の上に立ち、両前足で胸の前に @ミニダンベル を1つ抱え、もう1つの @ミニダンベル はマットの右前方に平置き、両脚を揃えて安定して立ち、2本の後ろ足はどちらもマットを踏んでいて明瞭に見える。表情は真剣で、視線は腕の中のダンベルに落ちている。画面の四方には開けたベランダの床が残され、朝日は柔らかく濃い影がない。単一静止フレーム、モーションブラーなし。
```

例（末尾フレーム、次のパラグラフに引き継がれる場合）：

```
@リビング、午後、淡い暖色の自然光が空間に均等に広がる、16:9 横構図の映画的スチル。ミディアムショット、目線の高さ、固定カメラ。@サルの赤ちゃん が画面中央やや右の @姿見 の前に立ち、体は画面外のソファの方を正面に向け、右手は @サングラス を胸の前で握り、左手は体側に自然に垂れ、両脚を揃えて立ち両足裏が接地して見える。口を少し尖らせ、視線は画面外へ。鏡面は画面の右端のみを占め、彼の背面の一部を映す。構図は安定し、人物は完全に画面内に収まる。単一静止フレーム、モーションブラーなし。
```

## 末尾フレームの追加要件

次のパラグラフが本パラグラフの末尾フレームを先頭フレームとして使う可能性があるため、末尾フレームは**そのまま芝居を続けられる画面**でなければならない：

- 人物は完全に画面内で姿勢が安定していること。「フレームアウト中」「背を向けて遠ざかる」「動作途中のモーションブラー」は不可
- 物だけの大アップで終わらない（次のパラグラフが本当に `cut` の場合を除く）
- 次のパラグラフで登場が必要なキャラクターと、その**手に持つ／身に着けている小道具**が画面内にあること（状態は `result` と一致）
- `result` の記述と一致すること

## 禁止事項

- キャラクターの外見属性（種族／服装／色／髪型／体型／顔立ち／年齢）全般
- 相対的な記述（「同上」「変わらず」）、時間の進行（「そして」「その後」）
- 動きの描写（カメラワーク、動作の経過）——キーフレームは静止した一瞬
- 否定形の四肢指示（「三本脚にしない」「2人に描かない」）——肯定形の完全列挙で代替する
- 台詞、ナレーション、字幕、画面外の声
- 参照リスト外のシーン／キャラクター／小道具名
- @ 可能な資産の素のテキストでの指示（「あの鏡」「画面外の鏡」）。最初の言及としての集合呼称（父母／二人／彼ら）
- 抽象的な心理描写、文学的な比喩
- 会話言語の指示と一致しない言語

## 保存

`update_storyboard`（または絵コンテ分解時の `save_storyboards`）を呼び出してキーフレームフィールドを書き込む。単独で生成する場合、`update_storyboard` には `storyboard_id` とキーフレームフィールドのみを渡し、他のフィールドを返さず、話全体を再分解しない。
