# キーフレームプロンプト（絵コンテパラグラフ → first/mid/last_frame_prompt）

各絵コンテパラグラフは、動画を生成する前にまず**静止キーフレーム画像**を一式作る：先頭フレーム、（任意の）中間フレーム、末尾フレーム。動画生成時は先頭フレームが `<画像1>` 兼第0フレームのアンカーとなり、中間フレーム／末尾フレームはタイムライン上のアンカーとなる。さらにシーン／キャラクター／小道具の参照画像が重ねられる。したがってキーフレームが動画全体の画面品質と人物の一貫性を決める。

1本のキーフレームプロンプトが描くのは**そのパラグラフ内のある静止した一瞬**であり、動きの経過ではない。時間の進行を書かず、「そして」「続いて」も書かない。

## 3枚のキーフレームの定義

| スロット | フィールド | 対応する瞬間 |
|---|---|---|
| 先頭フレーム | `first_frame_prompt` | `【镜头1】` の冒頭の一瞬 |
| 中間フレーム | `mid_frame_prompt` ＋ `mid_frame_time` | `mid_frame_time` 秒の時点にあるサブカットの開始の一瞬 |
| 末尾フレーム | `last_frame_prompt` | パラグラフ終了の一瞬。`result` の記述と一致 |

- `mid_frame_time` の単位は**秒**（そのパラグラフ冒頭からの相対）。必ずいずれかの `【镜头N】`（N ≥ 2）の開始時刻と正確に一致し、かつ 0.5秒 と `duration - 0.5` 秒の間に厳密に収まること
- 中間フレームの選び方：**最初のサブカット以外で最も重要なサブカット**（カットの切り替え点、感情の転換、重要な動作が起こる点）の開始時刻を選ぶ。パラグラフにサブカットが1つしかない場合は、`mid_frame_prompt` と `mid_frame_time` のどちらも書かない
- 引き継ぎパラグラフ（`continuity` が `continue`、`inherits_first` が `true`）：先頭フレームは**直前のパラグラフの末尾キーフレーム画像**をそのまま使うため、`first_frame_prompt` は必ず空にする。同時に、直前のパラグラフの `last_frame_prompt` は安定して情報が明確で、そのまま本パラグラフの冒頭画面として使える画面にしておくこと

## 絶対ルール：画像優先

キャラクターの見た目はアセット参照画像によって完全に決まる。**プロンプトの文字描写が参照画像と矛盾した瞬間に画面は崩れる**。

- キャラクターの種族・生物種・服装・色・髪型・体型・年齢・顔立ちなど、いかなる外観属性も**記述禁止**
- キャラクターは一律に `@キャラクター名` のみで指し示す。例：「@小満 は画面左側に立ち、半身で振り返る」
- **キャラクター名は単なる符号**であり、名前から見た目を推測しない（名前に「猫」「鼠」「老王」などが含まれていても外観を意味しない）
- シーン・小道具も同様：`@シーン名` / `@小道具名` で参照し、参照画像にない「今この瞬間の状態」（誰がどこにいるか、どんな姿勢か、光はどうか）だけを補う
- 書いてよいもの：ショットサイズ、カメラアングル、構図、画面内での人物の位置、姿勢、体の動き、表情、視線の方向、小道具とのインタラクション、光と雰囲気

## 各キーフレームプロンプトは自己完結すること

**キーフレームは1枚ずつ独立して生成される**：生成時にはアセット参照画像とそのプロンプト1本だけが渡され、モデルは他のキーフレームを見られない。したがって：

- 「前のフレームと同じ」「変化なし」「前の構図を継続」「前の1枚をベースに」といった相対的な記述は禁止
- 各プロンプトが自力で示すこと：`@シーン名` ＋ ショットサイズ／カメラ位置／構図 ＋ 画面にいる `@キャラクター名` とそれぞれの位置・姿勢・表情 ＋ 重要な `@小道具名` ＋ `atmosphere` から取った光と雰囲気
- ひと続きの連続した記述として書く。箇条書きや番号付けはしない

## 記述の構成（推奨順序）

**@シーン名 ＋ 時間／光 → ショットサイズとカメラアングル → 構図（誰が画面のどこにいるか） → 主体 @キャラクター名 の姿勢・動作の瞬間・表情・視線 → 重要な @小道具名 とのインタラクション → 雰囲気と光 → 映画的な静止フレームの締め文**

末尾には画面比と質感の記述を統一して添える：16:9 横構図の映画的スチル、単一フレームの静止画面。

例（先頭フレーム）：

```
@古い屋敷の居間、夕方、16:9 横構図の映画的スチル。ミディアムショットの目線固定カメラ。@小満 は画面左三分の一の位置で、八仙卓の脇に半身で立ち、右手がちょうど卓上の @銅鈴 に触れたところ。肩は張り詰め、顎を軽く引き、視線は画面右側の軒先を越えて外へ向かう。画面右側には空の軒先を視覚的な抜けとして残す。夕日の光が軒先から斜めに差し込み、床タイルに細長い光の帯を描く。全体は暖かい黄みがかったオレンジで、暗部は沈んでいる。単一フレームの静止画面、モーションブラーなし。
```

例（末尾フレーム、次のパラグラフに引き継がれる場合）：

```
@古い屋敷の居間、夕方、16:9 横構図の映画的スチル。ミディアムショットの目線固定カメラ。@小満 は画面中央やや左の八仙卓の前に立ち、両手で @銅鈴 を胸の高さに捧げ持って静止し、体は正面をカメラに向け、うつむいて手の中の鈴を見つめ、唇を軽く結ぶ。画面右側の軒先は空いており、光はすでに落ちている。全体は暖かい黄みから灰青へ移り、輪郭は明瞭で構図は安定している。単一フレームの静止画面、人物は全身が画面に収まり、モーションブラーなし。
```

## 末尾フレームへの追加要件

次のパラグラフが本パラグラフの末尾フレームを自分の先頭フレームとして使う可能性があるため、末尾フレームは**そのまま演技を続けられる画面**でなければならない：

- 人物は完全に画面に収まり、姿勢は安定していること。「画面外へ出かけている」「背を向けて遠ざかる」「動作の途中のモーションブラー」などを書かない
- 単なる物品の大クローズアップで締めない（次のパラグラフが確実に `cut` の場合を除く）
- 次のパラグラフで登場が必要なキャラクターが画面内にいること
- `result` の記述と一致させる（`result` は末尾画面の結果と細部を書いたもので、末尾フレームプロンプトはそれを画像生成可能な単一フレームの構図に翻訳したもの）

## 禁止事項

- キャラクターのあらゆる外観属性（種族／生物種／服装／色／髪型／体型／顔立ち／年齢）
- 相対的な記述（「同上」「変化なし」「継続」）、時間の進行（「そして」「その後」「続いてカメラが寄る」）
- 動きの記述（カメラワーク、プッシュイン／プルバック／パン／移動、動作の経過）——キーフレームは静止した一瞬である
- セリフ、ナレーション、字幕、画面外の声
- 参照リストにないシーン／キャラクター／小道具の名前
- 抽象的な心理描写、文学的な比喩（目に見える画面だけを書く）
- セッションの言語指令に合致しない言語

## 保存

`update_storyboard`（または絵コンテ分解時の `save_storyboards`）を呼び出して `first_frame_prompt` / `mid_frame_prompt` / `mid_frame_time` / `last_frame_prompt` を書き込む。キーフレームプロンプトだけを単独で生成する場合、`update_storyboard` には `storyboard_id` とこれらのキーフレームフィールドのみを渡し、他のフィールドを返さず、話全体を再分解しない。
