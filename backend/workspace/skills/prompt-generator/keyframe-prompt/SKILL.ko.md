# 키프레임 프롬프트(스토리보드 구간 → first/mid/last_frame_prompt)

각 스토리보드 구간은 비디오를 생성하기 전에 먼저 **정지 키프레임 이미지** 세트를 만듭니다: 첫 프레임, (선택적) 중간 프레임, 끝 프레임. 비디오 생성 시 첫 프레임은 `<이미지1>` 이자 0번 프레임 앵커가 되고, 중간 프레임/끝 프레임은 타임라인 앵커가 되며, 그 위에 장면/캐릭터/소품 참조 이미지가 더해집니다. 따라서 키프레임이 비디오 전체의 화면 품질과 인물 일관성을 결정합니다.

하나의 키프레임 프롬프트는 **해당 구간의 어느 한 정지 순간**을 묘사하며, 움직임을 쓰지 않고, 시간의 진행도 쓰지 않으며, "그다음" "이어서" 같은 표현도 쓰지 않습니다.

## 세 장의 키프레임 정의

| 슬롯 | 필드 | 대응 순간 |
|---|---|---|
| 첫 프레임 | `first_frame_prompt` | `【镜头1】` 의 시작 순간 |
| 중간 프레임 | `mid_frame_prompt` + `mid_frame_time` | `mid_frame_time` 초 지점에 있는 서브 컷의 시작 순간 |
| 끝 프레임 | `last_frame_prompt` | 구간이 끝나는 순간, `result` 묘사와 일치 |

- `mid_frame_time` 의 단위는 **초**(구간 시작 기준)이며, 반드시 어떤 `【镜头N】`(N ≥ 2)의 시작 시각과 정확히 일치하고, 0.5초와 `duration - 0.5` 초 사이에 엄격히 들어가야 합니다
- 중간 프레임 선택 규칙: **첫 번째 서브 컷을 제외하고 가장 중요한 서브 컷**(컷 전환 지점, 감정 전환점, 핵심 동작이 일어나는 지점)의 시작 순간을 고릅니다; 구간에 서브 컷이 하나뿐이면 `mid_frame_prompt` 와 `mid_frame_time` 둘 다 쓰지 않습니다
- 이어받는 구간(`continuity` 가 `continue`, `inherits_first` 가 `true`): 첫 프레임은 **앞 구간의 끝 키프레임 이미지**를 그대로 물려받으므로 `first_frame_prompt` 는 반드시 비워 둡니다; 동시에 앞 구간의 `last_frame_prompt` 는 안정적이고 정보가 명확하여 이 구간의 오프닝으로 바로 쓸 수 있는 화면이어야 합니다

## 절대 규칙: 이미지 우선

캐릭터의 생김새는 전적으로 자산 참조 이미지가 결정하며, **프롬프트의 문자 묘사가 참조 이미지와 충돌하는 순간 결과 이미지가 무너집니다**.

- 캐릭터의 종(種), 종족, 의상, 색상, 헤어스타일, 체형, 나이, 이목구비 등 **어떤 외형 속성도 묘사 금지**
- 캐릭터는 오직 `@캐릭터명` 으로만 지칭합니다. 예: "@샤오만 이 화면 왼쪽에 서서 몸을 틀어 뒤를 돌아본다"
- **캐릭터 이름은 코드명일 뿐**이므로 이름에서 생김새를 추론하지 마세요(이름에 "고양이" "쥐" "노인"이 들어가도 외형과 무관합니다)
- 장면과 소품도 동일합니다: `@장면명` / `@소품명` 으로 참조하고, 참조 이미지에 없는 「이 순간의 상태」(누가 어디에, 어떤 자세로, 조명은 어떤지)만 보충합니다
- 쓸 수 있는 것: 화면 크기, 카메라 앵글, 구도, 인물의 화면 내 위치, 자세, 신체 동작, 표정, 시선 방향, 소품과의 상호작용, 조명과 분위기

## 모든 키프레임 프롬프트는 자족적이어야 합니다

**각 키프레임은 독립적으로 생성됩니다**: 생성 시 자산 참조 이미지 + 이 프롬프트 하나만 주어지며, 모델은 다른 키프레임을 보지 못합니다. 따라서:

- "앞 프레임과 동일" "그대로 유지" "앞의 구도를 이어감" "앞 장을 기반으로" 같은 상대적 묘사는 금지
- 각 프롬프트가 스스로 밝혀야 할 것: `@장면명` + 화면 크기/카메라 위치/구도 + 화면 안에 어떤 `@캐릭터명` 들이 각각 어디에 어떤 자세와 표정으로 있는지 + 핵심 `@소품명` + `atmosphere` 에서 가져온 조명과 분위기
- 하나의 연결된 문단으로 쓰고, 항목으로 나누거나 번호를 매기지 마세요

## 작성 구조(권장 순서)

**@장면명 + 시간/조명 → 화면 크기와 카메라 앵글 → 구도(누가 화면 어디에) → 주체 @캐릭터명 의 자세·동작 순간·표정·시선 → 핵심 @소품명 과 상호작용 → 분위기 조명 → 영화적 정지 프레임 마무리 문구**

마지막에는 화면비와 질감 묘사를 통일해서 붙입니다: 16:9 가로 구도의 영화적 스틸, 단일 정지 프레임.

예시(첫 프레임):

```
@고택 거실, 해 질 녘, 16:9 가로 구도의 영화적 스틸. 미디엄샷 아이레벨 고정 카메라, @샤오만 이 화면 왼쪽 3분의 1 지점에서 팔선탁 옆에 몸을 틀고 서 있고, 오른손이 탁자 위의 @구리 방울 에 막 닿았으며, 어깨가 긴장되고 턱을 살짝 당긴 채 시선은 화면 오른쪽 문간을 지나 바깥을 향한다. 화면 오른쪽에는 빈 문간을 시각적 출구로 남겨 둔다. 석양빛이 문간에서 비스듬히 들어와 바닥 타일 위에 긴 빛 띠를 만들고, 전체적으로 따뜻한 노랑에서 주황 기운이 돌며 어두운 부분은 가라앉아 있다. 단일 정지 프레임, 모션 블러 없음.
```

예시(끝 프레임, 다음 구간이 이어받는 경우):

```
@고택 거실, 해 질 녘, 16:9 가로 구도의 영화적 스틸. 미디엄샷 아이레벨 고정 카메라, @샤오만 이 화면 중앙에서 약간 왼쪽에 있는 팔선탁 앞에 서서 두 손으로 @구리 방울 을 받쳐 든 채 가슴 앞에 멈춰 있고, 몸은 정면으로 카메라를 향하며, 고개를 숙여 손안의 방울을 바라보고 입술을 가볍게 다물고 있다. 화면 오른쪽 문간은 비어 있고 빛은 이미 어둑해졌다. 전체 색조는 따뜻한 노랑에서 회청색으로 바래고, 윤곽은 또렷하며 구도는 안정적이다. 단일 정지 프레임, 인물이 화면에 온전히 들어오고, 모션 블러 없음.
```

## 끝 프레임의 추가 요구 사항

다음 구간이 이 구간의 끝 프레임을 자신의 첫 프레임으로 쓸 수 있으므로, 끝 프레임은 반드시 **이어서 연기할 수 있는 화면**이어야 합니다:

- 인물이 화면에 온전히 들어오고 자세가 안정적이어야 하며, "화면 밖으로 나가는 중" "등을 돌리고 멀어지는 중" "동작 도중의 모션 블러" 같은 것을 쓰지 마세요
- 순수한 사물 클로즈업으로 끝내지 마세요(다음 구간이 실제로 `cut` 인 경우는 예외)
- 화면 안에 다음 구간에 등장해야 할 캐릭터가 있어야 합니다
- `result` 묘사와 일치해야 합니다(`result` 는 끝 화면의 결과와 디테일을 쓰고, 끝 프레임 프롬프트는 그것을 생성 가능한 단일 프레임 구도로 옮긴 것)

## 금지 사항

- 캐릭터의 모든 외형 속성(종/의상/색상/헤어스타일/체형/이목구비/나이)
- 상대적 묘사("위와 같음" "변화 없음" "이어서"), 시간 진행("그다음" "곧이어" "이어서 카메라가 밀고 들어간다")
- 움직임 묘사(카메라 무빙, 푸시인/풀백/팬/트래킹, 동작 과정) — 키프레임은 정지된 한 순간입니다
- 대사, 내레이션, 자막, 보이스오버
- 참조 목록 밖의 장면/캐릭터/소품명
- 추상적 심리 묘사, 문학적 비유(보이는 화면만 쓰기)
- 세션 언어 지시와 맞지 않는 언어

## 저장

`update_storyboard`(또는 스토리보드 분할 시의 `save_storyboards`)를 호출해 `first_frame_prompt` / `mid_frame_prompt` / `mid_frame_time` / `last_frame_prompt` 를 기록합니다. 키프레임 프롬프트만 따로 생성할 때는 `update_storyboard` 에 `storyboard_id` 와 이 키프레임 필드들만 전달하고, 다른 필드를 되돌려 보내거나 전체 화를 다시 분할하지 마세요.
