# 키프레임 프롬프트(스토리보드 구간 → first/mid/last_frame_prompt)

각 스토리보드 구간은 비디오를 생성하기 전에 먼저 **정지 키프레임 이미지** 세트를 만듭니다: 첫 프레임, (선택적) 중간 프레임, 끝 프레임. 비디오 생성 시 첫 프레임은 0번 프레임 앵커가 되고, 중간 프레임/끝 프레임은 타임라인 앵커가 되며, 그 위에 장면/캐릭터/소품 참조 이미지가 더해집니다. 따라서 키프레임이 비디오 전체의 화면 품질과 인물 일관성을 결정합니다.

하나의 키프레임 프롬프트는 **해당 구간의 어느 한 정지 순간**을 묘사하며, 움직임을 쓰지 않고, 시간의 진행도 쓰지 않으며, "그다음" "이어서" 같은 표현도 쓰지 않습니다.

## 세 장의 키프레임 정의

| 슬롯 | 필드 | 대응 순간 |
|---|---|---|
| 첫 프레임 | `first_frame_prompt` | `【镜头1】` 의 시작 순간 |
| 중간 프레임 | `mid_frame_prompt` + `mid_frame_time` | `mid_frame_time` 초 지점 서브 컷의 시작 순간 |
| 끝 프레임 | `last_frame_prompt` | 구간이 끝나는 순간, `result` 묘사와 일치 |

- `mid_frame_time` 의 단위는 **초**(구간 시작 기준 상대값)이며, 반드시 어떤 `【镜头N】`(N ≥ 2)의 시작 시각과 정확히 일치하고 0.5초와 `duration - 0.5` 초 사이에 엄격히 들어가야 합니다
- 중간 프레임은 첫 번째 서브 컷을 제외한 **가장 중요한 서브 컷**의 시작 시점을 고릅니다. 구간에 서브 컷이 하나뿐이면 둘 다 쓰지 않습니다
- 이어받는 구간(`continuity` 가 `continue`, `inherits_first` 가 `true`): `first_frame_prompt` 는 반드시 비워 둡니다. 대신 이전 구간의 `last_frame_prompt` 가 안정적이고 정보가 명확하여 그대로 이 구간의 시작 화면으로 쓸 수 있는 화면이어야 합니다

## 절대 규칙: 이미지 우선

캐릭터의 생김새와 의상은 전적으로 에셋 참조 이미지(스타일링 버전 이미지 포함)가 결정합니다. **텍스트 묘사가 참조 이미지와 충돌하는 순간 생성 결과가 무너집니다.**

- 캐릭터의 종, 인종, 의상, 색상, 헤어스타일, 체형, 나이, 이목구비 묘사 **금지**
- 캐릭터는 오직 `@캐릭터명` 으로만 지칭합니다. **이름은 코드일 뿐**이므로 이름에서 생김새를 추론하지 마세요
- 장면과 소품도 동일: `@장면명` / `@소품명` 으로 참조하고 "지금 이 순간의 상태"만 덧붙입니다
- **허용**: 상대 체격 비율("@쥐엄마 의 키는 @돼지아빠 의 약 3분의 2" — 비율은 생김새가 아님), 착용형 소품의 착용 상태("콧등에 @선글라스 를 걸침", "@파나마모자 를 왼손에 듦" — 이는 소품 참조)
- 쓸 수 있는 것: 화면 크기, 카메라 앵글, 구도, 인물 위치, 자세, 사지 동작, 표정, 시선, 소품과의 상호작용, 빛과 분위기

## 사지 상태 자가 점검 목록(프롬프트마다 항목별로 확인)

화면에 등장하는 **모든** 캐릭터에 대해:

1. **양손**: 각각 어디서 무엇을 하는지. 물건을 들면 "어느 손인지" 명시. 빈 손도 씁니다("왼손은 몸 옆에 자연스럽게 늘어뜨림")
2. **양다리**: 서기/앉기/쪼그리기/꼬기의 구체적 자세와 가시성 — 고위험 자세는 긍정형으로 완전히 열거: "왼다리를 오른다리 위에 포개고 두 발은 몸 아래로 모아, 화면에 두 발바닥이 보임". "다리 세 개 그리지 마" 같은 **부정 지시는 쓰지 않습니다**(무효)
3. **가림**: 몸통에 완전히 가려지는 사지 동작은 쓰지 않습니다. "손을 등 뒤로 보냄"이 필요하면 몸을 비껴 보이게 하는 동등한 자세로 바꿔 씁니다
4. **접촉**: 두 캐릭터가 접촉하면 양쪽의 사지 최종 상태를 모두 쓰고 접촉 지점은 하나만("@쥐엄마 의 오른앞발이 @원숭이아기 의 왼무릎을 누르고, @원숭이아기 는 두 손으로 의자 바닥을 짚음")
5. **착용 상태**: 모자, 안경, 선글라스 등은 프레임마다 선언 — 착용 중 / 어느 손에 들고 있음 / 화면에 없음
6. **비인간 체형**: 팔다리가 짧고 몸이 둥근 캐릭터에 인간의 표준 자세를 적용하지 말고, 그 체형으로 가능한 버전을 씁니다(두 앞발을 가슴 앞에 모아 안기, "두 팔을 몸 옆에 늘어뜨려 덤벨을 들기"가 아님)

## 거울과 화면 규칙

- 화면에 전신 거울이나 반사가 있으면 같은 프레임에서는 **거울상** 또는 **실체** 중 하나만 주체로 삼습니다: 거울상을 찍으면 거울 프레임을 온전히 화면에 넣고 실체는 뒷모습 일부만 보이게 명시하며, 실체를 찍으면 거울면을 화면 가장자리에 두거나 흐리게 합니다
- 거울 속 내용은 항목별로 명시하고(누가, 어떤 자세로, 무엇을 착용했는지) 실체와 일치해야 합니다
- 화면 안의 TV/스크린은 프로그램 영상(풍경, 뉴스 화면 등)만 재생하며, **본 작품의 캐릭터가 등장하는 것은 금지**
- 다중 캐릭터 + 거울면은 가장 위험한 조합이므로 피할 수 있으면 피합니다: "실체 컷"과 "거울면 리버스 컷" 두 개의 서브 컷으로 나누는 것을 우선합니다

## 참조 이미지 예산(강제 제약)

- 컷당 참조 이미지는 최대 9장이며, 비디오 생성 시 첫 키프레임이 먼저 1장을 차지하므로 실제 가용은: 장면 1 + 캐릭터 N + 소품 M ≤ 8
- 예산을 넘으면 우선순위로 버립니다: 장면 > 등장 캐릭터 > 사용되거나 클로즈업되는 소품 > 보이기만 하는 소품
- 밀려난 소품은 바인딩과 @ 참조를 함께 제거합니다. "@ 했는데 바인딩이 없는" 이름을 남기지 마세요
- 키프레임 프롬프트는 이 스토리보드에 바인딩된 장면/캐릭터/소품만 @ 합니다

## 모든 키프레임 프롬프트는 자족적이어야 함

각 키프레임은 독립적으로 생성됩니다(에셋 참조 이미지 + 이 프롬프트 하나만):

- "앞 프레임과 같음" "그대로 유지" "앞의 구도를 이어감" 금지
- 각 프롬프트가 스스로 설명해야 합니다: `@장면명` + 화면 크기/카메라 앵글/구도 + 각 `@캐릭터명` 의 위치, 자세, 사지 상태, 표정 + 핵심 `@소품명` 과 착용·파지 상태 + `atmosphere` 에서 가져온 빛과 분위기
- 한 단락의 연속된 묘사로 쓰고, 항목화나 번호 매기기를 하지 않습니다

## 작성 구조(권장 순서)

**@장면명 + 시간/빛 → 화면 크기와 카메라 앵글 → 구도(누가 화면 어디에) → 주체 @캐릭터명 의 자세·사지 상태·표정·시선 → 핵심 @소품명 과 상호작용/착용 상태 → 분위기와 빛 → 마무리 문구**

끝에는 일괄적으로 붙입니다: 16:9 가로 구도 영화적 스틸, 단일 정지 화면.

예시(첫 프레임, 소품과 사지 상태 포함):

```
@발코니, 이른 아침, 밝고 따뜻한 아침 햇살이 바닥에 고르게 퍼짐, 16:9 가로 구도 영화적 스틸. 미디엄 샷, 눈높이 고정 카메라, @지니 가 화면 중앙의 @트레이닝매트 위에 서서 두 앞발로 가슴 앞에 @미니덤벨 하나를 끌어안고, 다른 @미니덤벨 은 매트 오른쪽 앞에 평평히 놓여 있으며, 두 다리를 모아 안정적으로 서고 두 뒷발 모두 매트를 디뎌 또렷이 보입니다. 표정은 집중해 있고 시선은 품 안의 덤벨에 머뭅니다. 화면 사방에 트인 발코니 바닥이 남고, 아침 빛은 부드러워 짙은 그림자가 없습니다. 단일 정지 화면, 모션 블러 없음.
```

예시(끝 프레임, 다음 구간이 이어받는 경우):

```
@거실, 오후, 연한 따뜻한 자연광이 공간에 고르게 퍼짐, 16:9 가로 구도 영화적 스틸. 미디엄 샷, 눈높이 고정 카메라, @원숭이아기 가 화면 중앙에서 약간 오른쪽의 @전신거울 앞에 서서 몸은 화면 밖 소파 쪽을 정면으로 향하고, 오른손은 @선글라스 를 가슴 앞에 쥐고, 왼손은 몸 옆에 자연스럽게 늘어뜨리며, 두 다리를 모아 서고 두 발바닥이 바닥에 닿아 보입니다. 입을 살짝 내밀고 시선은 화면 밖을 향합니다. 거울면은 화면 오른쪽 가장자리만 차지하며 그의 뒷모습 일부를 비춥니다. 구도는 안정적이고 인물은 온전히 화면 안에 들어옵니다. 단일 정지 화면, 모션 블러 없음.
```

## 끝 프레임의 추가 요구

다음 구간이 이 구간의 끝 프레임을 첫 프레임으로 쓸 수 있으므로, 끝 프레임은 **이어서 연기할 수 있는 화면**이어야 합니다:

- 인물이 온전히 화면에 들어오고 자세가 안정적일 것. "프레임을 빠져나가는 중" "등을 돌려 멀어짐" "동작 중의 모션 블러" 금지
- 사물만의 큰 클로즈업으로 끝내지 않기(다음 구간이 정말 `cut` 인 경우 제외)
- 다음 구간에 등장해야 하는 캐릭터와 그가 **들고/착용한 소품**이 화면에 있을 것(상태는 `result` 와 일치)
- `result` 묘사와 일치할 것

## 금지 사항

- 캐릭터의 외형 속성 일체(종/의상/색상/헤어스타일/체형/이목구비/나이)
- 상대적 서술("위와 같음" "변함없음"), 시간 진행("그다음" "이어서")
- 움직임 묘사(카메라 워크, 동작 과정) — 키프레임은 정지한 한 순간
- 부정형 사지 지시("다리 세 개 금지" "두 사람으로 그리지 말 것") — 긍정형 완전 열거로 대체
- 대사, 내레이션, 자막, 화면 밖 음성
- 참조 목록 밖의 장면/캐릭터/소품 이름
- 추상적 심리 묘사, 문학적 비유
- 대화 언어 지시와 맞지 않는 언어

## 저장

`update_storyboard`(또는 스토리보드 분할 시의 `save_storyboards`)를 호출해 키프레임 필드를 기록합니다. 단독으로 생성할 때는 `update_storyboard` 에 `storyboard_id` 와 키프레임 필드만 전달하고, 다른 필드를 되돌려 보내거나 전체 화를 다시 분할하지 마세요.
