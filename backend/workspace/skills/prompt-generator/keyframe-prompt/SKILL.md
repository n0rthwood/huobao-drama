# 关键帧提示词（分镜段落 → first/mid/last_frame_prompt）

每个分镜段落在生成视频之前，先生成一组**静态关键帧图片**：首帧、（可选的）中间帧、尾帧。视频生成时首帧作为 `<图片1>` 与第 0 帧锚点，中间帧/尾帧作为时间轴锚点，再叠加场景/角色/道具参考图。因此关键帧决定了整条视频的画面质量与人物一致性。

一条关键帧提示词描述的是**该段落中的某一个静止瞬间**，不是一段运动，不写时间推进，不写"然后""接着"。

## 三张关键帧的定义

| 槽位 | 字段 | 对应瞬间 |
|---|---|---|
| 首帧 | `first_frame_prompt` | `【镜头1】` 的开场瞬间 |
| 中间帧 | `mid_frame_prompt` + `mid_frame_time` | `mid_frame_time` 秒处那个子镜头的起始瞬间 |
| 尾帧 | `last_frame_prompt` | 段落结束瞬间，与 `result` 描述一致 |

- `mid_frame_time` 单位是**秒**（相对该段落开头），必须正好是某个 `【镜头N】`（N ≥ 2）的起始时间，且严格落在 0.5 秒与 `duration - 0.5` 秒之间
- 中间帧选择规则：挑**除第一个子镜头以外最重要的那个子镜头**（切镜点、情绪转折、关键动作发生点）的起始时刻；段落只有一个子镜头时，`mid_frame_prompt` 与 `mid_frame_time` 都不要写
- 承接段落（`continuity` 为 `continue`、`inherits_first` 为 `true`）：首帧直接沿用**上一段落的尾关键帧图片**，因此 `first_frame_prompt` 必须留空；同时要保证上一段落的 `last_frame_prompt` 写的是稳定、信息清晰、可直接当作本段开场的画面

## 绝对规则：图像优先

角色长相完全由资产参考图决定，**提示词里的文字描述一旦和参考图冲突，出图就会崩**。

- **禁止**描写角色的物种、种族、服装、颜色、发型、体型、年龄、五官等任何外观属性
- 角色一律只用 `@角色名` 指代，例如"@小满 站在画面左侧，侧身回头"
- **角色名只是代号**，不要从名字推断长相（名字里带"猫""鼠""老王"都不代表外观）
- 场景、道具同理：用 `@场景名` / `@道具名` 引用，只补充参考图里没有的「此刻状态」（谁在哪、什么姿态、光线如何）
- 可以写的：景别、机位角度、构图、人物在画面中的位置、姿态、肢体动作、表情、视线方向、与道具的交互、光线与氛围

## 每条关键帧提示词必须自足

**每张关键帧都是独立出图的**：出图时只给资产参考图 + 这一条提示词，模型看不到其他关键帧。因此：

- 禁止写"同上一帧""保持不变""延续前面的构图""在前一张基础上"这类相对描述
- 每条都要自己交代：`@场景名` + 景别/机位/构图 + 画面里有哪几个 `@角色名` 及各自位置、姿态、表情 + 关键 `@道具名` + 取自 `atmosphere` 的光线氛围
- 写成一段连贯的描述，不要分点、不要编号

## 写作结构（推荐顺序）

**@场景名 + 时间/光线 → 景别与机位角度 → 构图（谁在画面什么位置） → 主体 @角色名 的姿态·动作瞬间·表情·视线 → 关键 @道具名 及交互 → 氛围光线 → 电影感静帧收尾语**

结尾统一加上画幅与质感描述：16:9 横构图电影感剧照，单帧静态画面。

示例（首帧）：

```
@老宅客厅，傍晚，16:9 横构图电影感剧照。中景平视固定机位，@小满 位于画面左三分之一处，侧身站在八仙桌旁，右手刚刚触到桌面上的 @铜铃，肩膀绷紧，下巴微收，视线越过画面右侧的门廊看向门外。画面右侧留出空门廊作为视觉出口。夕光从门廊斜切进来，在地砖上拉出长条光斑，整体暖黄偏橙、暗部沉。单帧静态画面，无运动模糊。
```

示例（尾帧，需要被下一段承接）：

```
@老宅客厅，傍晚，16:9 横构图电影感剧照。中景平视固定机位，@小满 站在画面中央偏左的八仙桌前，双手捧起 @铜铃 停在胸前，身体正面朝向镜头，低头看着手中的铃铛，嘴唇微抿。画面右侧门廊空着，光线已经转暗。整体暖黄褪为灰蓝，轮廓清晰、构图稳定。单帧静态画面，人物完整入画，无运动模糊。
```

## 尾帧的额外要求

下一段落可能把本段尾帧当作它的首帧，所以尾帧必须是**可被接着演下去的画面**：

- 人物完整入画、姿态稳定，不要写"正在出画""背身走远""动作做到一半的运动模糊"
- 不要收在纯物件大特写上（除非下一段确实是 `cut`）
- 画面里要有下一段需要出场的角色
- 与 `result` 描述一致（`result` 写的是结尾画面的后果与细节，尾帧提示词把它翻译成可出图的单帧构图）

## 禁止事项

- 任何角色外观属性（物种/服装/颜色/发型/体型/五官/年龄）
- 相对描述（"同上""不变""延续"）、时间推进（"然后""随后""接着镜头推进"）
- 运动描写（运镜、推拉摇移、动作过程）——关键帧是静止的一瞬
- 台词、旁白、字幕、画外音
- 引用列表之外的场景/角色/道具名
- 抽象心理描写、文学化比喻（只写可见画面）
- 语言与会话语言指令不符

## 保存

调用 `update_storyboard`（或分镜拆解时的 `save_storyboards`）写入 `first_frame_prompt` / `mid_frame_prompt` / `mid_frame_time` / `last_frame_prompt`。单独生成关键帧提示词时，`update_storyboard` 只传 `storyboard_id` 与这几个关键帧字段，不要回传其他字段，不要重新拆分整集。
