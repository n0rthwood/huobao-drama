# 关键帧提示词（分镜段落 → first/mid/last_frame_prompt）

每个分镜段落在生成视频之前，先生成一组**静态关键帧图片**：首帧、（可选的）中间帧、尾帧。视频生成时首帧作为第 0 帧锚点，中间帧/尾帧作为时间轴锚点，再叠加场景/角色/道具参考图。关键帧决定了整条视频的画面质量与人物一致性。

一条关键帧提示词描述的是**该段落中的某一个静止瞬间**，不是一段运动，不写时间推进，不写「然后」「接着」。

## 三张关键帧的定义

| 槽位 | 字段 | 对应瞬间 |
|---|---|---|
| 首帧 | `first_frame_prompt` | `【镜头1】` 的开场瞬间 |
| 中间帧 | `mid_frame_prompt` + `mid_frame_time` | `mid_frame_time` 秒处那个子镜头的起始瞬间 |
| 尾帧 | `last_frame_prompt` | 段落结束瞬间，与 `result` 描述一致 |

- `mid_frame_time` 单位是**秒**（相对段落开头），必须正好是某个 `【镜头N】`（N ≥ 2）的起始时间，且严格落在 0.5 秒与 `duration - 0.5` 秒之间
- 中间帧挑除第一个子镜头外**最重要的子镜头**的起始时刻；段落只有一个子镜头时两者都不写
- 承接段落（`continuity` 为 `continue`、`inherits_first` 为 `true`）：`first_frame_prompt` 必须留空；同时保证上一段落的 `last_frame_prompt` 是稳定、信息清晰、可直接当作本段开场的画面

## 绝对规则：图像优先

角色长相与服装完全由资产参考图（含造型版本图）决定，**文字描述一旦和参考图冲突，出图就会崩**。

- **禁止**描写角色的物种、种族、服装、颜色、发型、体型、年龄、五官
- 角色一律只用 `@角色名` 指代；**角色名只是代号**，不要从名字推断长相
- 场景、道具同理：用 `@场景名` / `@道具名` 引用，只补充「此刻状态」
- **允许**写：相对体型比例（「@鼠妈妈 身高约为 @猪爸爸 的三分之二」——比例不是长相）；穿戴类道具的佩戴状态（「鼻梁上架着 @墨镜」「@巴拿马帽 拿在左手」——这是道具引用）
- 可以写的：景别、机位角度、构图、人物位置、姿态、肢体动作、表情、视线、与道具的交互、光线氛围

## 四肢状态自检清单（每条提示词逐项核对）

对画面中**每一个**出场角色：

1. **双手**：各在哪里、做什么；持物写明「哪只手」；空着的手也要写（「左手自然垂在体侧」）
2. **双腿**：站/坐/蹲/盘的具体收纳方式与可见性——高风险姿态用正向完整枚举：「左腿盘在右腿上，双脚收于身下，画面中可见两只脚掌」；**不要**写「不要三条腿」这类负向指令（无效）
3. **遮挡**：不写被躯干完全遮挡的肢体动作；需要「手伸到身后」时改写为侧身可见的等效姿态
4. **接触**：两角色接触时双方肢体终态都写，接触点唯一（「@鼠妈妈 右爪按在 @猴宝宝 左膝上，@猴宝宝 双手撑椅面」）
5. **穿戴状态**：帽、眼镜、墨镜等每帧声明——戴着 / 拿在哪只手 / 不在画面
6. **非人体型**：短肢圆身角色不套用人类标准姿势，用该体型做得出的版本（双爪环抱于胸前，而不是「双臂垂于体侧持铃」）

## 镜面与屏幕规则

- 画面含穿衣镜/倒影时，同一帧只能以**镜中像**或**真身**之一为主体：拍镜中像则镜框完整入画、真身只露背影局部并写明；拍真身则镜面置于画面边缘或虚化
- 镜中内容逐项写明（谁、什么姿态、穿戴什么），且必须与真身一致
- 画面内的电视/屏幕只播节目画面（风景、新闻画面等），**禁止出现本片角色**
- 多角色 + 镜面是最高风险组合，能避则避：优先拆成「真身镜头」和「镜面反打镜头」两个子镜头

## 每条关键帧提示词必须自足

每张关键帧独立出图（只给资产参考图 + 这一条提示词）：

- 禁止「同上一帧」「保持不变」「延续前面的构图」
- 每条都要自己交代：`@场景名` + 景别/机位/构图 + 每个 `@角色名` 的位置、姿态、四肢状态、表情 + 关键 `@道具名` 及穿戴持握状态 + 取自 `atmosphere` 的光线氛围
- 写成一段连贯描述，不分点、不编号

## 写作结构（推荐顺序）

**@场景名 + 时间/光线 → 景别与机位角度 → 构图（谁在画面什么位置） → 主体 @角色名 的姿态·四肢状态·表情·视线 → 关键 @道具名 及交互/穿戴状态 → 氛围光线 → 收尾语**

结尾统一加上：16:9 横构图电影感剧照，单帧静态画面。

示例（首帧，含道具与四肢状态）：

```
@阳台，清晨，明亮暖色调晨光均匀铺满地面，16:9 横构图电影感剧照。中景平视固定机位，@基尼 站在画面中央的 @训练垫 上，双爪在胸前环抱住一只 @迷你哑铃，另一只 @迷你哑铃 平放在垫面右前方，双腿并拢站稳，两只后爪都踏在垫上清晰可见，神情专注，视线落在怀中的哑铃上。画面四周留出开阔的阳台地面，晨光柔和无重阴影。单帧静态画面，无运动模糊。
```

示例（尾帧，需要被下一段承接）：

```
@客厅，午后，浅暖色调自然光均匀铺满空间，16:9 横构图电影感剧照。中景平视固定机位，@猴宝宝 站在画面中央偏右的 @落地穿衣镜 前，身体正面朝向画外沙发方向，右手将 @墨镜 握在胸前，左手自然垂在体侧，双腿并拢站定、两只脚掌着地可见，小嘴微撅、视线望向画外。镜面只占画面右缘且映出他的局部背影。构图平稳，人物完整入画。单帧静态画面，无运动模糊。
```

## 尾帧的额外要求

下一段落可能把本段尾帧当作首帧，所以尾帧必须是**可被接着演下去的画面**：

- 人物完整入画、姿态稳定，不要「正在出画」「背身走远」「动作中途的运动模糊」
- 不要收在纯物件大特写上（除非下一段确实是 `cut`）
- 画面里要有下一段需要出场的角色，及其**手持/穿戴的道具**（状态与 `result` 一致）
- 与 `result` 描述一致

## 禁止事项

- 任何角色外观属性（物种/服装/颜色/发型/体型/五官/年龄）
- 相对描述（「同上」「不变」）、时间推进（「然后」「随后」）
- 运动描写（运镜、动作过程）——关键帧是静止一瞬
- 负向肢体指令（「不要三条腿」「不要画成两个人」）——用正向完整枚举代替
- 台词、旁白、字幕、画外音
- 引用列表之外的场景/角色/道具名
- 抽象心理描写、文学化比喻
- 语言与会话语言指令不符

## 保存

调用 `update_storyboard`（或分镜拆解时的 `save_storyboards`）写入关键帧字段。单独生成时 `update_storyboard` 只传 `storyboard_id` 与关键帧字段，不要回传其他字段，不要重新拆分整集。
