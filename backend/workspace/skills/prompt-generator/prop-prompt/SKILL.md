# 道具最终提示词（白底单品 · 标准产品摄影）

生成的是一张白底单品图（product shot）：**采用标准产品摄影视角**，画面中只有道具本身，孤立放置在纯白背景上，**不掺杂任何其他元素**——没有其他物品、没有人物、没有场景环境、没有手部持握。

三条硬性要求：
1. **物品各部分比例准确**——不要夸张、变形或风格化拉伸，道具的相对尺寸关系必须真实
2. **边缘完整**——道具整体完整入镜，四周留白，任何部分都不得被画面边缘裁切
3. **背景不承载任何叙事内容**——纯白背景只是衬底，不带场景感、不带情节暗示、不带装饰元素

## 输出结构（按此顺序组装单段连贯描述，语言跟随会话语言指令）

```
单品产品图，标准产品摄影视角，[道具名 + 材质/颜色/形状/大小 + 新旧程度与磨损细节]，
物品各部分比例准确，孤立放置在纯白背景上，居中完整入镜，边缘完整无裁切，
背景纯净不承载任何叙事内容，无其他物品、无人物、无场景，
柔和均匀的影棚光，轻淡阴影，高细节
```

## 生成规则

- 以道具 `name` 与 `description` 为核心：材质、颜色、形状、大小、新旧程度、磨损痕迹**逐项落地**；description 里的相对尺寸信息（如「铃身长度约为豚鼠前爪两倍」）转化为该图内可见的真实比例
- 标准产品摄影视角：微俯视 3/4 视角（同时看清顶面与侧面）；扁平道具（纸张、证件、照片、报纸）用正俯视平铺
- **成对道具**（description 写明「一对两只、完全同款」的）：两只并排同框、间距均匀、朝向一致、完全同款——这张图是「一对」的外观锚点，不要只画一只
- **穿戴类道具**（帽、眼镜、墨镜、头盔）：用 3/4 视角同时呈现正面与侧面结构（镜腿、帽檐内侧等佩戴相关结构要可见），方便角色佩戴镜头参考
- 单品居中完整呈现，四周留白，比例准确、边缘完整
- 柔和均匀的影棚光，阴影轻淡，高细节
- 只描写物品本身，不要提及剧情、角色或用途
- 输出使用会话语言指令指定的目标语言；**不要**「电影质感」类词汇（道具图是产品图不是剧照）

## 禁止事项

- 手部持握、人物、其他物品、场景环境入镜
- 包装、底座、展示架（除非它就是道具本体的一部分）
- 文字、水印、签名（道具本体上印刷的文字图案可以保留并描述）
- 环境反光、彩色光
- 夸张透视、变形、比例失真、边缘裁切

## 参考图引用（有参考图时必做）

`readCharacters`/`readScenes`/`readProps` 返回的 `reference_count` / `reference_images` 是该资产的参考图清单：**编号 = 列表序（资产编号，稳定身份）**，磁盘上已不存在的图会被排除，不在列表里。`description_citations` 是用户在描述字段里已引用的编号。

- **生图只发送最终提示词实际引用的那几张**（零引用则一张不发）。按需引用：用到哪张就写哪张，写法 `@参考图1`、`@参考图2`…（资产编号），每一处写清这张图提供什么；这是厂商无关写法，提交时由系统换成该模型认识的连续标签；
- **描述字段里用户已引用的参考图（`description_citations`）必须原样保留引用并写明贡献**，不得丢弃或改编号；
- 不用的参考图不必提及，也不得虚构未引用图的内容；只取参考图里的要素，不得整体照搬它的构图、画框、背景；
- `reference_count = 0`：提示词里不得出现任何参考图引用标记，也不得虚构参考图的形制与细节；
- 引用不存在的编号、或漏掉描述引用时，保存工具会拒绝并指出问题；**保存前先调用 `check_final_prompt_references` 自查**，按返回的 `will_send` / `description_citations_missing` 修正后再保存。

## 保存

调用 `savePropFinalPrompt`：prompt 参数不含风格词，**项目视觉风格由工具自动注入到最终提示词的最前方**。
