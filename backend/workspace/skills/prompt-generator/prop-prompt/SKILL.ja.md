# 小道具の最終プロンプト（白背景の単品・標準プロダクト撮影）

生成するのは白背景の単品画像（プロダクトショット）：**標準的なプロダクト撮影のアングルを用い**、画面には小道具そのものだけを置き、純白の背景に孤立させ、**他の要素を一切混ぜない**——他の物品なし、人物なし、シーン環境なし、手に持たせない。

3つの必須要件：
1. **物品の各部分の比率が正確**——誇張、変形、様式化した引き伸ばしをせず、小道具の相対的な寸法関係は現実どおりでなければならない
2. **エッジが完全**——小道具全体が完全に画面に入り、四方に余白を取り、どの部分も画面端で切れてはならない
3. **背景が物語的内容を一切担わない**——純白の背景は下地にすぎず、場所感も筋書きの示唆も装飾要素も持たない

## 出力構造（この順序でひと続きの文章に組み立てる。言語は会話言語の指示に従う）

```
単品プロダクト画像、標準プロダクト撮影アングル、[小道具名 ＋ 素材／色／形状／大きさ ＋ 新旧の度合いと摩耗のディテール]、
物品の各部分の比率が正確、純白の背景に孤立して置かれ、中央に完全に収まり、エッジは完全で切れがない、
背景は清潔で物語的内容を一切担わず、他の物品なし、人物なし、シーンなし、
柔らかく均一なスタジオ照明、淡い影、高精細
```

## 生成規則

- 小道具の `name` と `description` を核とする：素材、色、形状、大きさ、新旧の度合い、摩耗の痕跡を**1項目ずつ具現化**する。description 内の相対寸法情報（例「ベル本体の長さはモルモットの前足のおよそ2倍」）は、この画像内で見える実際の比率に変換する
- 標準プロダクト撮影アングル：やや見下ろす3/4アングル（上面と側面を同時に把握できる）。平たい小道具（紙、証明書、写真、新聞）は真上からの平置き
- **対になった小道具**（description に「一対2つ、完全に同型」と明記されたもの）：2つを同じ画面に並べ、間隔を均等に、向きを揃え、完全に同型にする——この画像が「一対」の外観アンカーなので、1つだけ描かない
- **着用系小道具**（帽子、眼鏡、サングラス、ヘルメット）：3/4アングルで正面と側面の構造を同時に見せる（テンプル、帽子のつばの内側など着用に関わる構造を可視にする）。キャラクターの着用カットの参照になるようにする
- 単品を中央に完全に提示し、四方に余白を取り、比率は正確、エッジは完全
- 柔らかく均一なスタジオ照明、淡い影、高精細
- 物品そのものだけを描写し、筋書き・キャラクター・用途に触れない
- 会話言語の指示で指定された目標言語で出力する。**「映画的質感」の類の語彙は使わない**（小道具画像はプロダクト画像であり劇中スチルではない）

## 参照画像の予算（ハード制約）

- 小道具画像は絵コンテの参照画像の供給源である：1カットあたり参照画像は最大9枚、動画生成時は先頭キーフレームが先に1枚を占めるため、シーン 1 ＋ キャラクター N ＋ 小道具 M ≤ 8
- 予算超過時は絵コンテ層が優先度で取捨する：シーン ＞ 登場キャラクター ＞ 使用される／寄りで映る小道具 ＞ 見えているだけの小道具。外された小道具は紐付けと @ 参照を同時に失う
- 取捨は絵コンテ層で行われる。本技能では小道具の数を圧縮しない。備えて使わない方が、使いたいのに備えがないよりよい

## 禁止事項

- 手で持つ、人物、他の物品、シーン環境の写り込み
- パッケージ、台座、ディスプレイスタンド（それ自体が小道具の一部である場合を除く）
- 文字、ウォーターマーク、署名（小道具本体に印刷された文字や図案は残して描写してよい）
- 環境の映り込み、色付きの光
- 誇張した遠近、変形、比率の歪み、エッジの切れ

## 保存

`save_prop_final_prompt` を呼び出す：prompt 引数にスタイル語は含めない。**プロジェクトのビジュアルスタイルはツールが最終プロンプトの先頭に自動で注入する**。
