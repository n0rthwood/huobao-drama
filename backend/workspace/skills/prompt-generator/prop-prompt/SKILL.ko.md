# 소품 최종 프롬프트(흰 배경 단품 · 표준 제품 촬영)

생성되는 것은 흰 배경의 단품 이미지(product shot)입니다: **표준 제품 촬영 시점을 사용**하고, 화면에는 소품 자체만 두며, 순백 배경에 고립시키고 **다른 어떤 요소도 섞지 않습니다** — 다른 물건 없음, 인물 없음, 장면 환경 없음, 손으로 쥐지 않음.

세 가지 필수 요구:
1. **물건 각 부분의 비율이 정확할 것** — 과장·변형·양식화된 늘이기 금지, 소품의 상대적 크기 관계는 실제와 같아야 합니다
2. **가장자리가 온전할 것** — 소품 전체가 온전히 화면에 들어오고 사방에 여백을 두며, 어떤 부분도 화면 가장자리에 잘려서는 안 됩니다
3. **배경이 어떤 서사적 내용도 담지 않을 것** — 순백 배경은 받침일 뿐, 장소감도 줄거리 암시도 장식 요소도 없습니다

## 출력 구조(이 순서로 한 단락의 연속 묘사를 조립, 언어는 대화 언어 지시를 따름)

```
단품 제품 이미지, 표준 제품 촬영 시점, [소품명 + 재질/색상/형태/크기 + 신구 정도와 마모 디테일],
물건 각 부분의 비율이 정확, 순백 배경에 고립되어 놓임, 중앙에 온전히 들어옴, 가장자리 온전하고 잘림 없음,
배경은 깨끗하고 어떤 서사적 내용도 담지 않음, 다른 물건 없음, 인물 없음, 장면 없음,
부드럽고 균일한 스튜디오 조명, 옅은 그림자, 높은 디테일
```

## 생성 규칙

- 소품의 `name` 과 `description` 을 핵심으로 삼아 재질, 색상, 형태, 크기, 신구 정도, 마모 흔적을 **항목별로 구현**합니다. description 안의 상대 크기 정보(예: "종 몸체 길이는 기니피그 앞발의 약 2배")는 이 이미지 안에서 보이는 실제 비율로 변환합니다
- 표준 제품 촬영 시점: 약간 내려다보는 3/4 시점(윗면과 옆면을 동시에 파악). 납작한 소품(종이, 증명서, 사진, 신문)은 정수직 부감으로 평평히 눕힙니다
- **한 쌍 소품**(description 에 "한 쌍 두 개, 완전히 동일" 이라고 명시된 것): 두 개를 나란히 같은 화면에 두고 간격을 균등하게, 방향을 일치시키고 완전히 동일하게 — 이 이미지가 "한 쌍"의 외형 앵커이므로 하나만 그리지 마세요
- **착용형 소품**(모자, 안경, 선글라스, 헬멧): 3/4 시점으로 정면과 측면 구조를 동시에 보여 줍니다(안경다리, 모자 챙 안쪽 등 착용 관련 구조가 보여야 함). 캐릭터 착용 컷의 참조가 되도록 합니다
- 단품을 중앙에 온전히 제시하고 사방에 여백을 두며, 비율은 정확하고 가장자리는 온전합니다
- 부드럽고 균일한 스튜디오 조명, 옅은 그림자, 높은 디테일
- 물건 자체만 묘사하고 줄거리·캐릭터·용도를 언급하지 마세요
- 대화 언어 지시가 지정한 목표 언어로 출력합니다. **"영화적 질감" 류의 어휘는 쓰지 마세요**(소품 이미지는 제품 이미지이지 스틸컷이 아닙니다)

## 참조 이미지 예산(강제 제약)

- 소품 이미지는 스토리보드 참조 이미지의 공급원입니다: 컷당 참조 이미지는 최대 9장, 비디오 생성 시 첫 키프레임이 먼저 1장을 차지하므로 장면 1 + 캐릭터 N + 소품 M ≤ 8
- 예산을 넘으면 스토리보드 층에서 우선순위로 버립니다: 장면 > 등장 캐릭터 > 사용되거나 클로즈업되는 소품 > 보이기만 하는 소품. 밀려난 소품은 바인딩과 @ 참조를 함께 잃습니다
- 취사선택은 스토리보드 층에서 일어나며 이 스킬에서는 소품 수를 줄이지 않습니다. 갖춰 두고 안 쓰는 편이 쓰려는데 없는 것보다 낫습니다

## 금지 사항

- 손으로 쥐기, 인물, 다른 물건, 장면 환경이 화면에 들어오는 것
- 포장, 받침대, 진열대(그것이 소품 본체의 일부인 경우 제외)
- 문자, 워터마크, 서명(소품 본체에 인쇄된 문자·도안은 유지하고 묘사해도 됨)
- 환경 반사, 색이 있는 조명
- 과장된 원근, 변형, 비율 왜곡, 가장자리 잘림

## 저장

`save_prop_final_prompt` 를 호출합니다: prompt 인자에는 스타일 단어를 넣지 않습니다. **프로젝트 비주얼 스타일은 도구가 최종 프롬프트 맨 앞에 자동으로 주입합니다.**
