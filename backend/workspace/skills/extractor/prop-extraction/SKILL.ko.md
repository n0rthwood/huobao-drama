# 소품 추출 세칙

## 왜 소품을 추출하는가

소품 자산이 없으면 스토리보드 프롬프트가 물건을 언급할 때 순수 텍스트로밖에 쓸 수 없고, 물건의 모습은 매 프레임 새로 만들어진다(한 컷에 덤벨 디자인이 세 가지, 신문 지면이 매 프레임 바뀌는 사고는 실제로 일어났다). 소품 이미지는 물건이 컷을 넘어 일관되게 유지되는 유일한 앵커다.

## 판정 기준(하나라도 해당하면 추출)

1. **대본이 그 생김새를 명확히 묘사했다**(외관에 반 문장 이상을 썼다)
2. **캐릭터가 그것을 들거나, 쓰거나, 착용하거나, 쓰고 벗는다**(손에 듦, 사용, 착용, 전달)
3. **캐릭터가 그 위에 올라서거나, 앉거나, 그것에 비춰 본다**(요가 매트, 트레이닝 매트, 전신 거울 같은 상호작용 가능한 대형 배치물)
4. **두 컷 이상에 등장하거나 클로즈업된다**
5. 아래 "필수 추출 범주"에 속한다

**수량 상한은 없다.** 추출 층은 "이 물건에 고정된 외관이 필요한가"만 본다. 각 컷에서 참조 이미지를 몇 장 쓸지는 스토리보드 층이 9장 예산으로 취사선택한다. 준비해 두고 안 쓰는 편이 낫지, 필요할 때 없으면 안 된다.

## 필수 추출 범주(명시적 열거)

| 범주 | 예시 | 요구사항 |
|---|---|---|
| 운동 기구 | 덤벨, 요가 매트, 트레이닝 매트, 스키 헬멧, 썰매, 스노보드, 스키 폴 | 대본에 등장하면 추출한다. 쌍을 이루는 것(덤벨 두 개)은 하나의 소품으로 세며 "미니 덤벨(한 쌍)" 같은 이름은 불가 — "미니 덤벨"로 하고 description 에 "한 쌍 두 개, 완전히 동일한 디자인"이라고 명시한다 |
| 착용 액세서리 | 안경, 선글라스, 모자(파나마 모자 등), 헬멧, 목도리, 손목시계 | 따로 쓰고 벗을 수 있는 것은 모두 소품이다(캐릭터가 내내 쓰고 있어도 마찬가지). **한 벌 의상은 소품이 아니다** — 설상복, 휴양복 세트 등 전신 의상은 캐릭터의 "스타일링 버전"으로 처리하며, extractor 스킬을 참조한다 |
| 일상 물건 | 컵, 찻잔, 책, 노트, 연필, 숙제장, 신문, 리모컨, 휴대폰 | 캐릭터가 사용하거나 화면에서 뚜렷이 보이면 추출한다. "일상 용품은 추출하지 않는다"는 면제는 존재하지 않는다 |
| 상호작용 가능한 대형 배치물 | 전신 거울, 요가 매트, 트레이닝 매트, 아동용 의자 | 캐릭터가 올라서거나/앉거나/비춰 보는 대형 물건은 장면에서 꺼내 소품으로 만든다. 순수 배경 가구(고정된 책상과 의자, 조명, 문과 창, 걸린 그림)는 여전히 장면에 속한다 |

## 추출하지 않는 경우

- 순수 배경 배치물: 아무도 건드리지 않고, 묘사되지 않으며, 클로즈업되지 않는 고정 가구와 장식(장면 prompt 에 속한다)
- 한 번 언급되고 화면에 보이지 않는 물건(대사에서만 거론되는 것)

## 명명 규범

- 2~6자, 대본의 표현과 일치시킨다(대본이 "파나마 모자"라고 쓰면 "파나마 모자"라고 하고 "밀짚모자"로 바꾸지 않는다)
- 괄호, 별칭, 화수를 붙이지 않는다. 화를 넘어 같은 물건은 같은 이름으로 기존 소품을 재사용한다
- 이름은 스토리보드에서 `@소품명` 으로 정확히 매칭되므로(최장 일치 우선) 안정적이고 모호하지 않아야 한다

## description 작성법(확정성 요구)

물건 자체의 물리적 외관만 항목별로 구체적으로 쓴다: **재질, 색상, 형태, 크기(캐릭터의 손바닥/몸에 대한 상대 크기), 새것·낡은 정도, 마모 흔적**.

- "또는", "아마", "대략" 금지: 색상과 디자인은 한 번에 못 박는다
- 줄거리상의 용도와 소유 관계 금지("지니의 덤벨", "운동용" 모두 쓰지 않는다)
- 상대 크기는 중요하다: "봉의 길이는 기니피그 앞발의 약 두 배" 같은 실행 가능한 비율을 써서 클로즈업 시 소품이 과도하게 커지는 것을 막는다
- 쌍을 이루는 물건은 "한 쌍 두 개, 완전히 동일한 디자인"이라고 명시한다

소품은 **이미지 프롬프트를 출력할 필요가 없다** — 최종 흰 배경 단품 프롬프트는 프롬프트 생성 Agent 가 prop-prompt 스킬에 따라 전담 생성한다.

## 저장

`save_dedup_props` 를 호출해 저장하고 현재 화에 자동 연결한다. 정말 소품이 없으면 빈 배열을 전달하고 억지로 채우지 않는다.
