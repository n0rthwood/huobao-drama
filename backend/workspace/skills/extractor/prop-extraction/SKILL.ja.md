# 小道具抽出の細則

## なぜ小道具を抽出するのか

小道具アセットがないと、絵コンテのプロンプトが物体に言及してもプレーンテキストで書くしかなく、物体の見た目はフレームごとに作り直される（1カットにダンベルのデザインが3種類、新聞のレイアウトが毎フレーム変わる、いずれも実際に起きた事故である）。小道具画像は物体がカットをまたいで一貫するための唯一のアンカーだ。

## 判定基準（いずれか1つに該当すれば抽出）

1. **脚本がその見た目を明確に描写している**（外観に半文以上を割いている）
2. **キャラクターがそれを持つ、使う、身につける、着脱する**（手持ち、使用、着用、受け渡し）
3. **キャラクターがその上に立つ、座る、それに映る**（ヨガマット、トレーニングマット、姿見などインタラクト可能な大型の設え）
4. **2カット以上にわたって登場する、またはアップで映る**
5. 下記の「必須抽出カテゴリ」に属する

**数量の上限はない。** 抽出層は「この物体に固定の外観が必要か」だけを見る。各カットで参照画像を何枚使うかは絵コンテ層が9枚の予算で取捨する。使わなくても備えておくほうがよく、必要なのに無いのは避ける。

## 必須抽出カテゴリ（明示的な列挙）

| カテゴリ | 例 | 要件 |
|---|---|---|
| スポーツ用具 | ダンベル、ヨガマット、トレーニングマット、スキーヘルメット、ソリ、スノーボード、ストック | 脚本に登場すれば抽出する。対になったもの（ダンベル2個）は1つの小道具として数え、「ミニダンベル（一対）」のような命名は不可——「ミニダンベル」とし、description に「一対2個、完全に同一デザイン」と明記する |
| 装着小物 | 眼鏡、サングラス、帽子（パナマ帽など）、ヘルメット、マフラー、腕時計 | 単独で着脱できるものはすべて小道具（キャラクターが終始つけていても同様）。**一揃いの衣装は小道具ではない**——スノーウェア、バカンス一式など全身の衣装はキャラクターの「造形バージョン」で扱う。extractor スキルを参照 |
| 日用品 | カップ、湯のみ、本、ノート、鉛筆、宿題帳、新聞、リモコン、スマートフォン | キャラクターが使う、または画面上で明らかに見えるなら抽出する。「日用品は抽出しない」という免除は存在しない |
| インタラクト可能な大型の設え | 姿見、ヨガマット、トレーニングマット、子供用チェア | キャラクターが上に立つ／座る／映る大型品はシーンから取り出して小道具にする。純粋な背景家具（固定の机や椅子、照明、ドアや窓、掛け絵）は引き続きシーンに属する |

## 抽出しない場合

- 純粋な背景の設え：誰も触れず、描写もされず、アップにもならない固定の家具や装飾（それらはシーンの prompt に属する）
- 一度だけ言及され画面に見えない物体（セリフの中でのみ語られるもの）

## 命名規範

- 2〜6文字、脚本の用語と一致させる（脚本が「パナマ帽」と書けば「パナマ帽」とし、「麦わら帽子」に言い換えない）
- 括弧なし、エイリアスなし、話数なし。話をまたいで同一の物は同じ名前で既存の小道具を再利用する
- 名前は絵コンテで `@小道具名` として厳密に照合される（最長一致優先）ため、安定していて曖昧でないこと

## description の書き方（確定性の要求）

物品そのものの物理的外観のみを、項目ごとに具体的に書く：**素材、色、形、大きさ（キャラクターの手のひら／身体に対する相対サイズ）、新旧の程度、摩耗の痕跡**。

- 「または」「かもしれない」「およそ」は禁止：色とデザインは一度で書き切る
- 物語上の用途や所有関係は禁止（「ジーニーのダンベル」「フィットネス用」などは書かない）
- 相対サイズは重要：「バーの長さはモルモットの前足の約2倍」のような実行可能な比率を書き、アップで小道具が膨張するのを防ぐ
- 対になった物は「一対2個、完全に同一デザイン」と明記する

小道具に**画像プロンプトは不要**——最終的な白背景の単品プロンプトは、プロンプト生成 Agent が prop-prompt スキルに従って専用に生成する。

## 保存

`save_dedup_props` を呼んで保存し、当該話に自動で関連付ける。本当に小道具がない場合は空配列を渡し、無理に埋めない。
