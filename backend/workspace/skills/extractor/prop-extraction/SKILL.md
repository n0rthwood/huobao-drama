# 道具提取细则

## 为什么要提道具

没有道具资产，分镜提示词提到物件时只能写纯文本，物件的样子每一帧都会被重新发明（哑铃一镜三个设计、报纸每帧换版式都是实际发生过的事故）。道具图是物件跨镜头一致的唯一锚点。

## 判定标准（任一命中即提取）

1. **剧本明确描写了它的样子**（花了半句以上写外观）
2. **角色会拿它、用它、戴它、穿脱它**（手持、使用、佩戴、交接）
3. **角色会站上去、坐上去、照它**（瑜伽垫、训练垫、落地穿衣镜这类可交互大件陈设）
4. **跨两个以上镜头出现，或会被特写**
5. 属于下方「必提类别」

**没有数量上限。**提取层只管「这个物件需不需要固定外观」；每个镜头用多少参考图，由分镜层按 9 张预算取舍。宁可备而不用，不可用而无备。

## 必提类别（显式枚举）

| 类别 | 例子 | 要求 |
|---|---|---|
| 运动器材 | 哑铃、瑜伽垫、训练垫、滑雪头盔、雪橇、雪板、滑雪杖 | 剧本出现即提取；成对的（两只哑铃）算一个道具，命名如「迷你哑铃（一对）」不可取——用「迷你哑铃」并在 description 写明「一对两只、完全同款」 |
| 穿戴配件 | 眼镜、墨镜、帽子（巴拿马帽等）、头盔、围巾、手表 | 可单独穿脱的都算道具（即使角色全程戴着）；**成套服装不算道具**——雪服、度假套装等整身衣着走角色「造型版本」，见 extractor 技能 |
| 日常物件 | 杯子、茶杯、书本、笔记本、铅笔、作业本、报纸、遥控器、手机 | 只要被角色使用或画面明显可见就提取，不存在「日常物品不提」的豁免 |
| 可交互大件陈设 | 落地穿衣镜、瑜伽垫、训练垫、儿童座椅 | 会被角色站上去/坐上去/照的大件从场景中拿出来做道具；纯背景家具（固定桌椅、灯具、门窗、挂画）仍属场景 |

## 不提取的情况

- 纯背景陈设：没人碰、没被描写、不被特写的固定家具与装饰（它们属于场景 prompt）
- 一次性提及且画面不可见的物件（只在台词里说起的东西）

## 命名规范

- 2-6 个字，与剧本用词一致（剧本写「巴拿马帽」就叫「巴拿马帽」，不要改叫「草帽」）
- 不带括号、不带别名、不带集数；跨集同物同名复用已有道具
- 名字会被分镜用 `@道具名` 精确匹配（最长优先），因此必须稳定、无歧义

## description 写法（确定性要求）

只写物品本身的物理外观，逐项落地：**材质、颜色、形状、大小（与角色手掌/身体的相对尺寸）、新旧程度、磨损痕迹**。

- 禁止「或」「可能」「大约」：颜色款式一次写死
- 禁止剧情用途与归属（「基尼的哑铃」「用来健身」都不要）
- 相对尺寸很重要：写「铃身长度约等于豚鼠前爪的两倍」这类可执行的比例，防止特写时道具暴涨
- 成对物件写明「一对两只、完全同款」

道具**不需要输出图片提示词**——最终白底单品图提示词由提示词生成 Agent 按 prop-prompt 技能专门生成。

## 保存

调用 `save_dedup_props` 保存并自动关联当前集；确无道具时传空数组，不要硬凑。
