# 角色、场景与道具提取指南

## 总原则：一切为视觉连续性服务

提取出的每一条资产都会变成生图参考，供分镜用 @ 引用。判断「要不要提、怎么写」时只问一件事：**这个信息能不能帮助画面在不同镜头之间保持一致**。描述必须确定无歧义——禁止「或」「可能」「大约」「浅粉色或米色系」这类把选择权交给模型的写法，一次写死。

## 角色提取规范

提取的角色字段（与 `save_dedup_characters` 工具参数一一对应）：
- **name**（必填）：角色全名
- **role**：角色定位，主角/配角/龙套
- **appearance**：样貌描写（200-400字）——性别、年龄感、五官、体态、**相对体型**（如「身高约为猪爸爸的三分之二」，多角色同框时这是防止比例漂移的关键信息）。只写**静态可见特征**；性格转化为一句常驻气质（如「眼神冷峻、少有笑意」），不要写行为过程（「训练时屏息凝神」这类时序性描写对单帧出图是噪声）
- **styling**：**基础妆造**——角色的常规发型、常规服装、常规配饰。基础形象一经确立不再改写（工具会保留已有非空字段）；它必须与角色资产图一致，发现文本与图冲突时在结束语中向用户报告，不要自行改字段迁就
- **styling_version**：**单集造型版本**（可选）——剧本给该角色一身成套新衣着（度假装、雪服、礼服等）时填写：`name`（2-6字版本名，如「夏威夷度假装」）+ `description`（整套衣着的确定性描述：每件单品的款式、颜色、图案）。成套衣着永远走造型版本，**绝不**写进 styling；帽子、眼镜、墨镜、头盔等可单独穿脱的配件不属于造型版本，按道具提取
- **description**：背景故事和人物关系（可选补充）

## 场景提取规范

提取的场景字段（与 `save_dedup_scenes` 工具参数一一对应）：
- **location**（必填）：具体场所名称。**一个物理空间 = 一个场景**：「客厅书桌前」「客厅沙发前」都是客厅里的机位，不是独立场景，一律用「客厅」；子区域的取景交给分镜的景别机位语言
- **time**：时间段（白天/黄昏/深夜等），同地点不同时段才视为新场景
- **prompt**：场景描述——空间、固定陈设及其**相对位置**（纯背景，不含人物）。剧情会用到的固定大件（电视、书桌、沙发、窗）必须写明位置关系；**可移动、会被角色拿起或使用的物件（杯子、书本、报纸、哑铃、垫子）一律不要写进场景**——它们属于道具，烤进场景图就无法单独控制
- **lighting**：场景光影——光源、色调、明暗、氛围

## 道具提取规范

详细判定标准、类别枚举与描述写法见 **prop-extraction** 技能，必须遵循。要点：
- 凡剧本明确描写、被角色手持/使用/佩戴、跨镜头出现、或会被站上去/照的物件都要提取，**没有数量上限**——每镜用多少由分镜层按 9 张参考图预算取舍，不在提取层压缩
- 成对物件（两只哑铃）算一个道具；成套服装不是道具（走角色造型版本）

## 使用步骤

1. 调用 `read_script_for_extraction` 读取当前集剧本
2. 调用 `read_existing_characters` / `read_existing_scenes` / `read_existing_props` 查看项目已有资产与当前集关联
3. 只提取当前集真实涉及的角色、场景和道具
4. 调用 `save_dedup_characters` / `save_dedup_scenes` / `save_dedup_props` 保存并自动关联当前集

## 当前集规则

- 目标是补齐「当前集」需要的资产，不是重扫整个项目
- 已在项目中存在但当前集未关联的，复用并关联到当前集
- 去重：角色/道具按名称精确匹配；场景按【地点+时间段】匹配，地点名互为包含时优先视为同一空间复用
- 近名去重：名称带括号定位或别名时按括号前主体比较；read_existing_* 返回的 normalized_name / normalized_location 即归一化结果，据此判断
