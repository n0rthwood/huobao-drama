# キャラクター・シーン・小道具の抽出ガイド

## 総原則：すべては視覚的連続性のために

抽出したアセットはすべて画像生成の参照となり、絵コンテから @ で引用される。「抽出すべきか、どう書くか」を判断するときは一点だけを問う：**この情報は異なるカット間で画面を一貫させるのに役立つか**。記述は確定的で曖昧さがないこと——「または」「かもしれない」「およそ」「淡いピンクまたはベージュ系」のようにモデルに選択を委ねる書き方は禁止。一度で書き切る。

## キャラクター抽出仕様

抽出するキャラクターフィールド（`save_dedup_characters` ツールのパラメータと一対一で対応）：
- **name**（必須）：キャラクターのフルネーム
- **role**：キャラクターの位置づけ。主役／脇役／端役
- **appearance**：容姿の描写（200〜400字）——性別、年齢感、顔立ち、体つき、**相対的な体格**（例「身長は豚パパの約三分の二」。複数キャラが同じ画面に入るとき、これが比率のズレを防ぐ鍵となる情報）。**静的で視認できる特徴**のみを書く。性格は常時の雰囲気一文に変換する（例「眼差しは冷たく、めったに笑わない」）。行動の過程は書かない（「トレーニング中は息を詰めて集中する」のような時系列的描写は単一フレーム生成にとってノイズ）
- **styling**：**基本の造形**——キャラクターの通常の髪型、通常の衣装、通常のアクセサリー。基本イメージは一度確立したら書き換えない（ツールは既存の非空フィールドを保持する）。キャラクターのアセット画像と一致していなければならず、テキストと画像の食い違いを見つけた場合は締めの文でユーザーに報告すること。画像に合わせて自分でフィールドを書き換えてはならない
- **styling_version**：**単話の造形バージョン**（任意）——脚本がそのキャラクターに一揃いの新しい衣装（バカンス服、スノーウェア、礼服など）を与える場合に記入する：`name`（2〜6文字のバージョン名、例「ハワイアンバカンス服」）＋ `description`（衣装一式の確定的な記述：各アイテムの型、色、柄）。一揃いの衣装は必ず造形バージョンとして扱い、**決して** styling に書かない。帽子、眼鏡、サングラス、ヘルメットなど単独で着脱できる小物は造形バージョンではなく、小道具として抽出する
- **description**：背景のストーリーと人物関係（任意の補足）

## シーン抽出仕様

抽出するシーンフィールド（`save_dedup_scenes` ツールのパラメータと一対一で対応）：
- **location**（必須）：具体的な場所の名称。**一つの物理空間 = 一つのシーン**：「リビングの机の前」「リビングのソファの前」はいずれもリビング内のカメラ位置であって独立したシーンではない。一律に「リビング」とする。サブエリアの切り取りは絵コンテのサイズ・カメラ位置の言語に委ねる
- **time**：時間帯（昼／夕暮れ／深夜など）。同じ場所でも時間帯が異なる場合のみ新しいシーンとみなす
- **prompt**：シーンの記述——空間、固定の設えとその**相対的な位置関係**（純粋な背景で、人物は含まない）。物語で使われる固定の大型品（テレビ、机、ソファ、窓）は位置関係を明記すること。**移動可能で、キャラクターが手に取ったり使ったりする物（カップ、本、新聞、ダンベル、マット）は一切シーンに書かない**——それらは小道具であり、シーン画像に焼き込むと単独で制御できなくなる
- **lighting**：シーンの光と影——光源、色調、明暗、雰囲気

## 小道具抽出仕様

詳細な判定基準、カテゴリの列挙、記述の書き方は **prop-extraction** スキルを参照し、必ず遵守すること。要点：
- 脚本が明確に描写している物、キャラクターが手に持つ／使う／身につける物、カットをまたいで登場する物、上に乗ったり映したりする物はすべて抽出する。**数量の上限はない**——各カットで何点使うかは絵コンテ層が参照画像9枚の予算に従って取捨する。抽出層で圧縮しない
- 対になった物（ダンベル2個）は1つの小道具として数える。一揃いの衣装は小道具ではない（キャラクターの造形バージョンで扱う）

## 使用手順

1. `read_script_for_extraction` を呼び、当該話の脚本を読む
2. `read_existing_characters` / `read_existing_scenes` / `read_existing_props` を呼び、プロジェクトの既存アセットと当該話との関連を確認する
3. 当該話に実際に関わるキャラクター、シーン、小道具のみを抽出する
4. `save_dedup_characters` / `save_dedup_scenes` / `save_dedup_props` を呼んで保存し、当該話に自動で関連付ける

## 当該話のルール

- 目的は「当該話」に必要なアセットを揃えることであり、プロジェクト全体を再スキャンすることではない
- プロジェクトに既に存在するが当該話に関連付いていないものは、再利用して当該話に関連付ける
- 重複排除：キャラクター／小道具は名称の完全一致。シーンは【場所＋時間帯】で照合し、場所名が互いを包含する場合は同一空間とみなして再利用することを優先する
- 類似名の重複排除：名称に括弧付きの限定やエイリアスが付く場合は括弧の前の主体で比較する。`read_existing_*` が返す normalized_name / normalized_location が正規化結果なので、それに基づいて判断する
