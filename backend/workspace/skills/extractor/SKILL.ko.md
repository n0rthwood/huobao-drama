# 캐릭터·장면·소품 추출 가이드

## 총원칙: 모든 것은 시각적 연속성을 위한 것

추출한 모든 자산은 이미지 생성 참조가 되어 스토리보드에서 @ 로 인용된다. "추출할지, 어떻게 쓸지"를 판단할 때는 단 하나만 묻는다: **이 정보가 서로 다른 컷 사이에서 화면을 일관되게 유지하는 데 도움이 되는가**. 설명은 확정적이고 모호함이 없어야 한다 — "또는", "아마", "대략", "연분홍 또는 베이지 계열"처럼 선택권을 모델에 넘기는 서술은 금지하며, 한 번에 못 박아 쓴다.

## 캐릭터 추출 규범

추출하는 캐릭터 필드(`save_dedup_characters` 도구 파라미터와 일대일 대응):
- **name**(필수): 캐릭터 전체 이름
- **role**: 캐릭터 위치, 주인공/조연/단역
- **appearance**: 외모 묘사(200~400자) — 성별, 연령감, 이목구비, 체형, **상대적 체격**(예: "키가 돼지 아빠의 약 3분의 2"). 여러 캐릭터가 한 화면에 들어올 때 비율이 어긋나는 것을 막는 핵심 정보다. **정적이고 눈에 보이는 특징**만 쓴다. 성격은 상시적인 분위기 한 문장으로 바꿔 쓰고(예: "눈빛이 차갑고 좀처럼 웃지 않음"), 행동 과정은 쓰지 않는다("훈련할 때 숨을 죽이고 집중한다" 같은 시간적 묘사는 단일 프레임 생성에는 잡음이다)
- **styling**: **기본 스타일링** — 캐릭터의 평상시 헤어스타일, 평상시 의상, 평상시 액세서리. 기본 이미지는 한 번 확립되면 다시 고쳐 쓰지 않는다(도구가 비어 있지 않은 기존 필드를 보존한다). 캐릭터 자산 이미지와 일치해야 하며, 텍스트와 이미지가 충돌하는 것을 발견하면 마무리 멘트에서 사용자에게 보고한다. 임의로 필드를 고쳐 이미지에 맞추지 말 것
- **styling_version**: **단일 화 스타일링 버전**(선택) — 대본이 해당 캐릭터에게 한 벌의 새 의상(휴양복, 설상복, 예복 등)을 부여할 때 기입한다: `name`(2~6자 버전 이름, 예: "하와이 휴양복") + `description`(한 벌 전체 의상의 확정적 설명: 각 품목의 형태, 색상, 무늬). 한 벌 의상은 언제나 스타일링 버전으로 처리하며 **절대** styling 에 쓰지 않는다. 모자, 안경, 선글라스, 헬멧 등 따로 쓰고 벗을 수 있는 액세서리는 스타일링 버전이 아니라 소품으로 추출한다
- **description**: 배경 이야기와 인물 관계(선택 보충)

## 장면 추출 규범

추출하는 장면 필드(`save_dedup_scenes` 도구 파라미터와 일대일 대응):
- **location**(필수): 구체적인 장소 이름. **하나의 물리적 공간 = 하나의 장면**: "거실 책상 앞", "거실 소파 앞"은 모두 거실 안의 카메라 위치일 뿐 독립된 장면이 아니므로 일괄적으로 "거실"을 쓴다. 하위 구역의 화면 잡기는 스토리보드의 화면 크기·카메라 위치 언어에 맡긴다
- **time**(필수): 구체적인 시간대 — 이른 아침 / 오전 / 정오 / 오후 / 황혼 / 저녁 / 심야, 또는 대본에 명시된 시간대. 대본에 없으면 줄거리로 추론하고 **절대 비워 두지 않는다**. 시간대는 time 에만 쓰며 lighting 에 써서 대신해서는 안 된다. 같은 장소라도 시간대가 다를 때만 새로운 장면으로 본다
- **prompt**: 장면 설명 — 공간, 고정 배치물과 그 **상대적 위치**(순수 배경, 인물 불포함). 스토리에서 쓰이는 고정 대형 품목(TV, 책상, 소파, 창)은 위치 관계를 반드시 명시한다. **이동 가능하고 캐릭터가 집어 들거나 사용하는 물건(컵, 책, 신문, 덤벨, 매트)은 절대 장면에 쓰지 않는다** — 그것들은 소품이며, 장면 이미지에 구워 넣으면 따로 제어할 수 없게 된다
- **lighting**: 장면의 빛과 그림자 — 광원, 색조, 명암, 분위기. time 과 일치해야 한다("오후"면 오후의 빛이며 밤 조명으로 쓰지 않는다)

## 소품 추출 규범

상세한 판정 기준, 범주 열거, 설명 작성법은 **prop-extraction** 스킬을 보고 반드시 따른다. 요점:
- 대본이 명확히 묘사했거나, 캐릭터가 손에 들거나/사용하거나/착용하거나, 컷을 넘어 등장하거나, 위에 올라서거나 비추게 되는 물건은 모두 추출한다. **수량 상한은 없다** — 컷마다 몇 개를 쓸지는 스토리보드 층이 참조 이미지 9장 예산에 따라 취사선택하며, 추출 층에서 압축하지 않는다
- 쌍을 이루는 물건(덤벨 두 개)은 하나의 소품으로 센다. 한 벌 의상은 소품이 아니다(캐릭터 스타일링 버전으로 처리)

## 사용 단계

1. `read_script_for_extraction` 를 호출해 현재 화의 대본을 읽는다
2. `read_existing_characters` / `read_existing_scenes` / `read_existing_props` 를 호출해 프로젝트의 기존 자산과 현재 화의 연결을 확인한다
3. 현재 화가 실제로 다루는 캐릭터, 장면, 소품만 추출한다
4. `save_dedup_characters` / `save_dedup_scenes` / `save_dedup_props` 를 호출해 저장하고 현재 화에 자동 연결한다

## 현재 화 규칙

- 목표는 "현재 화"에 필요한 자산을 보완하는 것이지 프로젝트 전체를 다시 훑는 것이 아니다
- 프로젝트에는 이미 있으나 현재 화에 연결되지 않은 것은 재사용해 현재 화에 연결한다
- 중복 제거: 캐릭터/소품은 이름 정확 일치, 장면은 [장소 + 시간대]로 매칭하며 장소 이름이 서로를 포함하면 같은 공간으로 보고 재사용하는 것을 우선한다
- 유사 이름 중복 제거: 이름에 괄호 한정이나 별칭이 붙으면 괄호 앞 본체로 비교한다. `read_existing_*` 가 반환하는 normalized_name / normalized_location 이 정규화 결과이므로 이를 근거로 판단한다
