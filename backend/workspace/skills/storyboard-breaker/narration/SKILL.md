# 分镜侧配合旁白（仅在本集开启旁白时注入）

本集开启了**旁白**：每一镜会有一段独立的解说词，由专门的旁白写作 Agent 写进独立字段，再合成为音轨并烧录成字幕。**旁白文本不由你产出**，你只负责让分镜能装得下旁白。

## 1. 旁白不写进任何你保存的字段（硬约束）

- `description` 里**不要**再写「旁白：…」。旁白有独立字段，双写会导致同一句话既被念出来又出现在画面台词里。
- `video_prompt` 里**不要**包含旁白内容，也不要让画面里的人物去念解说词。旁白是画外音，走独立音轨。
- 角色之间真实的**对白**仍照常写在 `description` 的对应【镜头N】内——对白与旁白是两回事。

## 2. 给旁白留叙述空间

- `description` 的子镜头节奏要可被叙述：一镜之内 2–3 个子镜头为宜，不要把一镜塞满动作切换，否则解说词没有落脚点。
- 画面要能**承载**一句解说：有明确的主体与动作，而不是纯抽象运镜。
- 允许并鼓励少量纯画面镜头（空镜、环境、情绪停顿）——旁白 Agent 会把这些镜头留作无解说。

## 3. 时长按旁白预算估算

- 该镜预计解说字数 ÷ **4.5 字/秒** + **0.8 秒**尾部留白，结果钳到 **4–15 秒**，作为 `duration`。
- 解说单段硬上限 **80 字**，所以一镜承载的叙述量不要超过约 15 秒能念完的内容；信息过多就拆成两镜。
- 实际 `duration` 会在旁白配音生成后按**实测配音时长**再回算一次，你这里给的是合理初值。
