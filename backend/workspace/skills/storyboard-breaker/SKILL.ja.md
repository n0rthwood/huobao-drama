# 絵コンテ分解ガイド

## 中核の定義：絵コンテパラグラフ

1つの絵コンテ = 1つの **絵コンテパラグラフ**（segment）= 1つの動画生成タスク。

- 各パラグラフの長さは **8〜15秒**、内部に **2〜4個のサブカット** を収める
- サブカット間は**カット割りしてよい**：サイズを変える、アングルを変える、被写体を変える。ハードカットでつなぐ
- サブカット間は**シーンをまたがない**：1つのパラグラフは1つのシーン内でのみ起こる（`scene_id` はパラグラフ単位の紐付け）
- 各サブカットは2〜6秒で、1つの画面単位（**1つの主要アクション**、1つのリアクション、1つのアップ）に集中する

## 分解フロー（5ステップ）

1. `read_storyboard_context` を呼び、脚本、キャラクター、シーン、小道具、既存の絵コンテ概要を読む
2. **ビートの識別**：【オープニング】【トリガー】【クライマックス】【締め】などのマーカーや物語の転換点を識別する。ビートの境界では強制的にパラグラフを切る。同じビートのサブカットは同一パラグラフを優先し、因果の連鎖をばらばらにしない
3. **カットごとの物体スキャン**：各パラグラフについて脚本を一文ずつスキャンし、画面に見える物体を列挙 → 小道具リストに対応づけて `prop_ids` を紐付け → 3つのキーフレームと video_prompt で @小道具名 を使う。承継チェーン上の手持ち物・装着物は連続して引用する（`prop-continuity` スキル参照）。脚本にあって小道具リストにない物体は締めの文のリストに記録する
4. **総量のアンカー**：目標総尺 = 脚本の文字数 ÷ 毎分500字。パラグラフ数 ≈ 目標総尺 ÷ 12秒、±20%
5. **パラグラフ内のサブカット分割**：アクション、視点、被写体の切り替え点で分割し、フィールドを補完してから `save_storyboards` を呼んで分割保存する

## リズム階層ごとの尺

| パラグラフ種別 | 尺 | 説明 |
|---|---|---|
| つなぎパラグラフ | 8〜10秒 | 移動、空舞台、環境の提示、場面転換 |
| 叙述パラグラフ | 10〜15秒 | 通常の物語進行、会話 |
| 山場パラグラフ | 12〜15秒 | アップ、ルールの開示、感情の爆発、どんでん返し。単一サブカットを4〜6秒とどめてよい |

ハードルール：15秒のパラグラフには最低3つのサブカット。どのサブカットも5秒を超えない。純粋なアップのサブカットは1パラグラフにつき最大1つで、締めにしてはならない——アップで締めると動画の後半がどんどん寄っていく大きな顔に潰れてしまう。

## セリフ尺の下限（ハードルール）

**パラグラフの尺 ≥ パラグラフ内のセリフとナレーションの総文字数 ÷ 毎秒4.5字 ＋ 演技の余裕2秒**。収まらないセリフは次のパラグラフに送る。

## アクションと四肢（ハードルール）

- **1サブカット1主要アクション**：「脚を下ろす→体をひねる→また組み直す」のようなアクション連鎖を1つのサブカットに詰め込むのは禁止。分割するか取捨する
- **高リスクなアクションは四肢の行き先を書く**：あぐら／しゃがみ込み／片脚立ち／脚を組む／振り向き／2キャラの身体的接触／鏡を見る、これらは description に両手両脚の収め方と見え方を明記する（「両脚を身体の前に引き寄せて組み、両足は身体の下にしまい、両手で膝を抱える」）
- **遮蔽されるアクションは書き換える**：手を背中側へ伸ばすなど胴体に遮られるアクションは、横向きで見える等価なアクションに書き換える（「カメラに対して横を向き、右手を背中側の腰へ回し、肘が見える」）——モデルは見えない四肢を描けず、でたらめにつなぐだけだ
- **接触インタラクションは双方を宣言**：A が B に触れるとき、両キャラクターの四肢の最終状態を書き、接触点は1つだけにする
- **非人間体型の実行可能性への書き換え**：短い四肢と丸い体、蹄、手足が同形のキャラクターは、まず人間の動作をその体型で実行可能な版に書き換える（モルモットがダンベルを持ち上げる → 両前足でバーを胸の前に抱える。樹のポーズ → 片方の後ろ足をわずかに地面から浮かせる）
- **複数キャラが同じ画面**：3キャラ以上、または2キャラの距離が半身分未満のときは、各キャラクターごとに1文で位置と姿勢を述べる。まとめて書かない

## カットの要素

1. **カットタイトル**：3〜5文字の要約
2. **時間**：具体的な時刻 ＋ 光の描写
3. **場所**：シーンの完全な記述 ＋ 空間レイアウト
4. **サイズ**：主となるサイズ。複数サイズなら組み合わせを書く
5. **アングル**：水平／アオリ／俯瞰／横／後ろ
6. **カメラワーク**：固定／寄り／引き／パン／フォロー／移動
7. **画面描写** `description`：【カットN】ごとにサブカット単位で描写。画面が先、セリフは中に（ルールは上記）
8. **画面の結果** `result`：パラグラフ末尾の直接的な帰結 ＋ 視覚的ディテール ＋ この時点で各キャラクターが**何を手に持ち、何を身につけているか**
9. **雰囲気** `atmosphere`：光 ＋ 色調 ＋ 音 ＋ 全体の雰囲気
10. **尺** `duration`：8〜15秒かつセリフ下限を満たす
11. **シーン紐付け** `scene_id`、12. **キャラクター紐付け** `character_ids`、13. **小道具紐付け** `prop_ids`
14. **接続の注記** `continuity`
15. **キーフレームプロンプト**：`first_frame_prompt` / `mid_frame_prompt` ＋ `mid_frame_time` / `last_frame_prompt`

## シーン紐付けのルール

- `read_storyboard_context` が返す `scenes` を優先する。`location + time` が明確に一致する場合は正しい `scene_id` を必ず書き戻す
- 存在しないシーン ID を勝手に生成しない。同一の物理空間を複数のシーンとして使わない

## キャラクター紐付けのルール

- `character_ids` は返されたキャラクターリストから取る。明確に登場する、見られる、動作する、話すキャラクターはすべて紐付ける。空舞台では空配列を渡す

## 小道具の紐付けと参照画像の予算

- `prop_ids` は返された小道具リスト（`props`）から取る
- 小道具が使われる、受け渡される、アップになる、装着される、または画面上で明らかに見えて物語上意味がある場合は、必ず紐付けてプロンプト内で @ する
- 予算：1カットあたり参照画像は上限9枚、動画側の先頭フレームが1枚を占める → シーン1 ＋ キャラクターN ＋ 小道具M ≤ 8
- 予算超過時の取捨優先度：シーン ＞ 登場キャラクター ＞ 使用・アップの小道具 ＞ 見えるだけの小道具。押し出された小道具は紐付けと @ を同時に外し、「@ したのに紐付けていない」名前を残さない（ref_issues が出る）
- 物語に関係のない背景の物は紐付けない。小道具のないパラグラフは空配列を渡す

## 接続の注記とキーフレーム

**注記のルール**（すべてのパラグラフに `continuity` を付ける）：

| 状況 | 値 |
|---|---|
| 最初のパラグラフ | `cut` |
| シーン変更（`scene_id`／場所の変化）、時間の飛躍、回想、意図的なハードカット | `cut`（**シーンをまたぐ continue は厳禁**——承継された先頭フレームが誤ったシーンの画像にアンカーしてしまう） |
| 同一シーン、前のパラグラフのすぐ次の瞬間、人物の継続 | `continue` |

**キーフレームのフィールド**（ルールの詳細は `keyframe-prompt` スキル。厳守すること）：

- `first_frame_prompt`：【カット1】の冒頭の瞬間。`continue` のパラグラフでは必ず空にする
- `mid_frame_prompt` ＋ `mid_frame_time`：最初のサブカット以外で最も重要なサブカットの開始の瞬間。`mid_frame_time` はその【カットN】の開始時刻とぴったり一致し、0.5 と `duration - 0.5` の間に厳密に収まること。サブカットが1つだけの場合は書かない
- `last_frame_prompt`：パラグラフ末尾の瞬間で、`result` と一致させる

**書き方の要求**：

- 各キーフレームプロンプトは自己充足であること：@シーン名、サイズ・カメラ位置・構図、各 @キャラクター名 の位置／姿勢／**両手両脚の状態**／表情、主要な @小道具名 と**装着・把持の状態**、光と雰囲気。相対的な記述は禁止
- **絶対的な画像優先**：キャラクターの種族、衣装、色、髪型、体型、顔立ち、年齢を描写してはならない。キャラクターは `@キャラクター名` でのみ指す。相対的な体格比率と装着系小道具の装着状態は書いてよい（それらは容姿の描写ではない）。衣装は造形バージョンの参照画像が決める
- 後ろに `continue` が続くパラグラフでは、`last_frame_prompt` は安定し、情報が明瞭で、人物が完全に画面に入り、次のパラグラフに必要な人物とその手持ち・装着小道具を含むこと
- 鏡と画面：同一フレームでは「鏡像」か「実体」のどちらか一方のみを主体とする。画面内のテレビは番組を流すだけで、本作のキャラクターを映してはならない

## 品質の要求

- `description` は人が読むのに適し、観客が実際に見て聞く内容をサブカット単位で描写する
- 3つのキーフレームプロンプトは単一フレームの構図、人物の位置と姿勢、四肢の状態、環境光を際立たせる
- `bgm_prompt` と `sound_effect` は簡潔なフレーズで書くが、「緊張」「悲しい」だけのように漠然としてはならず、空欄にもしない
- 調整が必要なら `update_storyboard` を呼んで該当パラグラフを修正する
