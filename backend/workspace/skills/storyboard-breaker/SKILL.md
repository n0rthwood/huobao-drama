# 分镜拆解指南

## 核心定义：分镜段落

一个分镜 = 一个 **分镜段落**（segment）= 一个视频生成任务。

- 每个段落时长 **8-15 秒**，内部承载 **2-4 个子镜头**
- 子镜头之间**可以切镜**：换景别、换角度、换拍摄对象，用硬切衔接
- 子镜头之间**不跨场景**：一个段落只发生在一个场景内（`scene_id` 是段落级绑定）
- 每个子镜头 2-6 秒，聚焦一个画面单元（**一个主动作**、一个反应、一个特写）

## 拆分流程（五步）

1. 调用 `read_storyboard_context` 读取剧本、角色、场景、道具、已有分镜摘要
2. **节拍识别**：识别【开场】【触发】【高潮】【收尾】等标记或叙事转折点，节拍边界强制切段；同一节拍的子镜头优先同段，不把因果链切散
3. **逐镜物件扫描**：对每个段落逐句扫描剧本，列出画面可见物件 → 映射到道具列表绑定 `prop_ids` → 在三条关键帧与 video_prompt 中 @道具名；承接链上的手持物/穿戴物连续引用（见 `prop-continuity` 技能）；剧本有、道具列表没有的物件记入结束语清单
4. **总量锚定**：目标总时长 = 剧本字数 ÷ 500字/分钟；段落数 ≈ 目标总时长 ÷ 12秒，±20%
5. **段落内拆子镜头**：按动作、视角、对象切换点切分，补全字段后调用 `save_storyboards` 分批保存

## 节奏分层时长

| 段落类型 | 时长 | 说明 |
|---|---|---|
| 过渡段 | 8-10 秒 | 赶路、空镜、环境建立、转场 |
| 叙事段 | 10-15 秒 | 常规剧情推进、对话 |
| 爆点段 | 12-15 秒 | 特写、规则揭示、情感爆发、反转；单个子镜头可停留 4-6 秒 |

硬规则：15 秒段落至少 3 个子镜头；任何子镜头不超过 5 秒；纯特写子镜头每段至多 1 个且不得收尾——特写收尾会让视频后半段塌缩成不断推近的大脸。

## 台词时长下限（硬规则）

**段落时长 ≥ 段内台词与旁白总字数 ÷ 4.5字/秒 + 2秒表演余量**，装不下的台词拆到下一个段落。

## 动作与肢体（硬规则）

- **一个子镜头一个主动作**：禁止把「放下腿—扭身—又盘回去」这类动作链塞进一个子镜头，拆开或取舍
- **高风险动作写四肢去向**：盘腿/蹲缩/单腿站立/翘二郎腿/转身/两角色肢体接触/照镜，description 必须写明双手双腿的收纳方式与可见性（「双腿向身前收拢盘起，双脚收于身下，双手抱膝」）
- **遮挡动作改写**：手伸向身后等被躯干遮挡的动作，改写为侧身可见的等效动作（「侧对镜头，右手绕向身后腰侧，手肘可见」）——模型画不出看不见的肢体，只会乱接
- **接触互动双边声明**：A 碰 B 时，两个角色的肢体终态都要写，接触点唯一
- **非人体型可行性改写**：短肢圆身、蹄足、手脚同形的角色，先把人类动作改写成该体型做得出的版本（豚鼠举哑铃 → 双爪环抱铃身于胸前；树式 → 一只后爪稍稍抬离地面）
- **多角色同框**：≥3 角色或两角色距离小于半个身位时，每个角色单独一句交代位置与姿态，不要合并描写

## 镜头要素

1. **镜头标题**：3-5字概括
2. **时间**：具体时分 + 光线描述
3. **地点**：场景完整描述 + 空间布局
4. **景别**：主导景别；多景别写组合
5. **角度**：平视/仰视/俯视/侧面/背面
6. **运镜**：固定/推/拉/摇/跟/移
7. **画面描述** `description`：按【镜头N】逐子镜头描述，画面在前、台词在内（规则见上）
8. **画面结果** `result`：段落结尾的即时后果 + 视觉细节 + 此刻每个角色**手持/穿戴着什么**
9. **氛围** `atmosphere`：光线 + 色调 + 声音 + 整体氛围
10. **时长** `duration`：8-15 秒且满足台词下限
11. **场景关联** `scene_id`、12. **角色关联** `character_ids`、13. **道具关联** `prop_ids`
14. **衔接标注** `continuity`
15. **关键帧提示词**：`first_frame_prompt` / `mid_frame_prompt` + `mid_frame_time` / `last_frame_prompt`

## 场景关联规则

- 优先使用 `read_storyboard_context` 返回的 `scenes`；`location + time` 可明确匹配时必须回填正确 `scene_id`
- 不要凭空生成不存在的场景 ID；同一物理空间不要当成多个场景使用

## 角色绑定规则

- `character_ids` 必须来自返回的角色列表；明确出场、被看见、发生动作或说话的角色都绑定；空镜传空数组

## 道具绑定与参考图预算

- `prop_ids` 必须来自返回的道具列表（`props`）
- 道具被使用、交接、特写、佩戴，或画面中明显可见且对叙事有意义时，必须绑定并在提示词中 @
- 预算：每镜参考图上限 9 张，视频侧首帧占 1 张 → 场景 1 + 角色 N + 道具 M ≤ 8
- 超预算取舍优先级：场景 > 出场角色 > 被使用/特写的道具 > 仅可见的道具；被挤掉的道具同时移除绑定与 @，不要留「@ 了却没绑定」的名字（会报 ref_issues）
- 与剧情无关的背景物品不绑定；没有道具的段落传空数组

## 衔接标注与关键帧

**标注规则**（每个段落都要给 `continuity`）：

| 情况 | 取值 |
|---|---|
| 第一个段落 | `cut` |
| 换场景（`scene_id`/地点改变）、时间跳跃、闪回、刻意硬切 | `cut`（**严禁跨场景 continue**——承接首帧会锚到错误场景的图上） |
| 同一场景、上一段紧接着的下一刻、人物延续 | `continue` |

**关键帧字段**（规则详见 `keyframe-prompt` 技能，必须严格遵循）：

- `first_frame_prompt`：【镜头1】开场瞬间；`continue` 段落必须留空
- `mid_frame_prompt` + `mid_frame_time`：除第一个子镜头外最重要子镜头的起始瞬间；`mid_frame_time` 必须正好是该【镜头N】起始时间且严格落在 0.5 与 `duration - 0.5` 之间；只有一个子镜头时不写
- `last_frame_prompt`：段落结尾瞬间，与 `result` 一致

**写法要求**：

- 每条关键帧提示词必须自足：@场景名、景别机位构图、每个 @角色名 的位置/姿态/**双手双腿状态**/表情、关键 @道具名 及**穿戴持握状态**、光线氛围；禁止相对描述
- **绝对图像优先**：禁止描写角色的物种、服装、颜色、发型、体型、五官、年龄；角色只用 `@角色名` 指代。允许写相对体型比例与穿戴类道具的佩戴状态（它们不是长相描写）；服装由造型版本参考图决定
- 后面跟 `continue` 的段落，`last_frame_prompt` 必须稳定、信息清晰、人物完整入画、含下一段需要的人物及其手持/穿戴道具
- 镜面与屏幕：同一帧只以「镜中像」或「真身」之一为主体；画面内电视只播节目，禁止出现本片角色

## 质量要求

- `description` 适合人读，逐子镜头描述观众实际看到和听到的内容
- 三条关键帧提示词突出单帧构图、人物位置姿态、四肢状态、环境光线
- `bgm_prompt` 和 `sound_effect` 用简洁短语，但不能空泛到只有「紧张」「悲伤」，也不要留空
- 如需调整，调用 `update_storyboard` 修改具体段落
