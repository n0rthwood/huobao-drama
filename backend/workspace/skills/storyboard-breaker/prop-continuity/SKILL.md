# 道具连续性（分镜层）

## 为什么

道具资产只有被分镜**绑定（prop_ids）并 @ 引用**才会变成参考图。漏绑一个镜头，该镜头里这个物件就会被模型重新发明一次外观。承接镜头尤其危险：上一镜还在手里的哑铃，下一镜不 @ 就会消失或变形。

## 逐句扫描流程

对每个分镜段落：

1. 把该段落覆盖的剧本句子逐句过一遍，列出**画面会看到的物件**（含角色手里的、身上戴的、脚下踩的、要照的）
2. 与 `read_storyboard_context` 返回的 `props` 列表匹配：
   - 匹配上 → 绑进 `prop_ids`，并在 description、三条关键帧提示词、video_prompt 中用 `@道具名` 引用
   - 匹配不上 → 记入「缺失物件清单」，完成全部保存后在结束语中列出，提醒用户先补提取；**不要**用纯文本描写顶替（纯文本 = 每帧重新发明）
3. 核对预算（见下），超了按优先级裁掉次要道具的绑定与 @

## 承接链规则

- **手持物**：角色拿着的东西，在它存在的每个段落、每条关键帧提示词、每个视频分段都要 @ 并写明「在哪只手」；放下/交接的瞬间单独成一个子镜头写清楚
- **穿戴物**（帽、眼镜、墨镜、头盔）：每张关键帧、每个视频段写明当前状态——**戴着 / 拿在哪只手 / 不在画面**。摘下和戴上各自是独立的主动作，不与其它动作并行
- **交接帧**：`result` 与 `last_frame_prompt` 必须写明段落结束时每个角色手持/穿戴着什么——这是下一镜承接的依据
- **静置资产同样逐段 @**：在场但无人持用的绑定道具（镜子、垫子、桌上的本子）与**场景本身**，在 description、关键帧提示词、video_prompt 的每个分段同样要 @（背景/虚化/画外用 `@名字（画外）` 注记）——段内未 @ 等于该段撤掉参考图；「扶着/搭在/放着 + @道具」要升级为含功能部件或持握部位的写法（详见 video-prompt 技能「引用规则」）
- 跨段落状态必须自洽：上一镜尾帧「墨镜拿在右手」，下一镜首帧（承接）不允许凭空变成「戴在脸上」

## 参考图预算与取舍

- 上限 9 张/镜，视频生成时首帧关键帧先占 1 张 → **场景 1 + 角色 N + 道具 M ≤ 8**
- 取舍优先级（从保到弃）：
  1. 场景图
  2. 出场角色（含造型版本图，系统按 asset_version_selection 自动选版）
  3. 被使用、交接、特写、佩戴的道具
  4. 仅静置可见的道具
- 被裁掉的道具：同时移除 `prop_ids` 绑定与所有 `@` 引用（@ 了未绑定会报 ref_issues；绑定了不 @ 则白占名额）
- 道具多到装不下时优先考虑拆分子镜头到两个段落，各自引用一半道具
