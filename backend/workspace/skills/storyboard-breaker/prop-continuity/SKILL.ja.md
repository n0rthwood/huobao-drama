# 小道具の連続性（絵コンテ層）

## なぜ

小道具アセットは絵コンテが**紐付け（prop_ids）し、@ で引用**して初めて参照画像になる。1カットでも紐付けを漏らすと、そのカットではその物体の外観がモデルによって作り直される。承継カットは特に危険だ：前のカットでまだ手にしていたダンベルは、次のカットで @ しなければ消えるか変形する。

## 一文ずつのスキャン手順

各絵コンテパラグラフについて：

1. そのパラグラフがカバーする脚本の文を一文ずつ通し、**画面に見える物体**を列挙する（キャラクターの手の中、身につけているもの、足元で踏んでいるもの、映すものを含む）
2. `read_storyboard_context` が返す `props` リストと照合する：
   - 一致した → `prop_ids` に紐付け、description、3つのキーフレームプロンプト、video_prompt で `@小道具名` として引用する
   - 一致しない → 「欠落物体リスト」に記録し、すべての保存を終えた後に締めの文で列挙し、先に抽出を補うようユーザーに注意を促す。**プレーンテキストの描写で代用しない**（プレーンテキスト = 毎フレーム作り直し）
3. 予算（下記）を照合し、超過した場合は優先度に従って重要度の低い小道具の紐付けと @ を削る

## 承継チェーンのルール

- **手持ち物**：キャラクターが持っている物は、それが存在するすべてのパラグラフ、すべてのキーフレームプロンプト、すべての動画分割セグメントで @ し、「どちらの手か」を明記する。置く／受け渡す瞬間は独立したサブカットにして明確に書く
- **装着物**（帽子、眼鏡、サングラス、ヘルメット）：各キーフレーム、各動画セグメントで現在の状態を明記する——**着けている／どちらの手に持っている／画面にない**。外す動作と着ける動作はそれぞれ独立した主要アクションであり、他の動作と並行させない
- **受け渡しフレーム**：`result` と `last_frame_prompt` には、パラグラフ終了時に各キャラクターが何を手に持ち何を身につけているかを必ず書く——これが次のカットの承継の根拠になる
- パラグラフをまたぐ状態は自己整合していること：前のカットの最終フレームが「サングラスを右手に持っている」なら、次のカットの先頭フレーム（承継）で何の説明もなく「顔に着けている」になってはならない

## 参照画像の予算と取捨

- 1カットあたり上限9枚、動画生成時は先頭フレームのキーフレームが先に1枚を占める → **シーン1 ＋ キャラクターN ＋ 小道具M ≤ 8**
- 取捨の優先度（守るものから捨てるものへ）：
  1. シーン画像
  2. 登場キャラクター（造形バージョン画像を含む。システムが asset_version_selection に従って自動でバージョンを選ぶ）
  3. 使用・受け渡し・アップ・装着される小道具
  4. ただ置かれて見えるだけの小道具
- 切り捨てた小道具：`prop_ids` の紐付けとすべての `@` 引用を同時に外す（@ したのに紐付けていないと ref_issues が出る。紐付けたのに @ しないと枠を無駄に占める）
- 小道具が多すぎて収まらないときは、サブカットを2つのパラグラフに分割し、それぞれが半分ずつ引用することを優先して検討する
