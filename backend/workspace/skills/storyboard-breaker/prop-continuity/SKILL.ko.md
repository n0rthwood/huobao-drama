# 소품 연속성(스토리보드 층)

## 왜

소품 자산은 스토리보드가 **바인딩(prop_ids)하고 @ 로 인용**해야만 참조 이미지가 된다. 한 컷에서 바인딩을 빠뜨리면 그 컷의 해당 물건은 모델이 외관을 다시 만들어 낸다. 승계 컷은 특히 위험하다: 앞 컷에서 아직 손에 쥐고 있던 덤벨은 다음 컷에서 @ 하지 않으면 사라지거나 변형된다.

## 한 문장씩 스캔 절차

각 스토리보드 구간에 대해:

1. 그 구간이 다루는 대본 문장을 한 문장씩 훑어 **화면에서 보게 될 물건**을 나열한다(캐릭터가 손에 든 것, 몸에 착용한 것, 발로 밟고 있는 것, 비춰 볼 것 포함)
2. `read_storyboard_context` 가 반환하는 `props` 목록과 매칭한다:
   - 일치 → `prop_ids` 에 바인딩하고 description, 세 개의 키프레임 프롬프트, video_prompt 에서 `@소품명` 으로 인용한다
   - 불일치 → "누락 물건 목록"에 기록하고, 모든 저장을 마친 뒤 마무리 멘트에서 나열해 사용자에게 먼저 추출을 보완하도록 알린다. **순수 텍스트 묘사로 대체하지 말 것**(순수 텍스트 = 매 프레임 새로 만들어짐)
3. 예산(아래 참조)을 확인하고, 초과하면 우선순위에 따라 덜 중요한 소품의 바인딩과 @ 를 덜어낸다

## 승계 체인 규칙

- **손에 든 물건**: 캐릭터가 들고 있는 물건은 그것이 존재하는 모든 구간, 모든 키프레임 프롬프트, 모든 영상 분할 구간에서 @ 하고 "어느 손에 있는지"를 명시한다. 내려놓거나 건네는 순간은 별도의 서브 컷으로 분리해 명확히 쓴다
- **착용 물건**(모자, 안경, 선글라스, 헬멧): 각 키프레임, 각 영상 구간마다 현재 상태를 명시한다 — **쓰고 있음 / 어느 손에 들고 있음 / 화면에 없음**. 벗는 동작과 쓰는 동작은 각각 독립된 주요 동작이며 다른 동작과 병행하지 않는다
- **전달 프레임**: `result` 와 `last_frame_prompt` 에는 구간이 끝날 때 각 캐릭터가 무엇을 들고 무엇을 착용하고 있는지 반드시 써야 한다 — 이것이 다음 컷 승계의 근거다
- 구간을 넘는 상태는 스스로 일관되어야 한다: 앞 컷 마지막 프레임이 "선글라스를 오른손에 들고 있음"이면, 다음 컷 첫 프레임(승계)에서 느닷없이 "얼굴에 쓰고 있음"이 되어서는 안 된다

## 참조 이미지 예산과 취사선택

- 컷당 상한 9장, 영상 생성 시 첫 프레임 키프레임이 먼저 1장을 차지 → **장면 1 + 캐릭터 N + 소품 M ≤ 8**
- 취사 우선순위(지킬 것부터 버릴 것까지):
  1. 장면 이미지
  2. 등장 캐릭터(스타일링 버전 이미지 포함. 시스템이 asset_version_selection 에 따라 버전을 자동 선택)
  3. 사용·전달·클로즈업·착용되는 소품
  4. 그저 놓여 보이기만 하는 소품
- 잘려 나간 소품: `prop_ids` 바인딩과 모든 `@` 인용을 동시에 제거한다(@ 했는데 바인딩하지 않으면 ref_issues 가 발생하고, 바인딩했는데 @ 하지 않으면 자리만 낭비한다)
- 소품이 너무 많아 담기지 않으면 서브 컷을 두 구간으로 나누어 각각 절반씩 인용하는 방안을 우선 고려한다
