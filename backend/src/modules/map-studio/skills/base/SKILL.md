# 地图工作流：底图

本阶段由你决定这张地图用哪条底图路线、取多大范围。你生成底图后要自己检查，再交付。代码只检查取景是否合格。

## 三条路线（`render_base` 的 mode）

| mode | 适用 | 注意 |
|---|---|---|
| `program` | 大多数历史地图。底图是 Natural Earth 的现代自然地理（陆地、海岸、河湖、国界），干净、出图快 | 现代地理，不代表古代河道或疆界 |
| `earth` | 需要真实地形、影像质感时 | 很慢（几分钟），失败时如实看错误原因 |
| `image` | 需求里给了外部参考图和控制点时 | 需求里没有参考图就不能用 |

用户在需求里写的底图偏好可以作为参考，由你权衡。

## 主题与底图

提示提供当前制图主题的名称、用途、色板和默认要素样式。人工已选主题不改；新任务的 null 在本阶段解析模块默认，写入 map_spec.style.map_style，后续底纹与绘制沿用。program 按主题渲染背景、陆地、河湖、海岸与现代边界的颜色/线宽；不要通过换地理数据或逐层手调来冒充风格化。earth/image 保留真实底图内容，主题只影响后续叠加样式。

正例：atlas-tint 区域图用 program 得到淡彩底图，再由 drawing 使用主题默认标注。反例：因选 relief-shading 就凭空补画山脉，或更改 bbox/河道几何来“更像古图”。主题参考不是史实证据。


## 取景（bbox）

- `bbox = [west, south, east, north]`，单位是 WGS84 度。
- **所有要素的所有顶点都必须落在画面内**，离画面四边至少留 2%。
- **要素整体要占画面主体**：所有顶点的外包框，最大边至少占画面的 30%。如果主题挤在画面一角、四周大片无关区域，就是取景过大，要收小 bbox。
- 只为说明位置而留背景时，适当外扩即可，不要把整个大洲都放进来。
- map_spec 里原有的 bbox 只是参考，不是约束；不合适就改。

## 工作方法

1. 调用 `render_base` 生成底图，不消耗轮次。返回结果里的 `frame` 给出每个要素的归一化位置、要素外包框占比，以及取景问题。
2. 用 `read_image` 看生成的底图：要素所在区域是否清楚，周边地理能否帮读者定位。
3. 取景有问题就调整 bbox 重新生成；满意后用 `submit_base` 交付那张底图的 `artifact_id`（消耗一轮）。
4. 如果是要素本身有错（例如某个点明显不在它该在的位置），在本阶段无法修正，调用 `request_rollback` 回到 `research`，并写清楚是哪个要素、哪里错了。
