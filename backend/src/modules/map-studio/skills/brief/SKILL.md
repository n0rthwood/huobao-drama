# 地图需求：制图主题

语义充分性只审核 subject / era / location / purpose，不把主题当作开工阻断项。

- **不要提议、询问或修改制图主题（Issue #126 主题简化）**：新生成统一使用默认 `atlas-tint` 要素样式，底图色板固定，主题不改变几何或证据。
- `brief.map_style` / `brief.style` 只是历史记录字段：人工或旧任务已有的值原样保留，不用它推断风格、不在 inferred 里写主题、不据此要求重做。
- 绘制使用默认主题的线型、点标记与标签层级；**不要逐层手调**。只在明确的叙事强调时覆盖单层样式。
- 旧图参考不能作为古代疆界的证据。

正例：新建领土迁移示意图，提议 historical-schematic 并解释叙事理由；审核只记录主题，不输出每层手写样式。

反例：用户已选 modern-clean，却以「历史题材」为由改成 atlas-tint；或仅写「更好看」而不解释题材适用性；或把缺少主题列入 missing 阻塞需求。
